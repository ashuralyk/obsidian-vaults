# 分镜图制作

## 核对输入并选择草稿路线

读取用户指定的分镜版本、对应剧本和资产集合。默认从同一项目的 `Storyboard - Draft N.md`、`Screenplay.md` 和 `Assets/资产统筹表.md` 取材。多版并存时优先采用已确认版；无法判定时让用户指定。按镜号建立对应关系，核对时长、运镜、视角、关键动作及出镜人物、场景和道具。打开统筹表链接的实际图像，核对资产编号、版本、造型与确认状态。使用模型时先取得可供图像生成引用的模型渲染图。正式出图前按 [资产制作技能](../screenplay-assets/SKILL.md#第三阶段实际生成一致性图) 核对适用的全员身高与体型对照图，并按镜号确认人物、道具及场景所需形态或状态的参考图及版本。缺少适用的对照图或状态图时，按下文缺项流程处理。

如果缺少实际资产、配套统筹表或本段所需的素材，说明具体缺项，询问用户想看九宫格分镜漫画、九宫格线框草稿，还是先补资料。资产与表齐备时，询问是否跳过九宫格；保留草稿时让用户同时选定漫画或线框。已有明确选择时直接执行对应步骤。

出图、改图或写视频提示词时，凡引用图片，先用一个独立段落按实际上传顺序登记图片与固定名词代称的对应关系。正文统一用登记的代称指向图片内容，例如写「取本页分镜图的右上格」。图片编号、文件名和产品图片绑定标记只出现在绑定段，原台词照录。交付时核对上传顺序、绑定段与正文是否一致。

单次出图、改图或单页视频提示词原则上最多引用 9 张图片。作为镜头内容参考上传的分镜页、待编辑原图和资产图均计入。出图或改图时，专门用于约束色调和风格的参考图另计。同一张图若也承担镜头内容或资产参考，仍计入 9 张。先去掉重复和非必要的图，能清楚提供所需细节时可使用已确认的合图。只有这样仍无法把必需参考压到 9 张以内，且目标工具允许时，才可按最低所需数量超出，并在对应页记录必须额外引用的图片和原因。

## 绘制九宫格草稿

按分镜顺序从左到右、从上到下排入 3×3 网格，每格对应一镜。绘制漫画时让动作和人物反应可读，绘制线框时用人物轮廓、视线和透视交代位置。每个有内容的格子左上角都要清楚标出原镜号、运镜、视角和时长，例如「镜 2.3｜缓推｜平视｜4 秒」。优先在排版时叠印文字，并打开成图核对字号和内容。尾页余格留空。保存实际图片，请用户看图确认或指出要改的镜号。若此时资产仍有缺项，交付草稿并列出进入正式制作所需补齐的资料。

## 制作正式四宫格

人物、道具、场景及其跨镜状态的一致性是正式分镜的首要验收项，优先于色调和风格。逐格绑定对应版本的资产图。筛减参考图时，先保留判定人物比例、道具结构和场景布局或状态所必需的资产图。如果资产图不足以判断剧情所依赖的比例、结构或位置，先回到资产制作补齐参考，再生成该格。

色调与风格一致性是正式分镜出图和改图的硬性要求。每次必须实际绑定已确认的项目风格图，或同场已通过且光线条件相近的分镜格。已有适用的同场参照时优先使用，并记录参考图的来源和版本。参考图负责约束配色、整体明暗、明暗反差、材质和纹理密度，镜头构图、动作及叙事所需的光线变化仍按原分镜执行。风格图单独计数，仍须遵守出图工具的总输入上限。缺少已确认的参照时，先选代表镜头做样图，获确认后再批量制作。

草稿确认或用户明确跳过后，在对应资产齐备的前提下，询问是否制作正式四宫格。得到同意后，按原镜序逐镜累加时长，每页最多四格，总时长最多 15 秒。加入下一镜会超时就立即另起一页，余格留空，不挪用后面的短镜填空。例如连续三镜分别为 6、6、4 秒，第一页放前两镜，共 12 秒，第三镜从新页开始。单一长镜超过 15 秒时沿用原镜号和上游时间段，跨页标明起止时间及连续动作；上游未分段时先提出分段点并与用户确认。不得缩短原镜或凭空加切。

结合剧本和分镜，逐格选择能读出该镜动作的瞬间。打开生成的图像，核对后按固定格序组成 2×2 正式页。保持单格画幅、清晰度和完整构图，镜号等制作信息记在表中，使有效画面可以独立裁出用于视频。留白不代表黑场或额外时长。工具不能接收参考图或不能产出可保存的图片时，说明受阻环节并保留已完成的工作。

每页必须交给独立子 Agent 实际看图。提供当前页、相邻页衔接画面、对应原分镜、资产图和实际使用的风格图，请其按页码、格位、镜号报告可见异常及依据。先逐格对照对应资产和状态图，再沿镜序核对相邻格及跨页衔接。检查人物身份、服装、体型和头身比，结合透视、同景深的人或物及全员对照图判断相对尺度。检查道具的尺寸、连接结构和使用动作，检查场景的固定位置、朝向和状态变化。区分透视、遮挡、裁切和剧本规定的状态变化。剧情依赖的形状、尺寸关系或动作必须在对应镜头中看得清。任何可见的一致性错误，或无法判断的剧情关键细节，均不得通过。修正问题格后必须复查受影响的相邻格和跨页衔接。

一致性核对通过后，把相邻格及跨页衔接画面与风格图并排，分别检查整体明暗、局部光源、色偏、材质和纹理密度。排除分镜明确要求的光线变化后，仍有明显过亮、偏色、纹理显脏或画风跳变的格子，必须修正并复查相邻格后才能通过。同时检查肢体和接触关系、视线与轴线、动作衔接、构图裁切、顺序与时长。主 Agent 修复问题格，重新合成并将新版本送检；修改影响邻格或跨页衔接时一并复查。当前图像版本通过后进入提示词编写和编表。无法看图或调用子 Agent 时保留待检状态。

## 编制分镜资源统筹表

正式图通过后，实际读取并使用同级 [prompt-writing-guide](../prompt-writing-guide/SKILL.md)。每页生成一条完整的视频提示词，把有效格当作依次发生的镜头参考，明确只呈现各镜全幅画面。视频提示词阶段以正式分镜页和所需资产为图像参考，禁止另外引用或绑定出图阶段使用的风格图。按原时长写连续时间段，结合剧本交代动作缘由、可见的表演变化、镜头运动和声画衔接；原台词逐字保留。连续长镜跨页时说明承接姿态和运动方向。只有指定目标产品时才依其当前官方文档填写专用字段和素材绑定语法。

另启未参与撰写的子 Agent 盲检。先只给正式图和候选提示词，让其独立还原格序、时间、动作与台词，记录歧义。随后提供原分镜与对应剧本段落，请其核对遗漏、擅加内容和可执行性。两遍均不提供主 Agent 的写作理由或预期评价。主 Agent 按镜号修改后将新稿交给独立子 Agent 重做盲检；只登记实际通过的图词版本。

默认将图片放在项目的 `StoryboardAssets/Drafts/` 和 `StoryboardAssets/Final/`，将 `分镜资源统筹表.md` 保存在 `StoryboardAssets/`。表头记录来源版本，每个正式页单列两列表格：

| 字段 | 内容 |
| --- | --- |
| 正式四宫格 | 嵌入可打开的本页图片，并标明页码和版本。 |
| 格序与时长 | 按格位列出原镜号、时间段、页总时长和空格。 |
| 使用资产 | 链接本页所用的资产编号及版本。 |
| 视频提示词 | 写入通过盲检的完整文本，保留时间段与台词，方便整页复制。 |
| 复核记录 | 分别登记图像复核和提示词盲检通过的版本。 |

## 分镜资源统筹表的独立验收

统筹表编完后、正式交付前，交未参与本轮出图、写词或编表的独立 Agent 做整表两轮测验。制作资料包括当前统筹表、原分镜、剧本、实际分镜图及对应版本的资产与风格图。图像复核和提示词盲检记录留待第二轮核对。两轮都须打开实际分镜图、核对每页提示词及相邻页衔接，按页码、格位和镜号记录发现。

两轮使用同一交付版本和同一组制作资料，中途不改图、不改词、不换表。

1. **第一轮，未加载技能的测验。** 用不继承制作对话的独立上下文启动审阅 Agent。只给本次范围、源文件、待检产物和一条中性的实际使用任务。统筹表若含旧分数、问题记录、验收结论或审阅链接，先在审阅副本中隐去这些内容，保留实际交付内容及其来源和文件链接。暂不提供技能、检查表、评分表、门槛、既有评审结论或制作方解释。审阅者先按自己的方法实测，记录实际操作、可定位的原始发现和使用判断。第一轮记录固定后，才允许进入第二轮。
2. **第二轮，加载技能的测验。** 由同一审阅者在第一轮记录固定后读取本技能及适用的配套指南，按条款重新检查同一版本。逐项留下检查证据，按下表打分并判定硬性项。第一轮的发现逐条复核，即使评分表没有对应维度，也保留原发现和核验结论。
3. **汇总。** 分列两轮结果，再列共同发现、第一轮独有发现和第二轮新增发现。对两轮不一致的结论，注明证据和最终处理，未能核实的标为待验证。涉及硬性项而尚未核实时，保留待检状态。以第二轮的正式分数和两轮核实的硬性问题共同判定是否通过，第一轮不套用正式评分表。

| 评分项 | 满分 | 检测内容 |
| --- | ---: | --- |
| 资产与跨镜一致性 | 40 | 对照资产和相邻镜头，核对人物身份与比例、道具结构、场景位置、状态变化和关键动作的可见性。 |
| 分镜与剧本忠实度 | 25 | 核对格序、镜号、时长、关键动作、运镜、信息揭示顺序及台词原文。 |
| 色调、风格与构图 | 15 | 对照已确认的风格图和相邻格，核对明暗、色偏、材质、纹理及单格构图可用性。 |
| 素材绑定与提示词可执行性 | 20 | 核对文件可打开、图词版本、素材上传顺序和名词代称、图像引用上限及其例外、时间段和跨页承接。 |

逐页按四项给分。完全符合给满分，部分符合按问题影响和范围扣分，整项无证据或不可用记零分。每页总分为四项相加，整表总分为各页分数的算术平均，判定时用未取整的分数。默认每页和整表均须达到 **80 分（含）**，且全部硬性项通过。既有的图像一致性、风格和提示词盲检要求仍须通过。另逐页核对有效格与原分镜一一对应、图片及必需素材可打开且版本正确、格序与时长无误、各页合计等于所选分镜总时长、台词逐字一致、素材绑定顺序与代称正确、引用数量及例外符合规定，且视频提示词阶段的图像引用符合风格图使用范围。任一硬性项失败均阻止通过。

在各页复核记录登记当前图词版本、审阅者、正式分项分、总分、硬性项结论及带镜号的证据。在表头登记整表版本、两轮原始记录或链接、汇总、总分及独立验收结论。低于门槛或硬性项失败时，修正后将新版交独立 Agent 对受影响页及相邻衔接重做两轮，第一轮须使用尚未接触评审技能和结论的审阅上下文，再重评整表。续作可复用版本和依赖均未变化的验收结果。无法实际看图或任一轮未完成时标为待检，只有当前版本通过才可正式交付。
