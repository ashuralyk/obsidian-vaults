# 提示词书写指南（参考用）

本技能**只作书写参考**：提炼「如何把演技/情绪写成模型可执行细节」的元方法。不要把它当成某个产品的出词模板，也不要默认自动套成海螺 / MiniMax H3 / Seedance / 即梦的交付管道。

适用：写或改 AI 视频提示词，尤其是近景、微表情、一镜到底、克制表演，以及多镜头接续与成片切点复核。
不适用（默认）：按某家模型官方字段、素材绑定语法、API/Context-IR 出可粘贴成片词。**例外：**用户明确要求输出 MiniMax H3 / 海螺 H3 / H3 提示词时，走第 9 节触发分支——先用本指南写表演与镜头草稿，再主动加载同级 `h3-prompt-writing` 做格式化校验；仍不把本指南本身改成 H3 字段模板。

---

## 元方法一句话

把「演技」翻译成：**时长骨架 + 每段可拍摄的身体变化 + 明确触发原因 + 镜头如何跟拍 + 全局约束块（正向定调 + 负向禁区）**。

正文写「每秒发生什么」；约束块写「整段戏长什么样、绝不能长成什么样」。两层缺一，模型容易用大哭、快切、甩手来「演悲伤」。多镜头另需在高风险接点写清上一镜结束状态与下一镜起始状态，并核对同一次动作、接触链、关键线索时长、持续感知效果与插入特写的时间关系；存在多个分镜切换时，连续三个及以上镜头不得使用同一景别；跨多段时每段只写本段事件，禁止用全局视角点名其他段内容的「不要出现」，衔接只写切出／开场状态。

## 1. 先锁镜头与时长

**有白模视频参考时，单次生成的默认建议上限为 30 秒。** 适用于把白模或导演台预演视频作为实际动态参考的提示词。按预演中的动作、表演停顿与切点选择所需时长，短段按原长生成。若目标模型或当前模式的上限更低，按其可用时长在相邻镜头切点或动作交接处分段。

- 开篇写清：总时长、画幅意图、景别、机位关系（例如「对面视角、近镜特写、一镜到底」）。
- 用时间切片当骨架（常见 2–4 秒一段），每段只推进**一点**情绪或信息，避免整段乱跳戏。
- 切片要连续（如 `0-3 → 3-6 → 6-9`），每段有独立小高潮或转折。
- 若某段承担观众必须先看清的因果线索（例如识破预兆、关键触发），为其预留足够可读时间；所需时长从冗余、重复或低信息段落挪移，不设通用固定秒数。

## 2. 写看得见的微动作，不写抽象情绪词

优先可验证的身体信号，少用「很悲伤 / 很深情 / cinematic」：

- 眼：眼眶微红、睫毛颤、泪在眶内聚起不落、泪从眼角滑
- 口：唇线绷紧、想笑未成形、抿唇、唇微颤、轻轻开口
- 呼吸与喉：呼吸很浅 / 停半秒、喉咙滚动、用力咽、鼻翼扩张
- 头肩：下巴浅点、肩膀几乎不动 / 慢慢送下、视线闪躲变专注

原则：**模型只能画/演它「看见」的过程**；形容词要落到动作上。

## 3. 因果链：看见什么 → 身体怎么反应 → 才说什么

台词是结果，不是开场白。

写法：`触发（对方的眼神/一句话）→ 身体瞬时反应 → 才开口或才点头`。

例：看见不舍 → 想扬起安抚的笑但笑意未成形 → 抿住嘴唇；听见「平安回来」 → 呼吸停半秒 → 想说「我会的」但喉咙堵住。

### 3.1 台词标点与停顿节奏

标点不仅分句，也可以提示台词的呼吸、停连和转折；但它**不是精确的语音控制指令**，不能保证模型按符号演出固定时长。重要的节奏点应同时写成可执行的声音或身体变化。

- **逗号 `，`**：语意未完的短停或换气，后半句仍接着前半句走；不必每处都补停顿说明。
- **句号 `。`**：一句话收住、一次态度落定；是否留出沉默，由场景决定，不等于必然长停。
- **省略号 `……`（或 `...`）**：迟疑、话未说尽、找词或声音渐弱拖尾。要说明具体是哪一种，不能把所有情绪都写成犹豫。
- **破折号 `——`**：突然截断、被打断或临时改口；写清中断的触发，以及原话是否继续。
- **问号 `？`、叹号 `！`**：提示语气，不自动等于升高音量、瞪眼或喊叫。克制场景仍需明确音量与力度。

写法：**台词原文 + 关键位置的停顿/重音/语速/尾音 + 对应呼吸或微动作**。不必给每个字标注，只抓会改变意思或关系的节奏点。

例：

- 「我……没事。」——“我”出口后停半秒，咽一下，再把“没事”轻轻说完，尾音压住；不是整句拖长。
- 「你早就知道，对吗？」——前半句平稳说完，短停后才问“对吗”，声音不抬高，视线仍留在对方脸上。
- 「我不是——」——对方关门的声响截断后半句；他张着嘴停住，随后合唇，不把剩下的话补完。

停顿必须有原因，如压住情绪、等对方回应、改变措辞或被外界打断；不要为了“有戏”随意断句。少用连续省略号，不把每句都写成断断续续。台词、换气、沉默和动作须共同计入该段时长；不要在很短的时间片内塞入长台词和多次长停顿。已有剧本的台词应保留原意与措辞，节奏说明放在引号外；需要改动台词内标点时，应保留其原有语义。

### 3.2 台词真实感：语气＋节奏＋状态

这是一套描述表演的元方法，不是固定情绪模板，也不保证仅靠文字就能控制生成效果。先判断人物此刻想对对方做什么，再从三个维度描述同一句话：

- **语气**：这句话如何对待对方，如催促、试探、安抚、质问、掩饰；不只写“着急”“悲伤”等情绪标签，必要时补音量、音色和用力程度。
- **节奏**：话怎样展开，如整体语速、局部抢快或放慢、重音、停顿位置与规律、句尾收住或拖尾。语速快不等于全句不停，语速慢也不等于每字等长。
- **状态**：人物说话时正在承受的身体或心理条件，如奔跑后气息不足、压住哭意、疲惫、疼痛、努力装镇定；必须落成可听见或可看见的表现。

**核心不是把三组形容词并排，而是写出“状态如何持续改变说话节奏，并使语气呈现出具体形态”。** 第 3 节写开口前的触发，本节补足开口后的持续作用：人物想怎样说，身体或心理状态怎样限制、打断或扭转这种表达。

通用写法：`台词原文＋语气/交流意图＋整体节奏＋状态对具体字句的影响`。三项是检查维度，不要求每句都写满；普通对白用最少的必要说明，关键情绪点再展开。第 3.1 节的标点用来提示这些已明确的停连，不代替表演说明。

例：

- **急着告知，但气息跟不上**：「别过去，桥断了！」语气慌急，想尽快拦住对方；整体偏快，但刚跑来的喘息打断句子，“别过去”抢着说出，随后急吸一口气，才挤出“桥断了”，停顿不均匀。快的是说话意图与局部字句，不是稳定流畅的整句播报。
- **想安抚，但哭意使声音不稳**：「我没事，你先回去。」刻意温和，前半句勉强连贯，到“你”前喉头收紧，吞咽后才把后半句放轻说完；不加哭喊，也不把每个词都切碎。
- **试探，但努力不露破绽**：「你昨晚，也在那里？」音量平常，前半句像随口一问，说到关键处短停，视线留在对方脸上等反应；问句尾音收住，不夸张扬调或配上无关喘息。

使用原则：状态要由场景支持，不凭空添加喘息、口吃或哭腔；也允许人物掩饰真实状态，但要写清“努力维持的语气”与“偶尔泄露的声音/身体信号”。不追求越破碎越真实，不让每句都叠满气声、吞咽与停顿，不强制把所有题材都处理成克制低声。声音变化与身体动作保持因果一致，台词和停顿共同服从片段时长。

## 4. 镜头语言服务情绪，不炫技

- 写清观众站在哪（对面、过肩、固定还是轻微手持呼吸感）。
- 用**几乎观察不到的推进**、推到更近特写、停在发丝/道具上再暗下等，放大脸上细节。
- 背景虚化、安静克制：把注意钉在脸上，而不是多场戏切镜。

### 4.1 镜间连续性：上一镜末状态与下一镜起状态

**每镜独立成立，不等于剪接后连贯。** 多镜头提示词除了写各镜发生什么，还应在高风险接点说明“上一镜结束在哪里，下一镜从什么状态继续”。这能减少歧义，但不能保证生成结果；不要求所有题材一镜到底或慢剪。

- **按风险锁必要状态**：人物的视线、头部朝向、双手位置及握持关系，产品朝向，物件相对位置、姿态、变形与落脚阶段，以及摄影机所在轴线一侧、运动方向和主要光源关系。只写影响衔接的项目，不死锁屏幕绝对坐标；允许景别和透视造成合理变化。
- **区分连续运镜与剪辑重构图**：需要连续拉远，就写摄影机从何处沿什么路径后退，哪些前后景逐渐进入画面，主体动作如何持续，不能只给下一镜一个宽景布局。若选择剪辑，可在同一次动作的衔接阶段切换，保持动作方向与进程可理解，而非切后重置姿态。
- **保留关键因果过程**：光或声音触发→移目→转头→抬手等反应，优先在同一镜内完整呈现；若跨镜，明确在动作进行到哪里时切出、下一镜怎样接续，不直接跳到结果态。尤其警惕相近机位、相近景别和几乎相同构图中的姿态突变；可连续拍完，或采用有叙事理由的景别、角度变化并承接动作，不机械强制角度规则，也不靠叠化、插黑掩盖状态矛盾。
- **允许合理动作省略**：无需展示每一步搬运或行走，但要交代省略了什么，使人物位置、手持物及方向变化可以理解。省略过程不等于物件无故消失、换手或瞬移。
- **验收既看整镜，也看接点**：先通过实际视频分析确认过程，再抽取切点紧邻的前后帧核对状态，必要时结合切点前后片段判断运动方向；不能仅凭相隔数秒截图或静帧证明运动连续。能够核查音频时，再检查环境声、对白及声桥是否接续。按当前环境支持的视频分析方式操作，不把静帧核查声称为观看了完整视频。
- **分析先核实，再归因**：分开陈述画面事实、剪辑判断与模型内部原因的推测。未入画不等于不存在，新景别露出的物件不等于凭空新增；透视尺寸或屏幕左右变化也不自动等于物理瞬移。区分正常硬切、跨镜状态不一致与镜内形变。证据不足就注明，不为凑预设问题数量编造断裂，也不把推测写成确定机制。

通用写法：上一镜结束时主体的位置、朝向和动作阶段；接法为连续移动、动作中接切或明确省略；下一镜从同一状态继续，并写后续变化。这是写作检查方式，不是任何模型的专用字段，也不要求把这些检查用语原样写进交付给模型的正文。

### 4.2 同一次动作阶段与同一次接触只完成一次

**姿态连续，仍可能把同一次动作又演了一遍。** 换景别、换机位时，默认承接同一动作阶段，而不是把蓄力、挥出、接触或收招重新开始。

- 只后撤一次、只挥出一次、只接触一次：若上一镜已完成蓄力或释放的某一阶段，下一镜应从该阶段继续，不得无说明地回到准备姿态再做一遍。这针对被设计为同一次的动作，不禁止剧情明确安排的多次独立动作。
- 区分「承接同一动作」与「明确重播」：蒙太奇回放、记忆闪回、刻意复述同一动作时，须在正文标明这是重播及其叙事理由；未标明则按同一次连续动作验收。
- 切点核对的不只是静止姿态，还包括动作阶段是否前进、停滞或倒退；阶段倒退而无重播说明，视为不连贯。

### 4.3 接触动作的完整因果链

对击打、推拉、碰撞、递接等接触动作，高风险接点应能核对整条链，而不是只写结果：

- **执行者**：谁在做；
- **执行端**：哪只手、哪只脚，或使用哪件工具／器械；
- **轨迹**：从何处沿什么方向运动；
- **目标部位**：准备接触哪里；
- **接触时刻**：何时真正碰上；
- **受力反应**：被接触一方如何随冲击或受力改变姿态。

切前与切后不得无说明地改换落点或目标部位。例如同一记接触不能在上一镜击中腹部／躯干，下一镜却变成击中脸部；此例仅说明落点跳变，规则适用于任意身体部位或物件接触面。中景已写出偏低或偏高的运动路径时，不能只靠特写改写落点来补救；路径可以按真实动作自然变化，但变化必须在时间和空间上可承接，不能切后换成不相容的拳路。若生成模型难以跨镜承接关键接触，优先让该次接触或释放在同一镜内完成，其他景别插在准备阶段或结果阶段等较低风险位置，但并不一刀切禁止硬切。

### 4.4 关键因果线索的可读性与时长

**镜头里出现过，不等于观众已经看懂。** 若后续反应依赖某条可见线索（识破预兆、发现物件异动、捕捉眼神变化等），须让观众有时间依次完成：看清变化 → 认出含义 → 理解随后反应。

- 为该线索分配足够可读时长；具体长短随信息密度与景别而定，不设通用固定秒数。
- 延长关键线索时，从冗余、重复或低信息段落挪移时间预算，而不是继续挤压其他必要过程。
- 只闪过一帧的关键预兆，即使后文写了“已经识破”，仍视为传达失败风险，应在文本阶段改时长或改写法。

### 4.5 持续感知效果的生命周期

耳鸣、听觉变闷、短暂眩晕、视线发糊、心跳盖过环境声等跨镜持续的主观或客观感知效果，应写出完整生命周期：

- **触发**：由什么事件开始（如受击、爆炸、情绪冲击）；
- **持续**：跨越哪些镜头仍存在，强度如何变化；
- **退出**：何时、因何减弱或消失；若片段结束时仍在持续，应明确保留，不强行安排消退。

跨镜时效果状态须前后一致：前文已建立的耳鸣，后文才能写消退；不能无触发地突然出现，也不能无退出地凭空消失。主观声音变化不等于现实环境被静音；环境声可变闷、被压低或被主观声覆盖，但要与画面事件和镜头衔接相符。耳鸣只是常见例子，同类持续光晕、残响、疼痛感等同样适用。

### 4.6 插入特写时的叙事时间与现实时间

插入眼睛、肩膀、手部、物件等特写时，须说明这段特写在时间上如何相对于主动作存在：

- **同一瞬间的主观展开**：特写放大观察，主动作在现实中几乎不推进；返回主镜头时应承接切入前的动作阶段，主体不能无故暂停等待观察结束。
- **实际时间继续推进**：特写期间主动作仍在进行；返回时必须接上已经前进后的阶段，而不是回到旧姿态。

不强制所有镜头使用慢动作，也不靠无意义地拉长蓄力来“等特写拍完”。若模型难以在硬切后正确承接高风险释放或接触，优先把该关键瞬间放在同一镜内完成；准备、观察与结果阶段仍可合理分镜，但不把“禁止硬切”写成绝对规则。

### 4.7 Review 硬性门槛：不连贯即不通过

连续性不是加分项，而是能否通过 Review 的硬性门槛。本技能提供人工与辅助复核的写法与验收标准，**不承诺**任何自动检测器都能可靠识别全部问题。

**文本阶段（出词或改词后、生成前）**必须检查：

- 跨镜动作阶段是否只完成一次，有无无说明重置或重演；
- 姿态、握持、朝向与物件状态是否承接；
- 接触链（执行者、执行端、轨迹、目标部位、接触时刻、受力反应）是否前后一致；
- 关键因果线索是否有足够可读时间；
- 插入特写与主动作的时间关系是否写清；
- 持续声音或视觉感知效果是否具备触发、持续与退出，或已交代片尾仍持续；
- 跨多段提示词时，是否禁止了「全局视角」负面列举：本段原本就不会出现的人物、道具、卖点或情节，不得写「某某不出现／不要演示某某」；仅允许段末切出状态与下一段开场已成立状态帮助衔接（见第 4.8 节）。**未遵守此项，文本阶段直接不通过。**
- 若提示词存在多个分镜切换，是否每镜都写明了景别，且按剪辑顺序连续三个及以上镜头没有使用同一景别（见第 4.9 节）。**未遵守此项，文本阶段直接不通过。**

文本未写清上述适用的高风险项，或违反第 4.8 节跨段全局视角禁令，或违反第 4.9 节连续同景别禁令，不得判定“文本通过”；应先修改，再安排生成。

**成片阶段（已生成视频后）**必须实际查看视频过程与切点前后，不能只凭稀疏截图、观感或单一静帧宣布通过。若确认出现下列情形，**直接不通过**：

- 同一次动作被无说明地重演；
- 姿态或动作阶段无交代地重置；
- 接触轨迹或落点在切后出现不相容的变化；
- 关键线索不可读却假定人物或观众已经领会；
- 持续感知效果缺失触发、跨镜矛盾或无交代地消失；
- 插入特写导致主体像在等待，或返回主镜头时时间关系混乱。
- 存在多个分镜切换时，连续三个及以上镜头为同一景别。

不通过时须列出具体缺陷 → 修改提示词、剪辑或重生成对应段落 → 重新 Review。画面漂亮、特效华丽、单镜表演出色，**不能抵消**连贯性失败。

**不得误判为穿帮的情况**：正常硬切；已交代的合理动作省略；景别或透视造成的合理尺寸与左右变化；正文已标明且成片能被识别为重播、回忆或蒙太奇复述的段落。不能只因文本有解释就忽略成片的实际传达失败。

**证据不足时标为待核实，不可宣称通过。** 文本阶段通过，只说明提示词接续写清楚了；**不等于**成片通过。未实际分析视频过程与切点，不得声称成片已验收；无法核查声音时应单独标明音频待核实。

### 4.8 跨多段提示词：禁止全局视角负面列举

**每段只写本段要发生的事。** 当一份交付拆成多段独立（或可硬切相接）的提示词时，禁止用「全局视角」去预告或否定下一段／其他段才会出现的道具、人物、卖点或情节。

- **禁止**：本段原本就不会出现的内容，用「某某不出现」「不要演示某某」「不要出现某某」去点名。例如第一段只做降噪，就不必写「阿凯不出现」「EQ 与 USB-DAC 不出现」——那属于跨段全局视角，不是本段约束。
- **默认**：本段未写到的人物、道具、功能，默认不出现；不必额外负面列举。
- **允许且建议**：为跨段衔接丝滑，可在**本段段末**写清切出状态（位置、朝向、握持、已成立的感知效果等），或在**下一段开场**写清已成立的起始状态；写的是本段／本段开场看得见的状态，不是「别段不要出现什么」。
- **与第 5 节区分**：第 5 节「全局约束块」管的是**本段**影像气质与可观察表演禁区（夸张哭喊、快切等）；本节管的是跨多段时不要用上帝视角点名其他段的内容。两者不要混用：本段约束块可以禁止夸张哭喊；不可以因为下一段才有某人，就在本段写「某人不出现」。

**文本 Review 硬门槛：** 多段稿中若出现上述全局视角负面列举，**直接不通过**；删改后再判通过。此项列入第 4.7 节文本阶段检查，不得凭审美放过。

### 4.9 多镜切换的景别硬性门槛：连续三个及以上不得同景别

**仅当提示词中存在多个分镜切换时生效。** 一镜到底、单镜内推拉造成的景别变化，或不构成「连续三个镜头」的切镜次数，不按本条处罚。

切镜后的每一镜都必须写明景别。按剪辑顺序排列各镜景别后检查：

- **连续三个及以上镜头不得使用同一景别。** 例如连续三个「近景」，或连续四个「中景」，文本阶段即不通过。最多允许相邻两镜同景别，第三镜必须换成不同景别。
- 判断依据是提示词里写出的景别类别（如大远景、远景、全景、中全景、中景、中近景、近景、特写、大特写），不是构图微调。同一类别的程度差（「近景」与「近景稍紧」、「中景」与「中景略宽」）仍视为同一景别。
- 单镜内的推、拉、跟造成景别变化，只计该镜一次（写本镜主导景别或起始景别即可），不把运镜过程拆成多次切镜来规避或误伤。
- 未写景别的分镜无法验收，须补写后再检查，不得跳过本条。

文本未通过时，先改切点或改景别再交付，不得以「情绪需要一直近」为由保留连续三镜及以上的同一景别。本条是出词硬性门槛，不替代第 4.1–4.7 节的状态与接触链检查，也不与第 4.8 节混用。

## 5. 全局约束块：正向定调 + 负向禁区

单独写一段「画面风格 / 避免」（或等价标题），与分秒正文并列。它是**全局滤镜**，不是又一段剧情。

### 5.1 正向：锁审美通道 + 表演通道

- **影像气质**：电影感、浅景深、柔和侧光/自然光、背景虚化等 → 规定光线与焦点，把注意钉在脸上。
- **题材气氛**：一句话定调（如古装别离），不讲完整故事。
- **表演带宽**：写「克制细腻」，并**点名本段要抓的微部位清单**（眼神、呼吸、唇颤、眉心松紧、鼻翼、吞咽停顿、眼泪滑落过程……）。这等于规定：细节预算花在这些通道上，与第 2 节的分秒描写对齐。

### 5.2 负向：封死常见翻车（必须可观察）

每条禁止项都要能在成片里一眼验出来，并保护时间轴上的微表演：

| 禁区 | 保护什么 |
|---|---|
| 不要夸张哭喊 | 挡情绪过载 |
| 不要快速剪辑 | 保一镜到底 / 慢节奏 |
| 不要大幅度肢体动作 | 保近景微表演 |
| 不要台词过多 | 台词让位于表情 |
| 不要表情突变 | 强迫按时间轴渐变，禁止跳切情绪 |

以上是按题材选择的示例，不是所有视频通用的禁剪辑或微动作限制；多镜头作品按第 4.1–4.9 节检查接续、跨段视角、连续景别与 Review 门槛。

再补强度下限表述更好：点头很浅、笑很浅、呼吸浅、肩膀几乎不动；「含泪望着」优于「泪如雨下」。

禁止空喊「高质量 / 精美 / masterpiece」。

### 5.3 与正文的分工

- 约束块 = 整段戏的滤镜与禁区（写一次即可，通常放开头或结尾）。
- 时间轴正文 = 每秒的触发、身体变化、台词。
- 正向清单里的「通道」应在正文里真正出现；负向禁区应能解释正文为什么写得那么「浅」。

### 5.4 约束块示意结构

```
画面风格：[影像气质]，[题材气氛]，表演克制细腻，重点呈现[微部位清单]。
避免：不要[可观察禁区1]，不要[禁区2]，……
```

## 6. 内外视角叠写（可选但有用）

在微动作旁补一句**意图方向**，避免随机抽搐：

- 外：他盯着对方的脸几秒
- 内：像要把这个人记住，带到路上

意图用短句点到为止，仍以可见动作为主。

## 7. 成稿形态

- 优先**连贯中文段落**（可按秒分段），不要只堆标签列表。
- 一段提示词 ideally **一件主事件**；多场戏拆条，不要预告片式塞满。
- 对白保留原文语气与音量约束（轻、哑、尾音微颤但努力平稳）；按第 3.1 节用标点提示停连，关键节奏配合呼吸、微动作与声音说明。
- 引用参考资产时，先按第7.1节在「引用资产」处为每个资产定义 `[别名]`，再写规格、约束与分秒正文；用户指定的固定开头语保留在最前面。
- 多镜头正文在高风险接点写明上一镜如何结束、下一镜如何继续，明确连续运镜、动作中接切或合理动作省略，不只笼统要求“保持连贯”。
- 涉及同一次击打、递接、碰撞等时，还须写清动作阶段不重演、接触链一致、关键线索可读、持续感知效果的起止，以及插入特写是主观展开还是时间推进；这些是检查要求，不必把内部检查用语当作模型字段塞进正文。
- 若提示词中有多个分镜切换，每镜写明景别，并保证按剪辑顺序连续三个及以上镜头不使用同一景别（第 4.9 节）。
- **默认成稿**仍是本指南的连贯段落 + 约束块。仅当用户明确要求 MiniMax H3 交付时，才在指南草稿通过后按第 9 节交给 `h3-prompt-writing` 格式化为对应模式字段；不要在未触发时预填 `integrated_multimodal_description` 等产品字段。

### 7.1 资产引用与方括号别名

凡提示词引用人物、场景、道具、风格图、首帧或切后参考图，都须在该段的「引用资产」处，将实际素材文件或上传标签与唯一的 `[别名]` 对应，并说明引用用途。例如：「图片1（角色正面.png）定义为[舰长]，锁定面孔与制服；图片2（驾驶舱.png）定义为[驾驶舱]，锁定空间与固定设备。」后续正文通过 `[舰长]`、`[驾驶舱]` 指代已绑定资产，不混用裸编号、文件名、角色姓名或未定义的称呼。指代清楚的「她」「他」「它」可以保留，原对白及画面内原有文字不因别名规则而改写。

每段独立生成的提示词都应完整定义本段所用别名，不能只依赖文档前面的资产总表。一个别名对应一个资产；该资产已有多角度参考时，必须先逐一引用其全部当前有效角度的实际文件或上传标签、标明各自视角，再将这一组素材共同定义为一个 `[别名]`，不能先定义别名再零散补图，也不能只列正面而漏掉现有侧面和背面。面部或局部细节参考也应随所属资产一并列出，并说明只约束哪些细节。不把历史废稿、相同角度的旧版本或其他剧情状态当作缺漏角度混入。单图资产直接定义，不虚构尚未制作的角度。

同一资产跨段沿用同一别名；同一人物的身份基准与伤态图使用不同别名，并写清伤态图的生效时间，正文中的人物身份仍指向同一角色。某状态尚无侧背视时，须明确缺项，不能借用另一伤态的侧背视冒充。首帧与切后图分别命名，不互换职责。无资产输入的纯文字提示词不编造素材或别名。方括号是本文的引用约定，不自动等于某家模型的素材绑定语法；进入明确指定的产品分支时，须保持与该产品正式标签的对应关系，并如实核查素材数量上限，不静默漏列角度。

## 8. 自检清单

写完后逐条问：

1. 时长与切片是否连续、每段是否只推进一步？承担关键因果线索的段落是否另有足够可读时间，且从冗余处挪移而非硬塞？
2. 情绪是否都落成可拍的脸/呼吸/嘴唇/肩动作？
3. 每句台词前是否有可见触发与身体反应？
4. 镜头是否说明了与人物的关系，并服务微表情？
5. 是否有独立的全局约束块：正向（气质 + 微部位通道）+ 负向（可观察禁区）？
6. 正向通道是否在正文里兑现？负向是否挡住所选题材不需要的夸张哭喊、快切、大动作、过多台词或表情突变，而非机械禁止它们？
7. 是否误写成某家产品的专用字段模板？默认不要求那些字段。若用户明确要求 MiniMax H3，是否已先完成指南草稿，再按第 9 节调用 `h3-prompt-writing` 格式化与校验，而不是跳过草稿直接套字段？
8. 台词标点是否符合语意与人物状态？关键停顿是否有触发、有可执行的表演说明，且连同台词和动作能装进该段时长？是否滥用省略号或把问号、叹号误写成喊叫？
9. 关键对白是否明确语气、节奏与状态之间的关系，尤其是状态如何影响说话过程？这些表现是否有场景依据，而非机械叠加喘息、哭腔或碎句？
10. 高风险接点是否写清上一镜结束与下一镜起始的必要状态，并允许合理透视变化，而非死锁屏幕坐标？
11. 连续拉远是否有实际摄影机路径和逐步显露过程？采用剪辑时，动作方向、阶段与物件状态是否接续？
12. 关键触发与人物反应是否完整呈现？相近机位硬切有无姿态突变？动作省略是否仍让位置、方向和握持变化可以理解？
13. 同一次动作的蓄力、释放或接触是否只完成一次？换景别后有无无说明的重置或重演？若为重播、回忆或蒙太奇，是否已在正文标明，成片是否能传达这一时间关系？
14. 接触动作的执行者、执行端、轨迹、目标部位、接触时刻与受力反应是否前后一致？切前切后有无改换落点？
15. 关键因果线索是否不仅“出现过”，而且时长足以让人看清变化、认出含义并理解随后反应？
16. 耳鸣、闷听、眩晕、视线发糊等持续感知效果是否写清触发、跨镜持续与退出，或已交代片尾仍持续？主观声音变化是否被误写成现实静音？
17. 插入特写时，写清的是同一瞬间主观展开，还是现实时间继续推进？返回主镜头时，主体是否像在无故等待，或动作阶段是否错位？
18. 如模型难以承接高风险接触或释放，是否优先安排在同镜完成，并把其他分镜放在准备或结果等较低风险位置，而非一刀切禁止硬切或单靠拖长蓄力？
19. 文本 Review 是否已按第 4.7、4.8、4.9 节检查动作、状态、接触链、线索可读性、时间关系、持续感知效果、跨多段时有无全局视角负面列举，以及多镜切换时有无连续三个及以上同一景别？未通过项是否已列出并修改，而非凭审美放过？
20. 如已生成成片，是否实际检查视频过程与切点前后，并按需核查可听音频？动作重演、无交代重置、落点变化等不连贯是否直接判不通过并复审？是否误把正常硬切、合理省略／透视或明确重播当成穿帮？证据不足是否标为待核实而非宣称通过？是否误把文本通过当成成片通过？
21. 分析是否区分事实、剪辑判断与原因推测，避免把未入画、透视变化或正常硬切误判为新增、瞬移或状态断裂，并明确证据不足之处？是否避免承诺自动检测器必能发现全部问题？
22. 跨多段时，各段是否只写本段事件，没有用全局视角点名其他段才会出现的人物／道具／卖点并写「不要出现」？段末／段首衔接是否只写切出／开场可见状态以利丝滑，而非跨段负面预告？（见第 4.8、4.7 节）
23. 若提示词存在多个分镜切换，是否每镜都写明了景别，且按剪辑顺序连续三个及以上镜头没有使用同一景别？未写景别是否已补写后再检？（见第 4.9 节）
24. 每段「引用资产」是否先列出同一资产全部当前有效角度的实际文件或上传标签及视角，再共同定义唯一的 `[别名]` 并说明用途？是否漏列侧背视或局部细节图，或者混入旧版、其他伤态？正文是否统一通过已定义的 `[别名]` 指代资产，且没有裸编号、未定义或一个别名混指不同资产的引用？跨段别名是否一致，身份图与伤态图、首帧与切后图的职责及生效时间是否清楚？未制作的角度是否如实注明，原对白是否保持原文？发现不一致时应先修正再交付。（见第7.1节）


## 9. 产品触发分支：MiniMax H3

**默认关闭。** 只有用户明确要求输出 MiniMax H3 / 海螺 H3 / H3 提示词（含 T2VA、I2VA、FL2VA、L2VA、Ref2VA / 全能参考等）时才进入本分支。未点名产品时，本指南仍只交付书写参考稿，不自动套 H3 字段。

### 9.1 触发与不触发

- **触发：**用户明确说要 MiniMax H3、海螺 H3、H3 提示词、H3 可贴入结构，或指定上述输入模式之一。
- **不触发：**只说「写提示词 / 改表演 / 盲评写法」而未点名 H3；Seedance / 即梦等其他产品也不走本分支。

### 9.2 固定流程（必须按序）

1. **指南草稿**：按第 1–8 节写出表演、镜头、时长、约束与连续性都到位的草稿（可仍是中文连贯段落）。
2. **主动加载**同目录旁的 `h3-prompt-writing` 技能并遵循其 Workflow（Obsidian 路径：`.agents/skills/h3-prompt-writing/`，与本技能同级）。不要把该技能的长模板全文并入本指南。
3. **格式化**：按请求模式映射到 T2VA / I2VA / FL2VA / L2VA / Ref2VA；读取其 `references/base-en.txt` 或 `references/ref-en.txt`，保留官方字段名、节序、标签与时长记法。
4. **校验**：核对字段齐全与顺序、参考标签一致、总时长与描述匹配（H3 常见 4–15 秒整数）、对白/可见文字原语种保留；缺少表演细节时**回到本指南补写草稿**，再重新格式化，禁止为凑字段删掉可见微动作与因果。
5. **交付**：输出 H3 可贴入结果；同时可附一句说明：表演写法来自本指南，产品骨架来自 `h3-prompt-writing`。

### 9.3 边界

- 本分支只做「指南内容 → H3 结构」的格式化校验，不替代产品官方手册里的素材绑定上限、上传顺序或平台 UI 操作说明。
- 不要在本指南正文内嵌整份 H3 英文模板；需要细则时打开 `h3-prompt-writing` 及其 `references/`。
- Seedance 或其他产品若需类似分支，另立触发条件；不可与 H3 语法混用。

| 他很伤心地说再见 | 眼眶微红，唇线绷紧、声音很轻：「等我。」 |
| 气氛感人 | 背景虚化，对面近景，轻微手持呼吸感 |
| 然后哭了 | 泪盈满眶但不擦；笑意刚上嘴角时一滴泪滑落 |
| 他下定决心 | 眉心一点点松开，目光从闪躲变专注 |
| 「我……没事……」但没有表演说明 | 「我……没事。」“我”出口后停半秒，咽一下，再轻轻说完“没事”，尾音压住 |
| 高质量、感人、cinematic | 电影感，浅景深，柔和侧光；重点呈现眼神与呼吸；不要夸张哭喊、不要快速剪辑 |
| 保持动作连贯 | 上一镜右肩已后撤到位；下一镜直接从此姿势转体送出，不先收回再重新蓄力 |
| 特写击中面部 | 中景与特写共用同一运动路径与同一目标部位；切在即将接触时，特写承接同一接触，不改落点 |
| 他识破了预兆 | 先用足够时长看清肩线后撤，再写眼神收紧与随后闪避，而不是预兆一闪而过 |
| 耳鸣渐渐消失 | 先写受击后耳鸣响起并跨过后续镜头，再写其减弱；消退前环境声仍偏闷 |
| 插眼部与肩部特写后继续出拳 | 写明特写是同一瞬间的主观展开；回到双人镜时从已蓄满的姿势直接释放，主体不等待 |
| 连续三镜都是近景 | 至多两镜同景别，第三镜须换成中景、特写或其他不同景别 |

## 使用方式

需要更细的表演戏时：先定时长与镜头 → 写全局约束块（正向通道 + 负向禁区）→ 再按秒填微动作与因果，有对白时补关键停连与声音节奏。多镜头增加接点状态、同次动作不重演、接触链、关键线索时长、持续感知效果与特写时间关系检查；存在多个分镜切换时，按第 4.9 节检查不得连续三个及以上同一景别；跨多段时禁止全局视角负面列举，仅用段末／段首状态帮助衔接；文本 Review 通过后再生成。已有成片则按第 4.7 节做过程与切点复核，不连贯即不通过并复审。把本文件当检查表与写法参考即可。

**默认**不自动套产品字段。用户**明确要求 MiniMax H3**时：完成上述指南草稿后，按第 9 节主动加载并遵循同级 `h3-prompt-writing`，再交付格式化校验后的 H3 结果。其他生成器的粘贴语法与绑图规则仍以该产品文档为准。
