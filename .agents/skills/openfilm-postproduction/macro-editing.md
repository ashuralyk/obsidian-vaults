# 全片组接与转场

## 先写出全片怎样成立

观众在场与场之间会带走一个问题、上一个动作的后果、尚未消化的感受，或对另一个人物处境的期待。下一段的开头接住其中一项，再改变它。当这种交接在全片持续时，时间可以跳，空间可以换，切口也可以明显，观众仍能跟上。

全片从谁的处境进入，观众一直在等什么，结尾有什么可见或可听的变化？用一句完整的话写出来，再并排看开头和结尾。开场交代关系或状态，结尾靠事件之后的一个行动、声音或选择让变化可见。开放结局可以留下问题，同时交代人物此刻已经站到了哪里。群像、纪录、多线叙事可以各有入口，但要知道哪一个问题将两条线拉在一起，以及回到每条线时观众怎样重新认路。依据见 [[脊梁贯穿全片，转变由事件推动]]、[[知情差安排揭示与隐藏]] 和 [[开场和终场要互为变化证据]]。

## 用段落剪一遍，再用镜头剪一遍

沿粗剪按**戏剧变化**划段。同一场景可能包含几个段落，一段也可以跨好几个地点。每段写一句变化、一个银幕证据、一个实测时长。重点补两栏：观众进来时在等什么，离开时带走什么。重要的揭示还要写人物和观众各在哪一段知道。用段落卡或 [记录模板](templates.md) 比较，先从全片自然速度播放中选定具体问题。

把相邻段落接成一句话，用下面四种关系检验交接。

- **后果。** 因为上一段发生了某件事，人物接下来必须应对，或者遭遇新的阻力。省略走路和交代，只要下一段还看得见那个后果。
- **追问。** 上一段提出一个观众已经在意的问题，下一段给答案的一部分、增加障碍，或推迟回答。观众仍应记得自己在等什么。
- **反应。** 危险、决定或揭示先发生，再让人物用一个动作、沉默或在途过程消化。缺了一次对观众很重要的反应，可以从原素材找回，不必用说明台词加速。
- **并置。** 两条线可以对照或相撞。先让两段各自可读，并保证并置会让观众改读前一件事。交叉剪辑时，让每次回到一条线都有新压力、新进展或同一问题的新角度。先约定观众应该读为同时、相遇、因果或主题对照。若要感到两条路线即将会合，找双方经过的同一地标、共有声音事件或已有可靠的时间锚。若只需对照，检查相似构图或共有音乐有没有让人误以为同地同时。见 [[剪辑交替需要交代两条线之间的关系]]。

有些段落只需要交代时间流逝、给观众恢复注意力，或完成从故事到片尾的离场。它们都有工作可做。当一段可以随意和别段互换位置，检查它是否承担实际的铺垫、呼应或后果。把重复功能合并，把决定之前的必要压力和决定之后的反应留下。在用户允许的剪辑范围内试段落顺序、时空省略和长短；涉及改写已定因果、人物选择、视点或揭示顺序时按已授权范围处理。见 [[过渡场类型拼成全片节奏曲线]]、[[节奏是把篇幅分给故事重点]]、[[重大情节后交通场承载反应]]。

## 分配全片的强弱和呼吸

用实测时长排一条线，标出观众获得的关键信息、人物受到的压力和反应时间。再选对项目真正重要的一两种画面或声音变量检查贯穿关系，例如画幅里的空间收紧、镜头运动密度、环境声的远近或配乐是否占前景。此前一直相似的东西，可在转折处有意改变。若每段都用相似的镜长、高对比和强配乐，峰值就缺少可觉察的变化。

重点看开场如何提出问题、主要转折如何改变路线、高潮后有没有时间感到后果，以及最后用什么让观众离开。强段之后可以留在演员的呼吸里，也可以借一段行走或距离变化给反应时间；必要的安静不一定要加镜头。若发现一段“拖”，找观众何时已经懂了却没有下一步。若发现一段“赶”，找他们丢的是空间、因果，还是消化的时间。检查能否从看向目标直接切到目标处，并保留起因与结果。线索尚未读清时，另一角度可以重带一小段动作；延长等待时，要继续发生可感知的压力、认识或情绪变化。见 [[电影时间随观众的推断与等待伸缩]]。用 [[六种必查的场景转换接口]]、[[转换低潮靠景物与机位距离]]、[[对比与相似调节视觉强度]] 和 [[停顿与留白是表演的时间预算]] 辅助判断。接口以本片的实际变化为准。

看片时先比较全片强弱，再检查段内快慢。把一场戏分别试成提早进入冲突、晚一点离开反应，或删去两者之间重复的动作或说明。关键段落可以试听只有原声的版本，分清拖慢感来自镜头持续时间、信息重复、音乐节拍，还是音效事件密度。切得更密并不保证压力更大，适时留在一个镜头里也会让压力累积。对照片中实测时长和 [[视觉成分要随故事曲线组织]]，保留能在正常速度下看出强弱变化的剪法。

## 场界先试硬切，再决定声音和画面怎样接

为重要场界一起看 **A 段最后被观众读到的东西、B 段第一个能辨识的东西**，再单独标声音起止。写清相接理由是行动、画面位置、形状、概念或声音，再试硬切、叠化、场内遮幅或淡黑等呈现形式。切口涉及两个高对比前景、脸或字幕时，特别看效果的中间状态。《剪辑的语法》第二版图 5.6 里叠在一起的两幅过肩镜会增加读图干扰。先用硬切和自然声试这对首尾。能读到「为什么来这里」，说明戏本身已经接住。接下来根据希望观众获得的体验调整连接方式。

| 希望观众怎样进入下一段 | 可以试的做法与验收 |
|---|---|
| 立即读懂后果，或感到世界突然改变。 | 试硬切或声音也在同一点断开。检查新场的第一项证据能不能迅速安置观众。 |
| 先预感下一个空间、人物或事件。 | 试让有辨识度的声音提前进入，或把上一段的问题留到下一段。检查预告是否抢先透露原本要晚一点才知道的内容。 |
| 先消化刚才发生的事，再注意新画面。 | 试多留一拍反应，或让上一段的台词、底声、音乐尾音越过切口。问残留声音使下一段被读成了什么。 |
| 跨越一段时间，同时保留同一意图。 | 试省略中间过程，用未完成动作、相似构图、持续音乐或同一主题的变奏接起。用明确的变化证据交代时空，避免观众把两个地点认成同一处。 |
| 让观众换一个角度认识刚才的事。 | 试把有因果或对照关系的两个片段直接并置，或先撤音乐让一个环境声接手。检查观众有没有得到预期的对照。 |

跨场使用持续音乐时，检查它带过来的是哪种情绪、何时应放下，以及是否提前替下一场定性。可比较音乐在切口之前收住、越过切口再退，以及这一处留无乐。关键台词、声音的空间归属和下一场的第一声仍要清楚。见 [[场景转换是事件的内化]]、[[分镜须成对设计场景首尾帧]]、[[钩子与匹配镜头绑住相邻场景]]、[[声音可以先于画面发动切换]]、[[声音把切开的画面连成一条流]] 和 [[音乐在转换线转化情绪]]。

### 选择转场手法时，说明希望发生的变化

- **硬切和跳过中间过程**适合后果直接可见的连接。下一场的首个动作或反应可以直接交代变化。若需要人物先作出关键决定，要给观众保留获得这项证据的机会。
- **J-cut 与 L-cut**分别把下一段的声音提早、把上一段的声音留晚。可以用来预告一个地方、保持对白的语气、延续余波。先标清声源，再标声音与画面各自的起止。抢先透露关键信息或者让观众认错声源时重新调整。
- **动作、构图或音色匹配**可以让观众携带一种节律、形状或动势跨越场界。若下一段已经换时空，给一项可辨认的变化，让观众既感到关联也知道已经换场。
- **叠化、淡出、黑场**可用于需要感到共存、消退、时间流逝或段落关门的位置。用去掉效果的版本检查底层关系，并实际看重叠处是否遮住了应当清楚的动作、脸或字幕。
- **交叉剪辑或蒙太奇省略**可让两条线汇合，也可把长过程收成几个变化节点。回到其中一条线时迅速给定位线索，并让每次回切都推动原有问题。音乐可以联结整段，事件的推进要能在画面和声音里读出来。剪蒙太奇时先用少数片段证明开头与结尾的状态确实不同，再让音乐乐句给转折和落点腾出时间。见 [[蒙太奇靠头尾状态变化压缩过程]]。

### 空镜分别承担定位、余波和时间

进入新空间时，先看人物的行动镜头能不能顺带交代地点。若下一步需要观众弄清入口、路线、距离或时间，空镜可以给一项明确证据。重要事件之后，空镜也可以给观众消化的时间，例如在人物离开后留在原地，听见脚步走远，下一场再进入。若要表现时间流逝或人物缺席，选有变化依据的景物或反复出现的地点，让观众发现灯、声音、人流或已建立的物件状态发生了变化。

空镜的长度由它的职务决定。用到几秒才认清空间，就留到观众读懂；用于余波，就听到底声或余音在何时转给下一段。把无空镜、短空镜和留长一点的版本连着上下段比较。人物出画后若要继续动势，优先在画面动势消失前切走；有意留下无人画面时，确认停留本身交出了具体的时间、地点或情绪后果。如果缺的是角色意识到一件事的可见反应，优先试原镜或听者镜头。空镜能否提供相应证据需要实际试看。参考 [[地点可以在故事点里被带出来]]、[[转换低潮靠景物与机位距离]] 与 [[相邻场所对立强化场间能量]]；仍有缺镜就做 [补镜头诊断](pickup-shots.md)。

## 在 OpenFilm 里验证段落关系

粗剪先保留可恢复版本，在同一画幅、帧率和片长目标下比较整段。为关键切换记录成片位置和两个片段 ID。测试时从前段的问题出现处开始，播放到后段的首个反应或后果结束，给观众足够的语境。一次只改影响最大的条件，例如调整段落顺序、前场多留一次反应，或固定画面只改声音先入。画面挪动时，对照同一事件重新核对对白、底声、字幕、拟音和 cue。接触表可定位 A 末和 B 首，段落连贯性要连续播放才看得出来。

从头看一遍时，先问「观众什么时候明白发生了什么」「哪个转场把注意力交得太早或太晚」「结尾能不能用一项具体变化回看开场」。若卡住，先提出一个可试的原因。例如观众以为两段无关，先去找前面有没有交出后段需要的动机；观众说句子很多，先查重复解释，或刚出现一次变化就被切走的地方。修改后把前后段放在一起复看，如实记录保住了什么、失去了什么。全片关系成立之后再处理逐刀精度和过渡质地。焦点仍可回到 [[试映的疼点不等于病灶]]。

## 一个从开场接到结尾的例子

把语音消息这个小场景放进四段结构。开场，女孩收到面试落选的通知，手机上一条母亲问近况的消息还没回。下一段，她在走廊录下“挺顺利的”。此时上一段带来的问题已经从「有没有录取」换成「她会不会说实话」。第三段，母亲回语音说“给你留了饭，回来热一下”。把这一句留完整，给女孩一个不必继续解释的机会。最后一段，再给她一次按住录音键的动作。这次她说“妈，我没过”。开头与结尾回到同一件事，观众听见她如何采取了不同的做法。

一处可以直接硬切，从确认落选切到她对着手机说“挺顺利的”，前后事实的落差足以传递冲击。另一处可以为母亲的回应试两版。上一段末尾先听见语音，再切到女孩在听，观众会被声音带进下一段。先切到她握着手机等回复，过一拍才响，则能保留她等候的感受。两版都应让声源清楚，并给她听完后的决定留时间。整片再看时，开场的落选证据、走廊里那句掩饰、母亲的回应以及重新录音须能解释彼此。只要这条因果和反应读得出来，大部分场界可以直接切。
