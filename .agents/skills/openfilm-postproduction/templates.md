# 记录模板与实例

记录用项目现有格式。新项目可把以下字段合并为一份剪辑记录。交付前保留实际采用的版本、素材与时间定位；表中“待验证”要对应一次实际看片或一个明确缺件。

## 版本、素材和剪接

在版本开头说明本片的输出用途、剧本和分镜版本、当前 OpenFilm 工程、工作帧率与画幅、已同意的成片时长、实测时长和本轮改动范围。有交付标准时注明响度、字幕和音轨要求。再用一句话说清观众在哪个时刻应该理解哪个决定。

| 需要回查的记录 | 最少要写什么 |
|---|---|
| 素材与拍次 | 写素材稳定 ID、镜号、源文件、拍次或生成版本、同步声、源入出和可用余量，说明该素材能交出的动作或反应、声音与画面问题，以及采用或备选的理由。 |
| 场景与实际时长 | 写该场前后的关系、目标或信息变化，说明主镜、必要覆盖、留给反应的时间和实测时长。 |
| 关键剪口 | 写成片帧或时间码、出入片段 ID、此时离开的理由、连接方式及新信息；画面或声音有意错开时记各自起止。 |
| 场界或峰值 | 对照 A 末与 B 初，写观众要延续或放下的情绪、首个可辨识线索及声音交接。 |
| 版本变化 | 写旧版与新版、旧范围与新范围、操作和累计时移、受影响轨道与复验结果。等长换镜另记需重对的镜内事件。 |

如果声音或字幕已经按一版画面开工，记录参考版、共同起点、帧率、全片时长和已知占位。试映反馈标出观众首次反应的位置，另记事后意见。带着前后因果复看，再把可能病因变成下一轮可比较的编辑。

## 全片组接与主要场界

粗剪完成后先从头播放。短片逐段填写，较长的片子优先记会改变观众理解的几个段落。可以与上面的时长和场界表合用。

| 段落与时间 | 观众进来时在等什么 | 本段改变了什么，证据在哪里 | 出去时带着什么进入下一段 | 实际时长及强弱变化 |
|---|---|---|---|---|
| 写起止时间或片段 ID。 | 写主要问题或上一段的后果。 | 写具体行动、反应、声音或信息。 | 写尚未解决的问题、必须应对的后果、需要消化的感受或有意断开的方向。 | 写实测秒数及这一段如何蓄力、抬升、释放或收束。 |

主要场界另记「A 末的最后可读事件 → B 初的第一项可辨证据」。要调整声音时写声音开始、结束和所属空间。并排检查一条最新工作版本和一条对照版本，记录全段看过后保留的是哪个连接，以及观众在哪个时间读懂它。

## 补镜头清单

| 片中位置与前后片段 | 缺少的证据与观众读法 | 现有素材试过什么 | 结论与所需画面 | 时长、接点与复验 |
|---|---|---|---|---|
| 写版本、场次和时间码，注明前后片段 ID。 | 写观众何时误读或来不及感受，以及此处必须看见或听见的具体事件。 | 写实际回看与贴片比较过的拍次、源区间、持镜或声音做法及结果。 | 写必补、可选或已有方案，并说明视点、动作、起止状态、方向和需要匹配的连续性。 | 分写预计入片时长与采集余量，记声音锚点、采用的素材，以及放入或拿掉后观众读法怎样改变。 |

同一片子没有发现必须补的镜头时，记下实际检查过的重点段落和现有解法即可。只在补拍、补生成或交接需要时细化制作字段。

## 配乐点与音频交付

| 字段 | 写法 |
|---|---|
| Cue、画面版本与主题 | 使用稳定的编号，同时记录音源文件、版本、主要主题素材及角色能否听见。 |
| 起止与段内变化 | 各写时间与银幕事件。必要时同时记从 cue 起算的相对时值，并单列尾音结束。 |
| 戏剧任务与听觉前景 | 用完整一句话说明观众何时感到什么，以及此处应听清的台词或声音。 |
| 试听与定稿 | 记录试用方案、有效变化、终混采用的素材与位置、各路是否可独立调整和权限范围。 |

## 审片记录

每个问题至少写「时间码或片段 ID → 实际观察 → 原因判断 → 具体改动 → 复看结论」。先做全片自然速度观看，再分别核对片段。下列项目只留适用的，失败的必须能定位。

| 核验项 | 通过的证据 |
|---|---|
| 叙事与节奏 | 连续观看可复述关键决定、触发、反应与后果。关键信息没有被剪掉或提前揭示，场长与注意力分配符合已定目标。 |
| 表演和场界 | 按正常速度能读到反应，动作、视线、银幕方向、空间或有意断裂都能解释。场界和结尾有预期的情绪余量。 |
| 对白、音效和配乐 | 台词和关键声响听得清，放置、退乐、无乐与主题回归有实际效果。声音没有重复、抢拍、拖出黑尾或盖住下一场的第一声。 |
| 工程与导出 | 关键媒体能打开，画面和声轨都能正常播放。指定导出文件的时长、帧率、画幅、黑场、字幕、峰值或适用响度已核验。 |

## 实例：三十秒的语音消息

一场戏中，女孩面试落选，对着手机给母亲说“挺顺利的”，想补一句又松开手。接着母亲的回复响起。音乐只承担一件事，等女孩把话说完，再让观众察觉她快要维持不住镇定。先剪出动作和反应能读懂的一版，再对照提前入乐、延后入乐和无配乐三个版本。

| 成片时间 | 画面与声轨安排 |
|---|---|
| 00:00–00:12 | 建立走廊和她试图说得自然的努力。用底声和完整台词承担前景。确保最后一个字清楚落下，走廊底声保持连续。 |
| 00:12–00:19 | 台词结束后，手还捏着手机。两个间隔开的弱钢琴音进入，第二个音之后有轻的持续音。 |
| 00:19–00:23 | 她张口又放弃补录。保留近处的一口气，和声继续悬着，松手时结束乐句。 |
| 00:23–00:30 | 尾音在母亲开口前落完，第一声交回真实的人声。 |

试剪固定画面和音乐素材。早进版让观众在她开口时已经怀疑这句话，晚进版让观众先听她撑住，再发现撑不住。无乐版考查呼吸、张口和松手能不能独立传达。若比较的是剪点，就固定声音，比较留在女孩脸上与切去看手的效果。定稿记录观众实际上先读到了什么，以及母亲的语音是否清楚。
