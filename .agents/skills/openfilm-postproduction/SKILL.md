# 样片剪辑与配乐

这套流程以观众在成片里实际看见、听见和理解的内容为依据。上游剧本决定事件、人物选择和揭示顺序，分镜给出预期镜流与声音意图，剪辑则要从已有素材中找出能实现这些意图的片段。可改动的程度由用户授权和既定版本决定。

技术操作随 OpenFilm 的版本核对。工作开始时读工作环境中的 `openfilm` 技能，并运行 `npx -y openfilm@latest` 取得官方指引。使用已有工程时先识别它对应的运行版本，继续使用与工程相容的入口。读该入口的 `skill film`。添加音乐或音效、转写或生成媒体前读官方 `skill media`。只有工作涉及 Studio 画布、用户指向画布节点或需要在画布上摆放分镜时，再读 `skill canvas`。在有素材可剪时先用现成素材完成剪辑。

## 输入与工作范围

- 先区分故事板或静帧预演、满素材剪辑、既有成片修订、单纯诊断四种情形。确认需要动的是哪些场次、轨道或交付件。
- 收齐已提供的剧本、选定分镜稿、镜头和拍次目录、同期声与其他音频、已有时间线和输出规格。通读可获得的剧本与分镜，并连续看指定时间线；局部剪辑也要看相邻镜头和相关伏笔。缺的上下文写明会影响什么。锁定用户已有的时长范围、画幅、帧率、生产语言和交付用途；无关紧要的可逆选择可以先做，重要规格从已有工程和素材中核对。
- 原始素材、正式稿与发布版本要可回查。先识别当前工作版本与 Studio 锁轨，做局部修改。存在用户与代理同时编辑的可能时，写前重读 `film.html`。重排多场、替换已锁定内容或大幅改动先保存可恢复版本，保留已确认的叙事决定、对白和镜内关键动作。
- 预演可以用 stills、临时对白和示意音效，标清代理素材以及它只能验证的事项。最终成片中仍有缺镜、临时音乐、口型不稳或其他无法交付的材料时，按位置记录实际问题。需要重生成、补拍或购买素材时沿用户已经授权的范围处理。

## 按顺序完成八次检查

1. **看片并建立素材账。** 先看演员的行动、对手反应、转折和关键物理状态，再记素材 ID、拍次或生成版本、可用源范围、同步声、画面与听觉问题、备选及前后剪辑余量。画格接触表用于定位，选中段落要实时播放、听同期声，并核对源时间。详见 [素材诊断与剪辑](creative-editing.md)。
2. **组出一版能读懂的粗剪。** 先按戏剧段落和信息揭示安排主镜及必要覆盖。保留第一版可回看的整片。先用同期声、对白和必要的环境声看一遍，确定开场、转折、峰值和离场可读，标出影响判断的占位内容。删镜前检查因果、身份或手中物是否因此断开。修剪时长优先处理重复功能和无变化的过程；给关键反应留真实的表演时间。
3. **单独过一轮全片组接。** 把粗剪按戏剧变化划段，记录每段的时长、发生的变化和银幕证据。检查上一段把哪个问题、后果或情绪交给下一段，以及开场建立的状态怎样在结尾改变。先修段落顺序、重复信息、缺失的反应和强弱分配。已有足够依据的过程可以省略；线索、反应和压力还在变化时给它们时间。两线交替要写清希望观众读到的时间、空间或主题关系。按 [全片组接与转场](macro-editing.md) 从头播放并比较主要段落，确认能读懂因果和知情顺序以后进入精剪。
4. **确认需要补拍或补生成的镜头。** 按 [补镜头诊断与交接](pickup-shots.md) 在时间线上标出观众看不清、误读或来不及感受的具体位置。先复查素材并贴片比较可行替代，确认缺的是细节、反应、重新定位还是动作衔接。保留现有素材和候选镜头的对照结果，再写必补与可选项。每个必补项说明所需画面、插入位置和两侧怎样接。精剪暴露新缺口时回到同一检查，并在换入素材后重看前后段。
5. **精剪并处理场界。** 实时播放寻找观众读完一个念头的位置，逐帧核对视线、动作阶段和剪点。在剪口分开记离开动机、两镜相接的依据、实际过渡形式及新增信息。出现冲突时依次权衡情感、故事、节奏、视线、画面平面和空间连续，保住观众还原空间所需的证据。场界成对检查前场末帧、后场首帧及声音如何交接。对高影响节点做单变量对照，例如保持同一素材，只改切点或声音先入。
6. **确定配乐点，并在同一时间线上试音乐。** 先决定听点、声音主次和无乐段，再写全片的音乐意图、可重复的主题材料及单条 cue 的戏剧任务。根据画面版本核对入点、同步点、退乐和尾音。至少保留原声对照，若争议在音乐时机则用同一 cue 比早进和晚进。详见 [配乐与终混](scoring-and-mix.md)。
7. **落实到 OpenFilm 并复核每次变动。** 使用 [OpenFilm 执行与技术核对](openfilm-execution.md) 区分源入出点、全片时间、音频起音和导出帧率。移动画面时检查关联对白、拟音、字幕和 cue 标记。Studio 实时回看故事和声音，`look` 定位关键帧与技术问题。正式配乐、字幕或完成交接时记录共同的画面基准。基准之后继续改剪时，按变更范围复核对白、拟音、字幕、cue 及导出，见 [审片版、锁定版与变更](openfilm-execution.md#审片版锁定版与变更)。
8. **审看成片并交付。** 先按正常速度完整看一遍，记录观众何时懂了什么、哪里误解或走神，再按证据回查原因。音画交接、对白清楚度、画幅、字幕、同步、黑帧、音尾及全片时长分别核验。用户要成片文件时，按受众和用途导出，再检查实际导出的文件。渲染成功与叙事通过分别记录。需要修订就修复后重看相关段落及前后场，发版前再从头回放。验收表和范例见 [记录模板与实例](templates.md)。

## 完成交付的尺度

- **只做诊断**时，给出可定位的证据、病因和修改方向。已授权实施时，用实际可播放时间线完成改动，并把关键修改点交还给用户。
- **交付可编辑样片**时，交付真实的 `film.html` 工程及其有效素材，列明采用的剧本、分镜、素材或旧剪辑版本，并明确现有样片验证了什么。
- **交付成片文件**时，另附实际导出路径、时长、分辨率、帧率及核验结果。交付要求涉及对白、音效、音乐分轨时，提供同长、同起点的分组素材和总混，或如实标出原素材分轨能力的限制。
- 记录量与剪辑规模相称。一个短片可以只在一份剪辑记录中同时放素材账、重点剪点、配乐点与验收结果。修订时让版本、镜号、时间码与 `film.html` 的片段 ID 可以互相追溯。

Obsidian 的 [表演、声音与剪辑](../../../Books%20Distillation/Maps/表演、声音与剪辑.md) 第三、四、七、八节汇总声音、剪点、配乐，以及样片到定剪的流程与原书页码。场界和镜流去《剧本写作》，裁切与亮度连续性去《分镜构图与布光》。详细概念及使用边界随参考文件列出。查库沿用当前项目的 Obsidian 本地 REST 规则，从地图和已链接概念取证；遇到特定片种或改版时补读相关笔记。
