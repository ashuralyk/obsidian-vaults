# 补镜头诊断与交接

## 确认缺的是什么

整段连播，先标出观众开始误读、看不清、失去空间方向，或尚未感到变化就被带走的那个位置，再回查缺失的证据可能在哪里。也要检查画面、声音、字幕中是不是已有证据，只是出现太早、太晚、太小或被抢走了注意力。看片时简单记「当前理解」「期望理解」「第一次发生偏差的帧或事件」。如果问题发生在观众看见反应之前，要检查前面的触发是否清楚。先解决观众的实际读法，再选补镜位置。

| 看片发现的缺口 | 优先寻找的画面证据 |
|---|---|
| 人物的决定来得突然，动作和后果之间少了一步。 | 找到触发、决定或动作结果中缺失的那一拍。可以用原主镜中漏选的动作完成段，或补一个真正交出结果的镜头。 |
| 事件已发生，但观众看不出关系或人物判断变了。 | 找到听见、看见或意识到的反应。优先比较原镜多留一拍与切到听者，必要时补能读出反应的镜头。 |
| 观众分不清谁在看哪里、该往哪走，或换到哪里。 | 找能交代人物、目标和方向的主镜、反向视点或动作中的定场画面。若观众必须认出路线，只有美观的远景通常不够。 |
| 两条素材没有可接的动作阶段，或手、道具、视线出现跳变。 | 先找动作重叠和结束状态匹配的拍次。仍有缺口时补足一个可接入和接出的连续动作，或有叙事职务的插入镜。 |
| 重要文字、物件或细节在输出画幅里看不清。 | 先试源镜合理重构图；仍缺可读的大小、角度或停留时间时，补能交代事实的细节。核对道具身份与前后状态。 |
| 段落转折过急，或者关键台词后立刻被另一段高强度带走。 | 先试该处现有表演和底声能否留住反应，再比较有具体时间、地点或情绪作用的空镜或过渡镜。 |
| 生成素材的关键部分有变脸、穿帮、动作跳变或口型不稳。 | 先用相容的拍次、邻镜、可用源区间或场内合理切法规避。如果出错的部分正是观众必须看清的动作、表情或口型，就补那一小段足以替换的素材。 |

对准缺少的证据选镜头。需要观众读到主动作中已有的物件状态，用插入镜；需要让观众在省略过程后跟上方位、看到旁观者或意识到关系变化，试切出镜、重新定位镜或明确的听者反应。人物退场后的空景要有它自己的任务。若补一条局部特写只是让两镜暂时不相邻，必须从前一个动作一直播到回来后的完整动作，检验方向和因果是否真的恢复。见 [[切入细节和切出现场承担不同的证据]]。

## 用对照决定要不要补

1. **查现有素材。** 回看被剪掉的起落、主镜、备选拍次和前后场。留长，延后进入，提前退出，局部重构图或换视点都可试，把移动后需要跟随的声音和字幕一并核对。
2. **验证最省的一版。** 保持其他变量，先比较不用新镜的版本。若声音足以交代画外事件，可用明确的声源加可信反应。先固定关键一句的声轨，回查现有素材是否有能与之接合的听者拍次；若观众必须亲眼看见谁做了什么，就用画面提供证据。短暂占位可以试位置和时长，仍需换入能让指定信息被看懂的真实素材再验收。
3. **分清优先级。** 必补项会妨碍理解因果、人物变化、空间或关键连续性，且现有画面和声音解决不了。能明确改善节奏或转场、已有成立版本的，可列为可选。若仅感觉镜头少、场面不够漂亮，先保留现有剪法，并写清理由。若连期望的情节作用也说不清，回到段落关系，先弄明白故事需要交代什么。
4. **反过来删一次。** 放入候选镜头后从前段播放到后段。再拿掉它，比较观众首次看到的信息、原有表演是否被切断、后续揭示有没有提前。可以用更短的源区间给出同样的证据时，就缩短。放入后重新核算场长和受影响的声音点。

这些判断可回看 [[新镜头必须带来新信息]]、[[备用镜头是在主镜之外买的剪辑保险]]、[[为剪辑而拍要重叠动作并匹配对话角]]、[[知情差安排揭示与隐藏]]、[[情感和故事优先于空间连续]]、[[试映的疼点不等于病灶]]。覆盖角来自实际剪辑风险；同一条补镜只有在前后两侧都接得上、又确实交出缺失证据时才算可用。

## 把必要的补镜交给拍摄或生成

需要演员、原景、道具实物或特定生成参考才能完成的候选项，尽早在可播放粗剪里验证。已有条件即将撤场或变更时，把确认的必补证据和两侧接法尽早交给制作环节。

每条在 [补镜头清单](templates.md#补镜头清单) 记成片版本、场次、时间码及前后片段 ID，说明缺失证据、已试替代和优先级。给能直接执行的画面要求，包括谁的视点、看见什么、动作或状态从哪里到哪里、银幕方向和视线、道具与光色、需要接入的前后动作阶段。估计最终入片时长，另外注明采集时要留多少首尾余量。要跟对白或重要声响同步，写出明确锚点。已授权补拍或补生成时，直接把清单交给对应的制作流程。当前任务只要求诊断时，交付可执行的清单。实际修改正式分镜时，沿用项目的新稿和 Audit 规则。

用走廊语音戏试三种判断。若观众看不出女孩为什么说“挺顺利的”是在掩饰，先查面试结果是否已在上段清楚交代。若已有通知近景在源素材里但被剪掉，把它找回即可。若画面只看见她低头、声音也没有交代，且观众必须在她撒谎前就知道结果，可补一条能读清“未通过”的手机画面。若结果已清楚，但母亲说完后直接切走，先把现有听者镜头留到她决定再录音的一刻；现有素材交不出这次改变，才补反应。若两层变化都读得到，只是想加一个走廊空镜，必须说清这条镜头是让观众辨认地点、感到时间流逝，还是给情绪留下余量；拿掉后照样成立就可以省下。
