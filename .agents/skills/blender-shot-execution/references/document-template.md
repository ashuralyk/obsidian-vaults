# 说明书模板

以下是填写结构，不是可直接交付的占位文本。写作时将字段变成项目中的实际对象与执行指令。共用信息只登记一次；逐镜说明引用它，仍须清楚交代本镜起止状态。

## 制作方式与资产核查

开头记录用户为本次任务确认的白模模式或现有 3D 资产模式，以及确认依据。未确认时不开始填写正式执行说明书。资产模式未通过核查时停止执行，只报告缺项，不输出一份假定资产齐全的说明书。

资产模式按本次制作范围逐项列出场景、角色与剧情道具的源文件或现有工程对象、版本、依赖完整性、尺寸与朝向、骨架及面部能力、必要适配和检查结果。已有工程内的完整资产同样有效，不要求重复提供外部模型文件。白模模式则说明拟建几何体、人物比例、走位和关键动作所需的关节，以及为了保证剧情可读必须保留的外形特征。

### 白模标识与参考图片映射

白模模式必须填写此表，现有资产模式说明本项不适用，除非用户另有要求。每个需要独立关联图片的模型占一行；同一模型在多个表面使用同一编号，并保持跨镜一致。

| 唯一标识与类别 | 对应模型与身份 | 标识附着位置 | 关联参考图片 | 可读性检查与限制 |
| --- | --- | --- | --- | --- |
| 填写项目内唯一的场景、人物或道具编号。 | 写明工程对象或集合，以及对应的剧本资产。 | 说明编号所在表面、重复展示位置及附着方式。 | 记录能清楚辨认编号与外形的图片路径，以及后续替换图片的对应关系。 | 记录检查分辨率、相关镜号及帧段；无法辨认的情况须说明如何通过参考图关联。 |

逐镜执行卡注明本镜可见资产的编号，并检查标识是否遮住表演、接触或剧情文字。编号不能仅写在说明区；它必须存在于模型上。后续生成成片时，非剧情编号默认不作为人物外观或场景内容保留。

## 文档与全片规范

开头说明剧本与正式分镜的版本、实际通读范围、工程文件及场景、适用镜号、输出规格和当前验证范围。缺少完整来源时明确未读部分及其影响；没有可读取工程时说明哪些值是拟定值。

在技术规范之前，用简短的完整段落写出通读后的全片理解，并引用相关场次和镜号：解释人物目的及关键变化、信息揭示的先后、跨镜延续的动作与声音，以及转折和结尾所需的节奏。随后说明剧本与分镜是否存在影响执行的差异，以及采用何种已确认依据。此处应提炼设计依据，不复述整个故事，也不另建重复的审计文档。

| 项目 | 应填写的执行信息 |
| --- | --- |
| 时间规范 | 记录帧率、起止帧口径、镜内帧换算、全片帧数和声音基准。 |
| 空间规范 | 记录长度单位、坐标轴、原点、角色左右与画面左右的区别，以及主要接触面的坐标。 |
| 资产映射 | 将角色与道具对应到实际对象、集合和骨架名称，说明尺寸、初始状态及可简化内容。 |
| 控制映射 | 按实际制作范围填写，白模只列走位与关键动作所用的控制。将根控制、骨盆、胸腔、头、视线、手脚及表情对应到可用控制器，注明缺项与拟建方案。 |
| 摄影规范 | 记录传感器有效尺寸、画幅、摄影机命名和焦距口径。 |
| 还原要求 | 明确剧情动作、接触和镜头意图的优先级，以及造型和表演允许简化到什么程度。 |

随后提供镜头索引表，列出镜号、全局帧段、帧数、摄影机、角色及该镜当前制作状态。索引总帧数须与时间账相符。

## 每镜执行卡

每镜使用独立标题和二列表，避免将整镜内容塞进宽表的一格。连续动作的帧段另用下方的小表表达。

| 执行项目 | 应填写的内容 |
| --- | --- |
| 镜头任务与依据 | 写出本镜必须读懂的行为与反应，并链接对应分镜。 |
| 工程对象 | 列出实际摄影机、角色骨架、道具及接触目标，引用共用映射。 |
| 开镜状态 | 写明根位置与朝向、身体姿态、视线、手脚支撑、持物及本模式需要呈现的表演状态，说明从上一镜承接什么。 |
| 关键姿态与身体协调 | 说明关键姿态、必要极值及过渡关系，写清哪些部位先动、后动、重叠或保持。 |
| 表演交接 | 白模按下文记录交给视频提示词的细节。现有资产模式承担面部表演时，指定可见变化、相应控制器、触发、强度和消退方式。强度数值必须注明控制器实际范围。 |
| 接触与支撑 | 写出接触对象、位置、成立与解除帧、约束变化，以及道具从哪里获得支撑。 |
| 摄影机与焦点 | 给出坐标参照、起止变换、焦距、路径、触发、速度与停稳方式，以及焦点变化。 |
| 声音关系 | 标出实际音频事件或拟定事件的位置，以及反应如何承接；没有音频验证时明确状态。 |
| 关镜状态 | 写明最后一帧的角色、道具与相机状态，以及下一镜接续的动作阶段。 |
| 验收与已知差异 | 指明检查视图、帧段、通过条件、已知限制与上游差异，附实际验证状态。 |

### 动作阶段表

| 帧段与阶段 | 可见过程与触发 | 控制对象与关键姿态 | 时间、路径与接触要求 |
| --- | --- | --- | --- |
| 填入本镜实际帧段。 | 用完整句子描述本阶段发生什么，以及为何开始。 | 对应实际控制器，明确阶段起止姿态。 | 说明加减速、保持、路径或支撑条件，避免只写“平滑”。 |

需要精确关键帧时，另列关键帧、控制器、属性、数值与参照系，区分工程测量值、设计值和已验证值。不要在没有骨架或工程时伪造可运行的数据。阶段允许合理重叠，但各身体部位与道具的同时要求不能互相冲突。

## 逐镜执行数据与操作步骤

以下模块属于每镜执行卡。影响剧情、接触、构图或动作节奏的控制量必须明确；其余量可以引用已定义的共用姿态或动作片段，不必逐根骨骼抄表。不适用项须说明原因。所有参数区分设计值、工程测量值和已验证值，不能把未经校准的数字当作可直接复现的工程事实。

### 人物关键姿态与运动路径

每个参与表演的角色分别填写。开镜、主要极值、接触、关键反应和关镜须有可重建的姿态依据，可以引用有名称、版本和明确位置的工程姿态。

| 执行项目 | 应填写的内容 |
| --- | --- |
| 姿态与发生帧 | 指明帧号、根位置与朝向、骨盆和胸腔倾转、头部朝向、手脚目标或所引用的姿态。注明坐标空间、旋转顺序或四元数口径，不只写“紧张地站着”。 |
| 重心与支撑 | 写明重量由哪只脚、座面或手承接，如何转移，何时允许脚跟或脚尖离地。转身记录落脚与转轴，步行记录落脚位置和支撑区间。 |
| 肢体路径 | 对关键的手、脚、头和根运动，给出必要经过点、弧线方向、避障要求及幅度，不让起终点自动插值决定全部轨迹。 |
| 时间与曲线 | 写清启动、到达、极值、保持和恢复的帧，以及部位间的延迟或重叠。说明保持量、插值和加减速要求；精确接触须限制过冲。 |
| 手指与次级动作 | 手部承担剧情时，写明掌面朝向、接触手指、握持形状及收拢和释放顺序。衣物、头发和饰物只在影响画面时说明跟随或模拟方式。 |

### 白模交给视频提示词的表演细节

逐镜用一两句话记下正式分镜要求的表情或细微姿态，以及它与白模动作、对白或切点的先后关系。只在时机影响剪辑时注明帧位。例如，白模做出人物扶桌起身并停住，提示词承接停住后才抬眼的细节；若切在抬眼时，执行卡同时注明该切帧。没有此类细节的镜头可略过。本栏供后续编写提示词使用，验收白模时只检查相应的构图与节拍。

### 现有资产模式的注意、面部与呼吸时间线

每个有意义的变化分别填写一行，不能仅写情绪名称或峰值。保持安静时也应说明注意目标与保持量。

| 角色、触发与帧段 | 可见变化和控制目标 | 基线、峰值与恢复 | 与身体及声音的关系 |
| --- | --- | --- | --- |
| 写明角色、刺激事件及发生帧，并给出反应开始、峰值、保持和恢复的帧。 | 写出视线目标的对象或位置，以及眼球、头部、眼睑、眉、嘴角、下颌或呼吸使用的控制器。 | 写明起始状态、变化方向、幅度和结束状态；数值注明控制器范围与左右侧，不强制恢复中性表情。 | 写明眼动与转头的先后、身体如何承接，以及对应台词或声音的位置。 |

视线目标移动时须说明目标轨迹，避免盯住已离开的空点。眨眼和呼吸不默认周期循环。需要口型时记录音频、对齐帧、驱动方法及与下颌和表情叠加的处理；没有音频时标为待对齐。确认当前景别和照明能够看见这些细节。

### 接触与控制切换

| 接触关系与帧段 | 几何与手脚状态 | 控制方法及切换 | 验收条件 |
| --- | --- | --- | --- |
| 写明接触双方及首次接触、稳定接触、释放的帧。 | 给出接触点或面、局部偏移、掌面或足底朝向，以及接触前后的支撑来源。 | 指明约束、IK/FK状态、目标、影响权重和变化帧，说明如何保持世界变换及是否需要烘焙。 | 按镜头可见程度规定允许偏差及检查方法，检查滑动、穿插、跳位和释放后的支撑，不套用未经确认的统一误差值。 |

### 摄影机路径、构图与焦点

分别处理位置、朝向、焦距和焦点。固定项也要记录值或可定位的工程引用，以及保持帧段。

| 执行项目 | 应填写的内容 |
| --- | --- |
| 相机与成像设置 | 记录相机对象、透视或正交类型、焦距或正交尺度、传感器尺寸与适配方式、画幅和像素宽高比。使用镜头偏移时记录偏移值；注明景深开关，启用时记录光圈与对焦方式。 |
| 位置与朝向关键点 | 给出启动、必要中间点、到达和停稳帧的机位与朝向，注明坐标空间和旋转口径。使用路径或目标约束时记录路径、目标、跟踪轴、向上轴与偏移，避免约束与旋转关键帧冲突。 |
| 路径与速度 | 说明路径形状、必要控制点、移动距离、加减速区间和停稳方式。路径进度须对应帧；进度匀速不等于空间匀速，须检查实际位移。摇转、推轨、变焦和移焦分别说明。 |
| 构图与可见性 | 在起点、关键经过点和终点记录景别、主体画面位置与大小、头顶及视线留白，以及必须可见或暂时遮住的内容。使用归一化画面坐标时定义原点、轴方向和允许范围。 |
| 焦点变化 | 写明焦点对象或距离、转移触发、起止帧及变化方式；主体移动时说明是否跟焦。检查移焦期间必须读懂的信息是否清楚。 |
| 与表演的同步 | 写明相机由哪次动作或声音触发，是提前、同步还是滞后，以及动作变速时如何处理，不擅自改变已确认的运镜意图。 |

### 相邻镜交接

给出前镜末帧、本镜首末帧和后镜首帧对应的剧情时刻，说明连续、重叠还是省略。核对位置、朝向、朝向及本模式实际制作的表演阶段、左右手持物、接触状态、运动方向与速度及声音延续。省略时间时说明状态变化的依据；连续动作不能重复起势、突然停顿或无依据复位。

### 本镜制作步骤

按实际依赖顺序说明如何建立或复用对象和控制器、摆关键姿态、设置支撑接触、补必要过渡（现有资产模式按需补面部变化）、建立相机动画、对齐声音及输出检查片段。注明动作片段、NLA轨道、约束或模拟缓存如何影响本镜，避免旧动画叠加和跨镜状态污染。需要程序生成时附参数或脚本入口，不强制把整套代码写入文档。

## 最终说明版的视频布局与逐镜文案

记录上方视频区域、左上角标注、中间进度条和下方描述区的尺寸、边距、字号、字体和换行方式，区分原视频画幅与合成画布尺寸。视频保持原比例，描述区必须容纳可读的完整句子。白模与现有资产模式都交付这一版式，并保留独立干净素材。

每镜执行卡附上以下展示字段，避免合成时临时从工程指令拼凑文案。

| 展示项目 | 应填写的内容 |
| --- | --- |
| 左上角镜头信息 | 写出分镜号、景别、运镜和视角的实际展示文案。镜内发生变化时说明标签如何表达。 |
| 进度段与时长 | 引用全剧镜头顺序、最终起止帧与入片帧数，填写由帧率换算的完整时长，以及进度条中的对应区段。 |
| 分镜设计描述 | 用完整句子说明主体、构图、注意重点、可见事件及镜头呈现方法，不能只重复标签。 |
| 演绎内容描述 | 用完整句子说明动作顺序与速度、视线、神态、停顿和接触；无人镜头明确适用的环境或物体变化。文案须与实际实现一致。 |
| 文案切换依据 | 默认在本镜首帧切入、末帧结束；镜内需要分阶段时给出实际帧段，并保持镜号和全镜时长不变。 |

全片进度条以播放位置为准，不表示制作完成率。局部交付标明其全剧位置与范围；资料不足则明确缺项。验收记录应包含各镜首末帧、切点、文字可读性、关键动作未被标签遮挡，以及视频、进度条和描述是否同步。

## 制作顺序与验收记录

交付前逐镜核对：制作人员能否凭本文及明确引用的工程资产，确定关键时刻人物在哪里、如何支撑、朝向哪里（现有资产模式按需核对面部变化），以及相机在哪里、如何移动和何时对焦。仍需猜测且影响剧情或运动的事项必须补齐；未校准参数保持设计值或待测状态。

把全片共用的制作步骤集中说明，逐镜只补特殊处理。记录代表片段验证、批量制作顺序、需要重查的镜口，以及输出方法。

| 镜号与版本 | 检查范围 | 观察结果 | 状态及后续处理 |
| --- | --- | --- | --- |
| 填入实际镜号和工程版本。 | 明确是文档核对、几何、接触、静帧、动态还是声音检查。 | 写出实际观察和证据位置，不能用“看起来正常”代替。 | 记录通过、失败、待测或有理由的不适用，并说明修复目标。 |

结尾说明已完成的文档和工程范围、剩余缺口，以及哪些更改需要同步到分镜。无需为每次小调整另建独立审计报告。
