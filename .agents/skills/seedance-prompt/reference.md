# Seedance 2.5 提示词细则

权威来源：<https://docs.volcengine.com/docs/82379/2607689?lang=zh>  
可选官方调优 skill：`npx --yes skills@latest add "https://arkdocs.tos-cn-beijing.volces.com/skills/" --skill sd25-pe --yes`，对话里用 `/sd25-pe`。

## 单段模板

```
素材绑定：
- 图 1：人物 A 外观 ID（正脸，必要时另附侧脸为图 2）
- 图 3：场景 S 主视图（同一房间的全景垫图）
- 图 4：道具 P 外观 ID（纸、杯、手机等会反复入画的物件）
- 图 5 / 图 6：仅当本段要切反打或顶视。必须从主视图垫图生成，并写明是场景 S 的哪个角度
- 视频 1：仅当续写/延长时，绑上一段 Seedance 2.5 成片（形象与空间的时间轴锁定）
- 音频 1：人物 A 音色（若有）
无参考则写：纯文本直出；下列一致性总谱仍必须写死，供模型当 ID 用。

一致性总谱（全片只此一份，后续段逐字粘贴，禁止改写同义句）：
- 人物 A：年龄、性别、身高、发型发色、五官特征、体型、服装（颜色/材质/层数）、鞋、配饰。同框两人必须写身高差。绑定图 1。不要改变角色形象。参考图若双手插兜，后面的手部动作做不出来，改成双手自然下垂再绑。
- 场景 S：空间名称、墙面/地面/窗的位置与颜色、固定家具、光源方向与色温。绑定图 3（主视图）。同一场戏不换房间。要切反打或顶视时，图 5、图 6 从这张垫图生成，写明「图 5 是场景 S 的反打，图 6 是同一房间的顶视」。只靠文字形容反打，模型会重造房间。
- 道具 P：名称、材质、颜色、相对大小、何时在谁手里。绑定图 4。同一件东西不替换成「类似物」。
- 风格锁：画幅、胶片/写实、色盘。整片不换风格。
可变化：表情、口型、走位、机位、手中道具的开合状态。不可变化：脸、发型、衣服、房间结构、英雄道具外形。

一句话概述：
[主体] 在 [地点] [事件]，[题材/风格]，[特殊运镜]。

分镜头（时间轴连续，单位 1 秒）：
0-3s：【景别 + 机位 + 运镜】画面。动作。看得见的微表情，只写人物 ID，不重描五官和服装。台词（角色）：「……」。音效：……。
3-8s：……
8-15s：……
15-30s：……

贯穿始终：
机位/运镜：……
环境/场景：……
声音：无配乐，只保留现场说话、环境音和动作音，不要旋律、不要垫乐。 / 或明确 BGM。
氛围：……
不额外加入对白字幕。

要做：
- ……

不要做：
- 不要字幕
- 不要配乐，不要旋律，不要垫乐（本段明确要 BGM 时删掉这条）
- 不要跳秒时间轴
- 不要在一段 30 秒里塞进无法演完的情节
- 不要换脸、换发型、换服装、换体型
- 不要更换房间布局、墙色、窗的位置
- 不要把关键道具换成另一件「差不多」的东西
- 不要在续写段用新的人物外貌复述替换总谱原文
- 不要在正脸镜头里把屏幕内容画在手机背面；正脸只见背壳，看界面切过肩
```

## 时长与任务分流

| 需求 | 做法 |
| --- | --- |
| ≤30s | 一条结构化 Prompt 直出 |
| 30s–数分钟 | 总谱 + 多段 30s；后续段「向后延长 @视频 1」或「续写」；输入输出 MOV |
| 两段相接 | 「将【视频 1】和【视频 2】衔接起来」+ 写清转场触发点与方式 |
| 改已有成片 | 提示词含「编辑视频 / 增加 / 删除 / 修改」；写清 A→B 与时间范围 |
| 严格对齐分镜图 | 关键帧，不要宫格 |

有锁定（宽高比/时长由素材决定，ratio=adaptive）：编辑、首尾帧、延长。  
无锁定（可指定宽高与时长）：参考生视频、宫格、关键帧。

## 时间戳

支持：`0-3s……3-7s……7-15s`、`[1s-4s]`、`第 5s 快速向左横移转场`、`3 秒后周围的人纷纷摇头`。  
禁止：时间轴断层；用时间戳写频率；单段堆叠过多情节。

## 素材上限（单次）

- 图最多 30 张（4K 以内）；视频最多 10 段且总时长 ≤30s；音频最多 10 段且总时长 ≤30s。
- 主体音视频 1–5 个、时长 5–10s 较稳；主体图 1–8 个较稳。超过易抽卡。
- 宫格：15 镜以内，火柴人/线稿，图上少字。
- 白模：简单几何体；细粒度白模不要轨迹线、坐标线、相机 cone。

## 人物 / 场景 / 道具一致性

官方能力对应的是**主体参考（外观 ID）**，不是在文案里换着称呼。模型认的是「图 1 的人」，不是「那个年轻人」。

必须做：

- 每个会再出场的人、房间、英雄道具单独编号，并在**每一段 Prompt** 里重复同一套绑定句，不要缩写成新外号。
- 有参考图时：人物 1–5 个较稳；超过 5 人用单视图分张传，不要一张拼多人多视角。人物参考 5–10 秒音视频或清晰正脸静帧。双手自然下垂，不要插兜。
- 同一空间的反打和顶视从主视图垫图生成，分开编号，写明角度。模型没有长期空间记忆，文字里的「反打」会另造一个房间。
- 无参考图时：总谱把脸、发、衣、空间、道具写成不可改的规格，分镜里用「人物 A / 场景 S / 道具 P」指代，禁止每段重新描写成另一套形容词。
- 续写：`向后延长 @视频 1`，视频 1 必须是上一段 Seedance 2.5 输出；写明「严格保持视频 1 中人物、房间、道具的外观，不要改变角色形象」。
- 需要动作一致、外观另定时：视频参考管运动/运镜，图参考管外形，Prompt 写清「参考什么、不参考什么」。
- 宫格只提供剧情，不锁 ID。要对齐脸和房间，用主体图 + 关键帧，不要指望线稿分镜维持外貌。

禁止做：

- 只在图片上写「张三」然后 Prompt 里直接写张三。
- 第二段把「米白针织衫」改成「浅色上衣」。
- 为了「好看」给角色加新配饰、换灯、换桌。
- 一场戏里无剧情依据地换空间。

可改 / 不可改：

| 可改 | 不可改 |
| --- | --- |
| 表情、视线、口型、走位 | 五官、发型发色、年龄体型 |
| 机位、景别、焦段 | 服装与鞋（除非剧情写明更衣） |
| 道具被拿起、放下、翻开 | 道具换成另一件 |
| 窗外光线随时间轻微变化 | 房间结构、家具位置、墙色 |

## 参考类写法

- 映射写在 Prompt 里：`图 1 是人物 A 的外观 ID，对应音频 1 的音色；图 3 是场景 S；图 4 是道具 P`。
- 部分参考写明部位：`参考视频 1 中施法的动作，视频 2 的环绕式运镜；外形只参考图 1，不参考视频 1 的服装`。
- 素材已足够准时，时间轴上外观只做指代、减少复述；一致性总谱仍要原句保留，不能删。分镜里再写一遍五官和服装，等于邀请模型改脸。

## 手机屏幕朝向（硬规则）

正脸对着镜头时，手机若入画，只许看见背壳。屏幕朝向人物自己，镜头看不见界面字。要看清微信、行情、按钮，必须先切过肩或肩膀视角，镜头越过肩膀看屏幕正面。

允许看见屏幕的镜头：过肩、肩膀视角、俯拍双手（画面里没有正脸）、屏幕特写（画面里没有正脸）。  
禁止：人物正脸 + 手机背面显示聊天/K 线/按钮；同一镜里正脸和屏幕文字同时出现。  
脸上可以有屏幕的冷青、红、绿反射，反射不是字。

写法示例：`0-6s：【中近景平视】只见手机黑色背壳与右上裂纹。6-14s：切到右过肩，越过肩膀看屏幕正面，顶栏「明日看盘」。`

## 镜头语言

可直接写：大全景/全景/中景/近景/特写；推/拉/摇/移/跟/环绕/俯冲/后拉/上摇/手持晃动；低角度/俯视/第一人称；一镜到底、希区柯克变焦、航拍、FPV、子弹时间、手持、回弹变速。  
小众词：`移焦，画面焦点发生平滑转变，前景树木变模糊，背景人物逐渐清晰。`  
转场：`第 5s 快速向左横移转场（向左擦除+自然叠化）`。

内心戏写成看得见的变化：眉心收紧、视线躲开、嘴角停住、呼吸间顿一下。不要写充血、红得滴血、泪如雨下、大汗淋漓，这些词会把脸画成夸张的生理反应。这条放在写法里，用正向句子写，不要塞进「不要做」。禁止用时间戳规定眨眼频率。

一个人连续说话时，说完一个信息就切到听者的反应或一件道具，再切回。整段钉在说话人脸上，运动预算会空掉。安静的戏可以固定机位。

## 负向控制（仅这些）

- 字幕：`不要字幕` / `不额外加入对白字幕`
- 音频：`无配乐，只保留现场说话、环境音和动作音，不要旋律、不要垫乐` / `不要任何声音`；可单控音效、bgm、对白。只写「无 BGM」时，模型仍会铺钢琴垫乐。

## 3 分钟成片装配

180 秒 = 6 × 30 秒。推荐：生成段 1（30s）→ 五次向后延长各 30s，始终用上一段 Seedance 2.5 的 MOV 作视频 1。每段只写本段情节，但**一致性总谱必须全文粘贴**，人物衣着、房间、英雄道具、色温不得改口。换场时先在总谱增补新场景 ID，旧 ID 仍保留，禁止覆盖。

## 交付检查表

- [ ] 有概述、有连续整数秒时间戳、有贯穿始终
- [ ] 单段不超过 30 秒；更长已拆段并写延长/转场词
- [ ] 要做 / 不要做 都写了，且不要做不与正文打架
- [ ] 有素材则编号绑定；无素材则声明纯文本直出
- [ ] 转场写了秒点与方式
- [ ] 表情是看得见的微表情，不是充血、泪如雨下、大汗淋漓
- [ ] 有参考图时，时间轴只指代人物 ID，没有重描五官和服装
- [ ] 长台词切到了听者反应或道具，没有整段钉在说话人脸上
- [ ] 要切反打或顶视时，已从主视图垫图分开绑定，并写明是同一空间的哪个角度
- [ ] 同框两人写了身高差；人物参考图双手没有插兜
- [ ] 无配乐时写了不要旋律、不要垫乐
- [ ] 标明画幅（如 9:16 竖屏 / 16:9 横屏）
- [ ] 有一致性总谱：每个人、每个固定场景、每个英雄道具都有 ID
- [ ] 有参考图则编号绑定外观；续写绑上一段成片
- [ ] 各段总谱原文一致，未改写服装/房间/道具
- [ ] 「不要做」含换脸、换装、换房间、换关键道具
- [ ] 正脸镜头里手机只见背壳；看屏幕已切过肩，无正脸与屏幕字同框
- [ ] 由分镜转写时：每一段对应分镜表一个镜号，整数秒与该镜一致，时间戳连续不跳秒
- [ ] 由分镜转写时：不写场号对照、跨场呼应、剧情背景梗概
- [ ] 需要支撑的道具已分开持有人和这一段的可见部分。入画的人被禁止碰到它时，时间轴写留下的那一段；没有写成空着、没有手、悬空，也没有在画外补一只本段不该出现的手。要做与不要做没有一起删掉支撑
- [ ] 同一件道具的持有人与剧本及前后段连续。持有人写在一致性总谱，不在时间轴里用「没有人握着」把持有人抹掉
- [ ] 时间轴的起点写成这一秒身体所在的体积和朝向。下缘、暗区、画面边缘没有被当成出发地点
- [ ] 朝向背对下一步要接触的人时，时间轴里先写原地转身、脚停住，再写抬手
- [ ] 被碰到的袖口、皮肤、手使用总谱里的同一人物指代，没有用「那只」把所有者省掉
