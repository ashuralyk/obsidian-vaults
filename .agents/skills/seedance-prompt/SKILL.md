# Seedance 2.5 提示词

官方规则：[Doubao Seedance 2.5 提示词指南](https://docs.volcengine.com/docs/82379/2607689?lang=zh)。写任何视频剧本或生成提示词之前，先读本技能与 [reference.md](reference.md)。禁止自创提示词格式，禁止把 3 分钟片写成一条超长直出词。

## 硬约束

1. 把模型当成视觉内容生产者，用导演思维写**结构化 Prompt**。
2. 单段直出最长 **30 秒**。更长成片必须拆段：先 30 秒，再「向后延长 / 续写」，或 6 段 × 30 秒后无缝转场。延长/编辑输入输出优先 **MOV**。
3. 时间戳只响应**整数秒**，时间轴必须连续（`0-3s → 3-7s → 7-15s`）。禁止跳秒（`0-3s` 后接 `5-6s`）。禁止用时间戳管频率（如「一秒摇头 3 次」）。一段事太少会自由发挥，事太多会切碎或漏戏。
4. 负向控制只用于字幕和音频：`不要字幕`、`无配乐，只保留现场说话、环境音和动作音，不要旋律、不要垫乐`。只写「无 BGM」时，模型仍会铺钢琴。画面与动作尽量正向写。
5. 有参考素材时，按上传顺序绑定 `图 1 / 视频 1 / 音频 1`，写清参考的是形象、音色、动作还是场景。不要只把人名写在图上再在 Prompt 里直接用人名。
6. 宫格分镜 ≤15 镜、线稿、少字；要对齐画面则改关键帧，第一句写「以图片 x 至图片 x 的顺序作为关键帧」。
7. **人物、场景、道具必须做 ID 锁定。** 先写一致性总谱，再写分镜。每个会再出场的人/房间/关键道具：固定外形描述 + 绑定参考图（有则必绑）。后续每一段重复同一套指代，禁止换脸、换装、换房间布局、换英雄道具。可改的只有表演、机位和剧情允许的位置。同一房间要切反打或顶视时，主视图、反打、顶视分开编号，写明是同一空间的哪个角度；反打和顶视从主视图垫图生成，不要另写一套房间。续写必须以上一段 Seedance 2.5 成片为 `视频 1`，并写「不要改变角色形象」。主体控制在 1–5 人较稳。同框两人把身高差写进人物规格。
8. **手机屏幕不得出现在朝向镜头的背面。** 正脸、平视中近景里，手机只许看见背壳；要看界面必须先切过肩/肩膀视角，镜头越过肩膀看屏幕正面。禁止同一镜里同时出现人物正脸和屏幕上的字。俯拍双手、屏幕特写可以看界面，但画面里不得出现正脸。
9. **持有与入画分开。** 道具由谁撑着、拿着或推着，以剧本和前后镜为准，持有人写在一致性总谱。某一段禁止入画的人碰到它时，时间轴只写这一段看得见的那一段，例如伞面在画面左侧、伞柄不进入画面。不要把「不拿」写成柄上没有手、没有人握着或悬在空中，也不要在画外添一只这一段不该出现的手。细则与分镜契约见 `storyboard-development/prompt-generation.md`「持有与入画分开」。
10. **这一帧的身体写全。** 时间轴写这一秒身体所在的体积，以及头顶、脸和胸口朝哪边。构图上的下缘、暗区、画面边缘不是出发地点。朝向背对下一步要接触的人时，先写原地转身、脚停住，再写抬手。被碰到的袖口、皮肤、手使用一致性总谱里的同一人物指代，不用「那只袖口」把所有者省掉。细则见 `storyboard-development/prompt-generation.md`「这一帧的身体写全」。

## 每次必须输出的结构

```
[素材绑定，若无素材则写「纯文本直出，无参考图」]
[一致性总谱：人物 ID / 场景 ID / 道具 ID，各绑参考图或写死外形]
[一句话概述：主体 + 地点 + 事件 + 题材风格 + 特殊运镜]
[分镜头：连续整数秒时间戳，逐段写画面、运镜、动作、台词、音效]
[贯穿始终：机位、环境、声音、氛围；重申仍用同一套 ID]
[要做]
[不要做：含不要换脸换装换房间换关键道具]
```

超过 30 秒时，先给一致性总谱，再按 30 秒切段；续写段用「向后延长 @视频 1」并只写新增 30 秒，总谱原文逐字沿用。

## 镜头与表演

通识词可直接写：大全景 / 全景 / 中景 / 近景 / 特写；推拉摇移跟环绕；低角度 / 俯视 / 第一人称；一镜到底、手持、航拍。小众术语写成「名词 + 解释」。转场写清第几秒和方式。动作宜概括，记忆点才写细节。内心戏写成看得见的微表情（眉心、视线、嘴角、呼吸间的停顿），不要写充血、泪如雨下、大汗淋漓。有参考图时，分镜只指代人物 ID，五官和服装留在总谱里，不要在时间轴上再描写一遍。一个人说得比一个反应更长时，切到听者的反应或一件道具，不要整段钉在说话人脸上。安静的戏可以固定机位，呆的是整段只有一张脸在说。
