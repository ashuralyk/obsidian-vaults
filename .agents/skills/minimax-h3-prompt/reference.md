## 可贴入模板

把方括号换成具体内容，收成一段话再交给用户。

```
[N]秒、[画幅]视频。[风格与气质]。
[图1]作为[人物/场景/道具/风格]参考，保持[不可改的外形要点]；[图2]作为[…]；[视频1]只参考[动作/运镜/剪辑节奏]，不参考其[服装/场景]；[音频1]作为[音色/BGM/对白]。
[核心事件，按发生顺序写完]。人物以[中近景/特写/…]为主。[运镜：推/拉/摇/移/跟/环绕/升/降/手持/一镜到底，需要时补幅度和速度]。
声音：[环境音与动作音]。台词：「[原文]」。[不要配乐，不要旋律，不要垫乐，只保留现场说话、环境音和动作音 / BGM 写乐器、速度、起伏，不写情绪形容词]。
不要[换脸换装、加字幕、另起一场戏、把界面画错位置]。
```

文生视频把绑定句删掉，改把主体外形写死在正文里。

## 镜头怎么拆

H3 单条 4–15 秒。按事件密度拆，不按「每秒一条指令」拆。

| 时长与事件 | 建议 |
| --- | --- |
| 一个动作、一个空间 | 一镜到底，靠运镜变景别 |
| 一个关系变化（靠近、取出、对视） | 2 镜：建立 → 反应 |
| 一个人连续说话 | 说完一个信息就切听者反应或道具，再切回。整段只有说话人的脸，运动预算会空掉 |
| 预告片节奏、产品卖点 | 3–4 镜，每镜只换一种信息：空间 / 主体 / 细节 |
| 首尾帧 | 默认一镜，写中间状态变化；用户点名分镜才切开 |

切镜必须带来新信息（空间、对象、状态、视点）。只是稍微靠近，用推或移，不要切。文生视频可在关键动作后加 `[运镜]` 短句引导调度，但仍要写在连贯句子里。

运镜写成自然语言：类型 + 必要时的幅度 + 速度。中等幅度、常速可省略。

可用：推、拉、摇、移、跟、环绕、升、降、变焦、手持微晃/大晃、POV、一镜到底、固定机位。  
不要在句尾堆 `Zoom In, cinematic, 8k`。

## 三类模式的写法差异

**文生视频**：首句写时长、画幅、风格。主体从零描述到能认出来。画幅必填（如 `16:9` / `9:16`），不能用自适应。

**首帧**：图就是 0 秒画面。先锚定图中的人、构图、空间，再写下一个动作。身份、服装、色彩、空间关系保持与图一致。路径：静帧锚定 → 动作起势 → 连续发展 → 结果或反应。

**尾帧**：图只锁最后一格。先写与图兼容的前史，再让动作、物体、构图在结尾落到图。路径：合理前史 → 明确过渡 → 终镜收敛 → 落图。

**首尾帧**：图1 是开头，图2 是结尾。不要把两张静帧各描述一遍，只写中间怎么走过去。优先单镜头插值。路径：首帧状态 → 可见的中间变化 → 差异收窄 → 尾帧状态。

**全能参考**：每条素材一个职责。官网好案例都是「图锁人、图锁物、图锁风格、视频锁动作或分镜」。禁止一条素材既当首帧又当外形参考，除非用户明确只要这个。同一房间要切反打或顶视时，主视图、反打、顶视分开绑定，写明各是哪个角度；反打和顶视从主视图垫图生成。图最多 9 张，这场戏不切反打就不要占这几张。有人物图时，运动句只指代图 N，不要再描写五官和服装。同框两人写身高差。参考图双手插兜，后面的手部动作做不出来。

## 声音

- 角色能听见的：环境、脚步、物体碰撞、对白、歌声、现场收音机，写进事件句。
- 只有观众能听见的 BGM：单独一句，写乐器、速度、强弱变化，不写「悲伤的音乐」。
- 不要 BGM 就写「不要配乐，不要旋律，不要垫乐，只保留现场说话、环境音和动作音」。只写「无 BGM」时，模型仍会铺钢琴。
- 画外音要写明口型闭合。
- 复用参考音频时，写复制整段、复制一层，还是只借音色/节奏。

## 容易踩的坑

- 把 15 秒写成三场戏、两次转场、一句旁白、一段完整歌词。
- 绑定了图却不说参考什么，模型会同时偷外形、构图和场景。
- 首尾帧提示词复述静帧，不写中间路径。
- 全能参考里视频既管动作又管服装，人物会串装。
- 文生视频不写画幅，或写成自适应。
- 用「高质量、大师级、8K、cinematic」代替具体材质和光线。
- 台词被意译；屏幕字被翻译。
- 把 Seedance 的 `0-3s / 3-8s` 时间戳硬套过来。H3 产品词用事件顺序；只有 Context-IR 英文改写才用 `[Shot 2] At 00:03.500`。
- 内心戏写成充血、泪如雨下、大汗淋漓。写成眉心、视线、嘴角、停顿。
- 参考图已经锁了脸和衣服，运动句再描写五官和服装，模型会改脸。
- 反打只靠文字形容。主视图垫图生成反打和顶视，分开绑定并写明角度。
- 整段只有说话人的脸。说完一个信息就切听者或道具。
- 参考静帧双手插兜；同框两人不写身高，体型会被拉平。
- 超过素材上限：图 9、视频 3、音频 3、合计 12；提示词超过 7000 字。
- 把分镜缩写原样贴进提示词。`画左 / 画右 / 半步 / 将扣 / 接触尚未发生 / 从下沿出来 / 那只袖口 / 这一镜的光是人物浅灰 / 眼睛落在 / 他 / 她` 都要译成看得见的过程，见技能正文「分镜缩写要译成看得见的过程」和「元规则」。

失败：

```
这一镜的光是人物浅灰、雨幕亮明。图1向画右半步，图2的手从画左伸入将扣腕。
```

可用：

```
打在图1身上的光保持浅灰亮度，斜着落下的雨比图1更亮。不要把画面罩成灰雾，也不要改图1衣服的颜色。图1朝画面右侧迈出很小的一步，迈完就停。图2的手从画面左边缘伸进画来，指尖靠近手腕，在碰到皮肤之前停住。
```

## 特定风格 · 提示词示意

从官网案例抽出的写法，不是要复制题材，而是复制「规格 + 绑定 + 一件事 + 声音」。

**时尚品牌大片**：先写画幅与气质，再把氛围图、人物图、产品图、logo 图分开绑定，故事只留一个动作链（走回车尾 → 打开后备箱 → 取包 → 离开）。

**生活感视觉实验**：写手持抖动、对焦犹豫、逆光波动等拍摄缺陷；声音只用环境音和必要的生物声，明确不要广告式整理。

**竖屏短剧预告**：画幅 `9:16`，人物图锁身份，场景图锁空间；中近景和特写为主；关系张力写进动作，不要写成剧情大纲。

**电商产品**：白棚、无缝背景、产品结构细节来自产品图，模特气质来自人物图；卖的是物，不是另写一条故事。

**UI / 官网演示**：写滚动、悬停、放大、反色等界面运动；产品图是被展示的主体，不是背景装饰。

**国风角色 PV**：一张图锁人物全套服饰并逐项复述，另一张图只锁分镜节奏；远景不许露脸可以写进「不要做」。

## 撰写的最佳方式

1. 先定模式、时长、画幅、参考清单，再写故事。
2. 用导演口吻写连贯段落：谁在哪做了什么，镜头怎么看，声音是什么。
3. 参考素材写成职责，不写成文件名。
4. 一件主事件写透，细节留给关键动作和声音。
5. 成稿读一遍：删掉形容词堆砌，补上没写的声音，检查绑定是否一对一。

## Context-IR / API 英文改写

仅当用户明确要求 H3-Context-IR、API 结构化 prompt 或英文 rewrite 时使用。正文用英文；对白、歌词、屏幕字保留原文。时长必须覆盖用户要的秒数。

文生 / 首帧 / 尾帧 / 首尾帧，按此顺序：

```
[首帧或尾帧对齐句，文生没有这一行]

integrated_multimodal_description: [Shot 1] ...
overall_soundscape: ...
non_diegetic_music: ...
```

全能参考六段，按此顺序：`subject_definitions` → `summary` → `retention_analysis` → `detailed_description` → `overall_soundscape` → `non_diegetic_music`。标签用 `<Subject N>` `<Picture N>` `<Video N>` `<Audio N>`，说话人用 `(S1)`，台词用 `<d>[Language] ...</d>`。

对齐句不要改写：

- 首帧：`For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.`
- 首尾帧：`How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot N) aligns with the S.SS-second mark of the target video.`
- 尾帧：`How the reference pictures align with the target video — <Picture 1> (from [Shot N]) aligns with the S.SS-second mark of the target video.`

字段名、镜头时间戳、运镜英文词以 Hugging Face 两份指南为准，不要自创字段。

## 交付检查表

- [ ] 已分流：这是 H3，不是 Seedance
- [ ] 模式正确，素材角色没有混用
- [ ] 时长为 4–15 的整数（H3 Max 为 5–15）
- [ ] 文生写了画幅；首尾帧没有靠文字去改静帧身份
- [ ] 有参考则 `图N/视频N/音频N` 一对一绑定
- [ ] 四要素都有：主体、场景、运动、声音
- [ ] 事件量配得上时长
- [ ] 内心戏是看得见的微表情；有图时运动句没有重描五官和服装
- [ ] 长台词切到了听者反应或道具
- [ ] 要切反打或顶视时，已从主视图垫图分开绑定；没切反打就没有多占视角
- [ ] 同框两人写了身高差
- [ ] 不要配乐时写了不要旋律、不要垫乐
- [ ] 可贴入稿是连贯中文段落，不是标签列表
- [ ] 方位写成画面左/右或从画面边缘伸入，没有画左、画右、画下
- [ ] 没做完的动作写到停住的那一帧，并在「不要做」里禁止把动作做完
- [ ] 浅灰、深灰、亮明、阴暗写成落在谁身上的亮度；人身上用了灰色亮度时，写明不要罩成灰雾、不要改衣服颜色
- [ ] 「不要做」具体，且不与正文打架；同一组禁令只写在可贴入最后一段，代码块外不再重复
- [ ] 需要支撑的道具已分开持有人和这一镜的可见部分。入画的人被禁止碰到它时，正文写留下的那一段；没有写成空着、没有手、悬空，也没有在画外补一只本镜不该出现的手。正文与不要做没有一起删掉支撑
- [ ] 同一件道具的持有人与剧本及前后镜连续。持有人的名字和揭示留在分镜对照，不写进可贴入
- [ ] 由分镜转写时：镜号、秒数、景别、焦距与分镜表该格一致，秒数不短于该镜
- [ ] 由分镜转写时：谁 / 在哪 / 用什么 = 三附件锁定的图N；可贴入没有剧本人名、场景专名、P-/L-/A- 代号（台词与屏幕字原文除外）
- [ ] 可贴入不用他、她、他们、她们。有图的人写图N；没有图的画外声重复「画外的男人」或「画外的声音」；台词和屏幕字里的原文不改
- [ ] 人的起点写成这一帧身体所在的体积，并写明头顶、脸或胸口朝哪边。下缘、暗区、画面边缘没有被当成出发地点
- [ ] 伸手前的朝向连续。上一个朝向背对要碰的人时，先写原地转身、脚停住，再写抬手；不要做里禁止还背对着就伸手
- [ ] 被碰到的袖口、皮肤、手写着图N。没有「那只袖口」「袖口和皮肤」这种不带图号的回指
- [ ] 可贴入没有「眼睛落在」「眼睛先落在」。观众第一眼写成对焦，并写明景别保持，或写明本镜就是特写、大特写、插入、手部近景；角色视线写成「图N的视线」
- [ ] 由分镜转写时：可贴入只写本镜，没有场号对照、跨场呼应、全片总谱、剧情背景梗概
- [ ] 用户没要 IR 时，没有输出英文三字段
