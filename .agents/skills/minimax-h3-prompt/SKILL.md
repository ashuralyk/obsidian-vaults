# MiniMax H3 提示词

写任何 MiniMax H3 / 海螺 / Hailuo / MiniMax Design 提示词之前，先读本技能与 [reference.md](reference.md)。禁止套用 Seedance 的整数秒分镜模板。

权威来源：

- 产品手册：[MiniMax H3 模型 - 使用手册](https://vrfi1sk8a0.feishu.cn/wiki/FIWjwgL33ipnkekzk30crmKUnIh)
- 规格与入口：[视频生成](https://platform.minimaxi.com/docs/guides/video-generation)
- 案例：[H3 亮点功能示例](https://platform.minimaxi.com/docs/guides/video-prompt)
- 英文结构化改写（仅 Context-IR / API）：[base](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_base_en.md) / [ref](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_ref_en.md)

## 模型分流

- MiniMax H3、H3 Max、海螺、Hailuo、MiniMax Design、全能参考、首尾帧 → 本技能。
- Seedance、即梦、火山方舟 → `seedance-prompt`。
- 用户没点名模型时，先问用哪套；不要默认写成 Seedance。

H3 默认产出 **4–15 秒一条成片**，不是 30 秒一段再向后延长。H3 Max 为 5–15 秒。时长只接受整数。

## 硬约束

1. 把模型当成视听一体的内容生产者：画面、动作、镜头、对白、音效、BGM 写在同一条提示词里。
2. 先定模式，再写词。文生、首/尾帧、全能参考的素材角色不同，不要混用 `first_frame` 与 `reference_image`。
3. 提示词用完整中文句子，不要堆英文关键词。台词、歌词、屏幕上的字保留原文，不要翻译。
4. 有参考素材时，按上传顺序写成 `图1 / 图2 / 视频1 / 音频1`，并写清参考的是外形、场景、道具、动作、运镜、节奏、音色还是整段声音。**可贴入正文**里人物、地点、道具只用 **图N** 指代，不要用「他」「她」「他们」「她们」代替图号；不要写剧本人名、场景专名、P-/L-/A- 内部代号（代号只出现在交付文件的「素材」行供上传对表）。台词、屏幕字、道具印刷字保留原文，但说明「图几开口」「图几锁屏幕」。同一房间要切反打或顶视时，主视图、反打、顶视分开绑定，写明各是哪个角度；反打和顶视从主视图垫图生成，不要用文字另起一个房间。全能参考最多 9 张图，这场戏不切反打就不要为了凑视角占额度。
5. 一条提示词只装得下一件主事件。15 秒里不要塞预告片式多场戏。
6. 负向控制写具体、可观察的画面或声音，不要空泛的「高质量 / cinematic / 精美」。
7. 默认交付 **可直接贴进海螺 / MiniMax Design 的整段中文提示词**。只有用户明确要 Context-IR 或 API 英文改写时，才改用英文三字段 / 六字段。
8. 可贴入词只描述**本镜**可见的画面与声音。不要写全片调色总谱、场号对照、跨场呼应（例如「绿色只出现在第×场」）、剧情背景梗概；全片纪律放在分镜文档对照区，不重复进每条 H3 词。

## 整体公式

```
[规格] 时长 + 画幅 + 画质意图
[绑定] 图N / 视频N / 音频N 各负责什么、不负责什么
[主体] 谁或什么，外形锁定
[场景] 在哪，光线、材质、风格、气质
[运动] 按时间顺序发生的一件事，含人物反应
[镜头] 景别、机位、运镜；需要时才写幅度和速度
[声音] 环境音、动作音、台词原文；不要配乐时写明不要旋律、不要垫乐；或写明 BGM
```

可贴入的成稿把以上内容收成连贯段落，不要输出成标签列表。规格和绑定放在最前。

## 分镜缩写要译成看得见的过程

分镜对照可以保留摄影组的缩写。可贴入要写成模型演得出的过程和亮度。缩写留在对照区，不要原样贴进提示词。

**画面左右。** 写「画面左侧」「画面右侧」「从画面左边缘伸进画来」「从画面右下边缘伸进来」。左右以观众面对画面为准。不要写「画左」「画右」「画下」。模型会把这两个字对调，或当成演员自己的左右手。

**没做完的动作。** 写到停住的那一帧：手伸向手腕，指尖靠近，在碰到皮肤之前停住。不要写「将扣」「即将抓住」「接触尚未发生」。模型会把「将」和「尚未」做成已经抓住。停住的动作要在「不要做」里再禁一次：不要碰到，不要抓住。

**幅度。** 写结果：「很小的一步，迈完就停」「轻轻摇过，大约十五度，人一停镜头就停」。不要只写「半步」「轻摇」。模型会走成一整步，或只晃一下。

**亮度词。** 浅灰、深灰、亮明、阴暗是曝光，不是雾，也不是衣服或道具的颜色。人写成「打在图N身上的光保持浅灰亮度，雨比图N更亮」。物写成「纸面保持浅灰亮度，四周更暗」。人身上用了灰色亮度时，同一句写上「不要把画面罩成灰雾，也不要改图N衣服的颜色」。不要写「处在浅灰中」，也不要写「这一镜的光是人物浅灰、雨幕亮明」。

有参考图时，仍然不要重描五官和服装。亮度只写光落在谁身上，不写这个人变成了灰色。

## 元规则

下面几条管全部可贴入，分镜对照可以继续用人物名字供人对表。

**人称写成图号。** 可贴入正文不写「他」「她」「他们」「她们」。这一镜「素材」行里已经绑定的人、场景、道具，句子里写对应的图号。图号只认这一镜的上传顺序，不沿用上一镜。同框的人写成「图1和图2」，不写成他们。没有参考图的画外声，把「画外的男人」或「画外的声音」再写一遍，不改称他或她。台词原文、屏幕上的字、道具上的字保持原样，里面的 he、she、她不改。

**眼睛落在要写成镜头。** 「眼睛落在」「眼睛先落在」不写进可贴入。分镜里的第一眼是观众先看见哪里，模型会把它读成角色自己看向那里，或者读成切到特写。转写时写成对焦，并带上本镜已经确定的景别。本镜不是特写、大特写、插入或手部近景时，写「对焦先落在……。景别保持〔本镜景别〕，不切到特写，也不推近。」本镜本身就是特写、大特写、插入或手部近景时，写「本镜保持〔景别〕，对焦在……，不要再切近，也不要推。」对焦从一处移到另一处，写「对焦先落在……，再落到……」，并写明不切镜、不推近。角色自己的视线另写「图N的视线落到……」，不用眼睛落在代替。第一眼的落点如果不是角色正在看的东西，在「不要做」里再禁一次：不要让图N把视线转到那个落点。

**裁切不是改世界。** 分镜写某人不拿某件道具时，先回剧本和相邻镜确认谁在持有。持有人这一镜不入画，可贴入只写物体留在画面里的那一段。不要做里禁止把被裁掉的部分画进来，也禁止入画的手去碰它。需要支撑的物体包括撑开的伞、端着的杯子、拉开的门。看得见的人都不许碰它时，先回答它靠什么停在那里、观众看见哪一段，再写句子。伞由画外的人撑着、这一镜只留伞面时，写成「画面里只看见黄色伞面，下沿停在画面左侧，伞柄不进入画面」。不要写「伞柄空着」「柄上没有手」「不要把伞柄放进任何一只手里」，也不要把一只握柄的手放到画面边缘外面。持有人的名字留在分镜对照。

**这一帧的身体写全。** 模型只有这一句，不共享分镜里已经排好的挡位。人从哪里出发，写成这一帧身体所在的那一块体积，并写明头顶、脸和胸口朝哪边。构图上的一条边不是起点。下缘、暗区、画面左侧是机位和剪点留给摄影组的标记，留在分镜对照。分镜写「从伞下冲出」时，不要收成「从伞的下沿出来」。下沿是伞布的边，模型会让人贴着伞布外侧走进来。写成「这一镜的第一帧，图1站在黄色伞面的正下方，头顶还在伞布下面，再朝画面右侧走出伞面」。

下一步要碰到另一个人时，先看上一个朝向还指不指向那个人。脸和胸口朝着画面一侧、后背朝着要碰的人，就先写原地转身：转到面朝那个人，脚停住，然后才抬手。不要把伸手直接接在朝反方向迈步的后面。不要做里再禁一次：不要还背对着那个人就伸手。

被碰到的那一截身体带上图号。去掉剧本人名时，把所有者写成图N。不要改成「那只袖口」或「袖口和皮肤」。那只、这只指不回上一句。这一镜刚被对焦的往往是伸手的人自己的手腕，没有图号的袖口和皮肤会贴到这个人身上。写成「图4的袖口，以及图4袖口下面的皮肤」。

## 四个要素

| 要素 | 写什么 | 失败写法 |
| --- | --- | --- |
| 主体 | 外貌、服装、体态、关键道具；同框两人写身高差。有图则绑图，运动句不再描写五官和服装；无图则写死不可改的规格 | 「一个美女」「那个年轻人」；有图仍把脸和衣服再写一遍 |
| 场景 | 空间结构、时间、光线、材质、风格（电影感、真人实拍、2D、3D、粘土、水彩、胶片、国风等）。浅灰、深灰、亮明写成落在谁身上的亮度。要切反打时，反打和顶视从主视图垫图来，并写明是同一空间的哪个角度 | 只写「高级质感」；「这一镜的光是人物浅灰」；「处在浅灰中」；反打只靠文字形容，房间会被重造 |
| 运动 | 从这一帧的体积和朝向，到下一个体积和朝向。方位写画面左/右。朝向背对要碰的人时，先转身再抬手。被碰到的袖口、皮肤、手写图N。没做完的动作写到停住。内心戏写看得见的微表情（眉心、视线、嘴角、停顿）。台词长过一个反应时，切到听者或一件道具 | 「从下沿出来」「向画右半步」「将扣腕」「那只袖口」；迈步之后直接伸手；并列一堆互不衔接的动作；整段只有说话人的脸；充血、泪如雨下、大汗淋漓 |
| 声音 | 环境、物体、口型内对白、画外音、角色能听见的音乐、观众才能听见的 BGM。不要配乐时写「只保留现场说话、环境音和动作音，不要旋律、不要垫乐」 | 完全不写声音；只写「无 BGM」仍会被铺上钢琴；把对白写进 BGM |

镜头不是第五个标签，而是把运动落到画面上的方法。细则见 [reference.md](reference.md)。

## 三类模式

先判断入口，再写提示词。

| 模式 | 素材 | 提示词重点 |
| --- | --- | --- |
| 文生视频 | 只有文本 | 从零建立主体、场景、运动、声音；画幅必填，不能写自适应 |
| 图生视频 | 文本 + 首帧和/或尾帧 | 不要复述静帧。首帧：从图里的状态往前发展；尾帧：先写合理前史，最后落到图；首尾帧：写中间路径，优先一镜插值 |
| 全能参考 | 文本 + 图/视频/音频，合计 ≤12 个文件 | 每条素材只承担一种职责。外形用图，动作用视频，音色用音频。写明「参考什么、不参考什么」 |

素材上限（全能参考）：图 ≤9，视频 ≤3 且总时长 ≤15 秒，音频 ≤3 且总时长 ≤15 秒。单段视频/音频 2–15 秒。

## 每次必须输出

1. **模式与规格**：文生 / 首帧 / 尾帧 / 首尾帧 / 全能参考；时长；画幅。
2. **素材清单**：无素材则写「纯文本直出」。
3. **可贴入提示词**：一整段中文，开头含时长与画幅，随后绑定、故事、镜头、声音。
4. **不要做**：3–6 条，针对换脸、换装、跑题、多场戏、乱加字幕或乱加 BGM。这几条只写进可贴入的最后一段，用「不要做：」起头，和前面的正文隔开。不要在代码块外再列一遍。只放在代码块外面时，用户复制可贴入会把禁令丢掉。

用户只给模糊题材时，先问模式、时长、画幅、有无参考，再写词。不要直接开写。
