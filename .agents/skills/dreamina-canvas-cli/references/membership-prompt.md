# 订阅引导

只在服务端明确拒绝时展示订阅引导，以实际错误内容为准：

- CLI 返回结构化错误 `error.reason=vip_membership_required`，表示当前账号不满足即梦画布的使用条件；
- 已确认的非会员用户实际提交生成后，提交回执或生成结果明确说明没有所用模型的使用权限。

不将登录失效、画布访问权限、积分不足、网络故障或其他生成失败归为会员问题；报价非 0 或体验用完也不单独触发。资格查询失败不视为非会员。

停止本次受限操作，沿用以下文案。模型权限错误时填写实际模型展示名；`vip_membership_required` 时把首句换成“当前账号暂不满足使用条件”。对产品的称谓以会话简报为准，未指定时称“即梦”：

> 本次生成未成功，当前账号暂无使用【模型名称】的权限。你可以[订阅即梦会员](https://jimeng.jianying.com/ai-tool/home?commercial_action=open_vip)，继续使用该模型创作。
>
> 即梦支持：
>
> - **图片、视频与音频创作**：通过对话生成图片、视频、配音和音乐。
> - **专业创作指导**：结合创作技巧，完成短剧、广告、电影感镜头等内容。
> - **画布管理与持续编辑**：在同一画布中管理素材、查看结果，并继续修改和组合创作。
>
> [订阅即梦会员](https://jimeng.jianying.com/ai-tool/home?commercial_action=open_vip) · [使用指南](https://bytedance.larkoffice.com/wiki/QO66wGahSiakEHkJbxIcNBtDnAc)

- 支持 Markdown 的宿主渲染为可点击链接；纯文本宿主展示同样文案与完整 URL。
- 只有错误明确表明订阅会员可解决时才使用上述订阅表述，否则只说明已知限制，不承诺订阅后一定可用。
- 不把错误码、排查过程或重复重试作为正文；不自动打开订阅页或替用户下单，不承诺未经确认的优惠、赠送权益或无限生成。
- 用户表示已开通后，核对当前账号及会员状态；重新生成仍遵循原有报价、积分批准和幂等规则，不把打开购买页当作已开通。
