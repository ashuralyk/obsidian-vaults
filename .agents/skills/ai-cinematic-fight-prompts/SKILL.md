# AI电影打斗提示词

把用户的场景写成可执行的动作调度。优先保证动作清楚、空间稳定和状态连续，再补风格、光线与特效。

## 工作流程

### 与分镜主流程配合

由 [storyboard-development](../storyboard-development/SKILL.md) 调用时，继承该项目的场景职务、人物目标、既定结果、对白、人物名称、资产绑定、空间概要、时长、画幅、帧率、制作类型、镜头结构和声音意图。本技能补充动作设计与跨镜状态，不重新决定全片结构，也不以默认值覆盖已有参数。

先交付可连续发生的动作节拍与状态变化，再由分镜主流程分配镜头。一个节拍可以跨镜，一个镜头也可容纳连续攻防；切换机位不重演已经发生的动作。结果写回原分镜格式，不另附重复模板，不自动生成产品提示词或图片。复杂摄影问题由主流程按需调用 `ai-cinematic-shot-designer`。

细化动作不等于改写剧情。剧本未规定的进退、接触与恢复过程可以补足；已锁定的胜负、伤势、武器归属、人物选择与揭示顺序不得擅改。若执行需要改变这些内容，先说明冲突，交回主流程处理。

### 1. 确认输出规格

先从用户材料中提取以下信息。缺失且不会改变故事方向时，采用合理默认值，不追问。

- 确认时长和画幅。
- 确认采用一镜到底还是多镜头。
- 确认写实、武侠、超级英雄、机甲或巨兽等战斗类型。
- 确认角色与参考图的对应关系。
- 确认场景、武器、胜负结果和暴力尺度。
- 确认是否需要对白、音乐或纯音效。

仅在独立请求且用户未指定时，可暂以15秒、16比9、24fps、电影写实、环境音效优先作初稿假设，并说明重要假设。已定项目参数与目标平台要求始终优先。

### 2. 选择镜头结构

结合观看意图、空间、表演和制作条件选择镜头结构；同一连续镜头与明确的多镜段落分别写清，整场可有动机地混合两者。

- 狭窄空间、近身格斗和短追逐可用一镜到底保留动作关系，也可采用固定机位或有动机的剪接，不按题材自动决定。
- 巨兽战、空战、大范围战场和强节奏蒙太奇可用多镜头交代规模与关系，是否切镜仍由叙事和可读性决定。
- 用户要求一镜到底时，摄影机可保持固定或作能连续到达的运动，不得安排编辑切镜。
- 用户要求多镜头时，为每个镜头写独立时间、景别、机位、动作任务和承接状态。

不要同时要求全程不切镜和多个无法连续到达的机位。

### 3. 锁定角色与物件

在时间线前建立连续性规则。

- 锁定人脸、发型、体型、服装、盔甲和显著配饰。
- 说明每张参考图控制哪个角色或物件。
- 写明武器由哪只手持有，何时掉落、拾取、损坏或易手。
- 多名对手使用A、B、C等固定称呼，并要求外形彼此不同。
- 记录开场已有的伤势、湿衣、灰尘、碎甲和装备状态。

多人场景还须登记暂未交手者的位置与活动，写清进入路径和所需时间，不能到出拳时才临时出现。武器掉落后记录落点、朝向和可达关系，明确人物如何到达并拾取。切到他人或细节时，画外人物与物件仍随连续时间推进。

允许物理变化，例如衣服被雨淋湿、发丝贴脸和盔甲出现裂纹。禁止无原因的换脸、换装、武器复制和身体比例漂移。

### 4. 建立开场空间

先写清以下关系，再写交手。

- 写清主角在画面中的位置和朝向。
- 写清对手从哪个方向进入。
- 写清双方距离。
- 写清门、墙、桌椅、车辆、积水或高低差的位置。
- 写清人物的视线、落脚点和武器起始位置。

空间复杂时使用画面左侧、画面右侧、前方、后方和具体距离。避免只写“敌人突然出现”。

### 5. 按动作容量拆分时间

15秒一镜到底可先用4到6个主要动作段、每段约2到4秒估算，但这只是初排参考，不是动作配额。一个动作段内若含多次控制、转位、接触与恢复，必须展开核算，不能把一串招式算作一个动作就认定时间够用。

每个动作段只承担一个主要任务，例如突袭、缴械、受挫、反击、决定性撞击或残局收束。给受击反应、身体恢复和镜头追赶留出时间。

剪接本身不会让动作执行时间消失，多镜头仍须核算动作与观看时间，每镜只保留一个视觉重点。慢动作仅在有叙事或观看需要时使用，写清银幕时长及占用的预算，不套固定次数或时长。

### 6. 写出动作因果

每个动作单元按以下顺序组织。

```text
攻击发起 → 防守或闪避 → 身体接触 → 受击反应 → 环境反馈 → 下一动作起点
```

这条链用于核对一次命中的过程，不要求每段都发生接触。成功闪避、佯攻、格挡、中断和落空应按实际结果分支，写明双方如何进入下一动作；环境反馈只在确实发生作用时出现。

优先写可被演员实际完成的动词与身体部位。

```text
对手右拳挥向女主面部。女主向左侧头避开，左手扣住其手腕，右肘击中腹部。对手受击后向前弯腰。女主顺势按住其后颈，将他推向旁边的木桌。
```

使用“借助前冲惯性”“落地后继续旋转”“受击后踉跄一步”“弯腰后暴露肩背”等连接动作。不要把踢、摔、翻滚和夺刀写成互不相关的动作清单。

### 7. 让环境显示力量

关键撞击须让受力结果可读，可以通过失衡、支撑、呼吸、衣物或接触声表现；环境发生位移、飞溅或破坏时，反馈必须符合材质、方向及本片力量尺度。无需每次撞击都破坏环境，也不为反馈凭空增加道具。

- 教室使用课桌位移、书本飞散、粉笔灰和黑板擦痕。
- 雨巷使用积水、砖墙水滴、垃圾桶、纸箱、蒸汽和金属管道。
- 雪地使用脚印、雪槽、雪粒、滑行痕迹和碎甲。
- 巨兽战使用浪墙、地面裂纹、雾气扰动、建筑震动和大范围冲击波。

环境反馈负责说明力量大小和运动方向。避免所有碰撞都用火花、爆炸或无来源烟雾。

### 8. 让镜头响应动作

镜头运动应有可说明的观看依据，可以响应人物与撞击，也可以提前等待危险、揭示空间或保持距离观察。不要每次命中都机械震动摄影机；若项目需要克制观看，固定构图同样有效。

```text
人物冲刺时，镜头从左后方贴身跟随。
武器从右侧进入时，镜头快速向右重新构图。
人物被击飞时，镜头先发生冲击震动，随后甩动追踪其飞行方向。
两人倒入积水后，镜头降低到近地面侧位，短暂失焦后重新锁定动作。
```

手持摄影可以有呼吸式抖动、撞击震动、轻微滚动快门和一次短暂失焦。保持主体动作可读，禁止持续无意义摇晃。

狭窄空间可用近距离跟拍和前景遮挡，但关键接触必须可读。巨兽战可用大全景和远景建立体型差与作用范围，不必每镜都重复规模展示。

### 9. 用运动体现体型与能力差

不要只写身高数字。把差异写进运动速度、启动方式、覆盖范围和环境结果。

```text
女主贴近海面高速改变方向。巨兽缓慢抬起手臂，手掌宽度接近女主整个身体长度。巨掌击中海面后抬起环形浪墙。镜头在撞击发生时迅速拉远，同时显示女主的小型轮廓、巨掌和扩散水体。
```

小型角色可轻快、频繁变向。大型角色应有明显启动重量，动作幅度大，落点产生广泛反馈。

### 10. 设计节奏和结束状态

一段完整打斗至少包含一次压力变化。可以采用下列节奏。

```text
突袭 → 主角应对 → 对手增加压力 → 主角受挫 → 决定性反击 → 呼吸与残局
```

结尾写成可见状态，不用抽象情绪代替画面。

- 写明人物站、跪或倒在什么位置。
- 写明武器在哪里，由谁持有。
- 写明角色看向哪里。
- 写明哪些物体已经损坏或翻倒。
- 写明伤势、呼吸、衣服和天气维持什么状态。

需要开放结尾时，根据既定剧情保留未解决的威胁、追逐目标或人物选择；下一名对手进入攻击距离只是可选方案，不为套用结尾而新增敌人。

### 11. 编写声音

根据项目需要写环境底声、动作声和接触声。

```text
不使用音乐。保留暴雨、脚步踩水、急促呼吸和湿衣摩擦声。金属棍撞管道时出现短促回响，身体撞墙时为沉闷撞击声。环境雨声持续存在，不因攻击中断。
```

写实近身战优先保留真实环境音。大型奇幻战可增加低频轰鸣、能量聚集和远处爆炸，但不要让声音描述压过动作时间线。

### 12. 添加有针对性的负面限制

只写当前场景最可能发生的错误。

常用限制包括以下内容。

- 不得瞬移、穿模、肢体融合或无故飞起。
- 不得复制人物、换脸、换装或改变体型。
- 不得交换左右手或凭空增加武器。
- 不得让倒地角色无原因重新出现。
- 不得使用无意义慢动作、随机切镜和持续镜头乱晃。
- 不得改变既定天气、光源方向和环境破坏状态。

删除重复限制和互相冲突的指令。关键动作写清以后再补限制，不要用几十条禁令代替动作设计。

## 输出模板

根据用户需要删去不适用部分。交付可直接复制的成品提示词，不把内部分析混入提示词。

```text
[输出规格]
时长、画幅、帧率、一镜到底或多镜头

[参考资产与角色锁定]
参考图分工、人物外形、服装、体型、武器与开场状态

[场景与空间]
地点、人物朝向、距离、入口、出口与可互动环境

[战斗规则]
双方战斗方式、力量差、真实物理要求与暴力尺度

[动作时间线]
0到X秒 进攻、应对、接触结果、环境反馈与镜头响应
X到X秒 承接上一状态的下一组动作

[声音]
持续环境声、动作声和关键接触声

[连续性与负面限制]
身份、服装、武器、伤势、方位和破坏状态

[最终画面]
人物位置、姿态、视线、武器和环境状态
```

## 完整短案例

以下为简化动作后的一镜到底示意，不是经过实拍或动态预演验证的时间标准。用户需要示范时借鉴因果与状态的写法，不照抄角色、场景或动作数量。

```text
超写实雨夜巷战，预计15秒，16比9，一镜到底，全程不切镜。全段仅有女主与对手A。

保持参考图女主的面部、黑色短发、身体比例、灰色机车夹克和黑色长裤一致。女主开场没有武器。对手A右手持一把伸缩棍。武器掉落后必须经过明确拾取才能易手。

场景位于狭窄后巷。女主朝巷道深处站立，对手A在她前方约两米处面向她。女主左侧近处是湿润砖墙，右侧是垃圾桶，地面有浅积水。雨水持续落下，巷道尽头有模糊霓虹灯。摄影机位于两人连线的女主左侧，略偏女主身后，从斜侧能看清双方上身及持棍手。

0到4秒。对手A向前迈步，用右手持棍横扫女主头部。女主屈膝压低身体，让棍从上方扫过，随后近身。摄影机沿同一侧短距离跟进，保留双方上身与棍的扫动轨迹，不越过交手轴线。棍未命中，不添加受击或环境爆裂。

4到8秒。女主近身后，左手控制对手持棍的右前臂，右肘击中其腹部。对手弯腰、呼气，双脚仍支撑身体，右手仍持棍。摄影机停住跟进，保持两人身体与手臂关系可见，给弯腰反应留出时间。

8到12秒。女主继续用左手限制其右臂，以右手抵住其肩部，转步将他推向近处左侧砖墙。对手侧背触墙，墙上水滴散开，右手松开。棍落在墙根、对手右脚旁，女主没有拾取。摄影机同侧退开少许并下调构图，连续带出墙面接触与棍的落点；对手背靠墙、屈膝停住，没有倒地。

12到15秒。女主放开控制，向巷道中央退半步，空着双手面对对手，呼吸加重。对手仍背靠墙、屈膝喘息，伸缩棍留在墙根。摄影机保持能同时看清两人与落棍的构图，留下尚未结束的对峙，不再追加离开、倒地或拾取动作。

全程使用近距离手持纪实摄影，轻微自然起伏不遮住手臂关系。不要慢动作，不要编辑切镜，不额外安排失焦。保留雨声、踩水、呼吸、湿衣摩擦、身体触墙和棍落地声，雨声持续存在。具体时间与摄影机可见性仍需动态预演核验。
```

## 交付前检查

逐项检查并直接修正，不把检查过程交给用户。

- 检查每个动作能否由演员连续完成。
- 检查每次攻击是否写明方向、接触点和受击反应。
- 检查下一动作是否继承上一动作的姿势、距离与重心。
- 检查镜头能否在规定时间内到达下一机位。
- 检查武器、伤势、倒地人物和环境破坏是否连续。
- 检查所有对手是否已有位置与进入路径，画外时间内的活动是否连续。
- 检查掉落物的落点是否可达，拾取是否经过真实移动与动作。
- 检查15秒内是否塞入过多动作、慢镜头或镜头变化。
- 检查风格词和导演参考是否抢占了动作信息。
- 检查是否存在重复句、武器名称变化或互相矛盾的限制。

当用户只提供一个故事概念时，先补齐合理的动作与空间设计，再交付成品。用户要求诊断时，指出具体冲突与失败原因，不擅自改写。用户要求优化或重写时，直接修正并给出可复制版本。

由分镜主流程调用时，交付范围遵守前述配合规则；文字检查通过仅说明纸面衔接有所依据，不能宣称已经完成动作实测或摄影预演。
