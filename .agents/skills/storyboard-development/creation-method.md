# 从观看意图到连续镜头

## 何时读取

建立视觉策略、寻找主镜头、设计关键揭示或修订镜流时读取。本文补充生成与取舍，不替代轴线、剪接、光意图和双评分门槛；属于现有知识的流程归纳，不是新来源论述。

## 固定剧本，再选择如何观看

记录指定版本、覆盖起止位置、物理动作顺序、准确对白与屏幕字、知情差和揭示顺序。比较方案时使用同一份剧本，避免新旧剧情混淆镜头效果。

按时间顺序写明观众已知什么、还在误认什么、希望或担心什么、哪个可见事件才能改变判断。写进现有场景拆解与散文分镜，不另建重复表。不能让人物提前看见秘密，或用新增反应替剧本作出选择。

## 把视觉形容词落实为空间和事件

“压迫”“亲密”只是预期效果。继续决定谁在哪里、面向哪里、谁能接近谁、什么被遮挡、哪个动作改变关系，以及观众何时才看见。然后选画框边界、主体大小、距离、高度、焦距和切点。导演走位须标作制作方案，不改剧本的动作发起者或先后。

用具体前后画面证明意图，不把空位、门框或冷色当作固定心理含义。焦距以画幅和机位距离为前提；没有勘景尺寸就说明假设与需核验的视线，不把毫米数当效果保证。

## 关键段落比较不同镜流

对支点、揭示或反复失效的段落，试两三个短小的连续镜头序列，实际写出每镜事件与切入时机。让观众距离、画外空间、调度或切点真正不同，不只换景别。

所有方案遵守同一剧本揭示顺序，不能靠改剧情取胜。说明观众跟随谁、等待多久、哪里可能误读，以及覆盖与制作代价；原方案也可胜出。选定前用“看见什么、听见什么、因此期待什么”顺读一次，找出漂亮单帧之间不成立的连接。

依据是《每一格只承担一个视觉主意》《停顿与留白是表演的时间预算》及 reference 的支点、镜流和剪口方法。主导视觉主意限制注意力竞争，不禁止一个镜头容纳连续动作；注意力转移时写清过程。

## 写成可以检查的画面

补机位和概要图，检查相机能否实际看见主体，人物有没有瞬移，过肩是否挡住关键动作，画外声音是否使人物提前获知信息。剪口两侧可保留拍摄动作重叠，但成片账不能重复计算。

逐字将对白和屏幕字分配到镜号，核对遗漏、增写与次序。允许画外说话，不得因镜头缩短删改台词。按自然说话、走位、文字阅读和反应分配时长；保险镜头不计主剪辑总长，备用末帧不与主版本同时相加。超过十五秒的连续镜头沿用一号并分段，不靠多切镜填满技术上限。

人物行动与倾听承载表演，不机械给每句台词配情绪或眨眼。停顿是可用的表演时间，不能承诺演员在固定秒点产生情绪。

## 用视域和连续时间复核物理方案

原文引用列证明文本没有漏抄，不能证明相机拍到了动作。将关键事件对应到实际“画面”字段：哪里看见发起、变化和结果；若关键事实只出现在引文或说明里，尚未落实。关键道具与身体局部须在所定景别可读，不以“第一眼落点”代替可见尺度。

复杂空间用同一概要图给出可核验位置和相机朝向，检查视域、墙体和门扇遮挡，以及各镜银幕方向是否与投影相符。相机相同、焦距相同、主体距离相同却宣称景别变宽，须说明是否另拍、重架或改变裁切；不能以“微调”隐去一个新机位状态。没有实景尺寸时把结论标为纸面可行，不宣称验证通过。

会持续运动的门、车、倒计时或正在倒出的水，须从动作开始一路核算到结束，包含切到反应镜的时间。不能在切走后默认它暂停或复位；需要阻尼、停靠或操控时标明实际制作安排，并核对是否改变原剧情。物理安排尚未成立时保留阻断，而不是只写“现场注意”。

如果已经给出相机坐标、目标点、焦距和画幅，就用 [scripts/check_camera_view.py](scripts/check_camera_view.py) 核验关键身体或道具边界点的投影，不能仅凭“广角足够宽”作通过判断。以米统一世界坐标，焦距与有效传感器宽高用毫米；默认36×20.25毫米对应16:9全画幅有效区。全画幅等效焦距与其他传感器不能混用。一个人脸中心入框仍可能裁掉整张脸，因此须同时检查上下左右边界及运动端点，给留白余量。

脚本读取 JSON，所需字段为 position、target、focal_mm 和 points；每个 point 含 name 与三维 position，可另设 sensor_width_mm、sensor_height_mm 和 up。用 `python3 scripts/check_camera_view.py 场景相机核对.json` 运行，退出码0表示所给点在理想画框内，1表示有出框点，2表示输入错误。脚本不验证墙体、遮挡、地面碰撞或镜头畸变，点集通过不能升级为整镜通过。身体过门另检查长度、宽度及转向后的整体包络，不能用中心线或单个门隙宽度代替通行检查。

压缩版是一条独立的完整镜头序列，须重新列镜号映射、入片时长、机位状态和遗漏代价。不把素材拍摄长度混入成片账，不重算同一段时间，也不直接假设原局部近景机位能拍全新宽景。先让压缩版自己成立，再说它与主版保住了哪些相同效果。

## 修订后检查损失

区分理解或执行缺陷、可争论选择与个人偏好。针对主要问题重排整段镜流，再比较：关系是否更可见；揭示是否清楚却过早；特写是否挤掉双方反应；覆盖是否打散节奏；空间是否清楚却消除原有不安；声音是否重复解释画面。

交付实际新序列，不只说“减少正反打”。删镜后重读相邻镜头和声音，增镜后重算时长、机位与拍摄时间。硬指标通过只说明可执行，不自动证明视觉表现力提高。

## 评估与停止

先执行 [quality-checklist.md](quality-checklist.md) 的实际镜流检查。隐藏职务解释顺读后，比较可疑镜头保留与删除的损失；连续景别只在信息、关系或观看效果失效时构成问题。高负载镜分列对白、动作、阅读、注意力转移和反应预算，明确哪些可重叠，不能把估算当实测。

先裸读再查硬指标，双评分分开，并保留裸读与对表两段记录。裸读只凭模型自身的观影与剪辑经验写下第一反应，量表在记录落盘后才介入，不能覆盖裸读发现的具体问题。接受修改须引用具体镜号与前后差异，也说明反对意见；镜头更多、字段更齐全或自评分上涨不能证明更有表现力。连续两轮无可定位收益或只是偏好摆动时保留较有依据版本；未过硬门槛仍须报告未就绪，不能以平台期当通过。

外部仪器维持原开关；审稿者先裸读后对表，两段记录随独立性一并保存。同源新上下文可以揭露缺拍，不是非同源或成片验证。反复出现具体短板才定向补知识。

## 怎样保留案例

保留固定剧本、不同实际镜流、选定序列、声画连接、未选方案的优势及适用边界。保留连续镜头，不只收集漂亮单帧。全文留在 Audit，技能只保留可迁移机制。
