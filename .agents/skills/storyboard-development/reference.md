## 将剧本决策转化为视觉策略

不要从类型形容词凭空发明视觉风格。把上游决策转成可以逐镜检验的规则：

- **形式**：复原型形式可从稳定可读的秩序开始，让压力将其打碎，再恢复一种已经改变、而非原样复归的秩序。反讽或反复原形式不得在结尾悄悄恢复视觉和谐，除非反讽本身需要如此。
- **观众位置**：与人物同步时，倾向采用人物高度、允许观众进入其视线，并让信息在人物得知时到达。领先人物时可先揭示威胁或背景行动；落后人物时应隐去原因，使用局部视野或画外信息。观察或审判会增加距离，让行为完整发生，而不靠解释性特写。
- **情感曲线**：把上升与低谷转化为距离、时长、稳定度、空间深度和镜头密度的变化。不要把每个低谷都等同于手持，也不要每逢转折都推近；选择有限语法，并为破例保留力量。
- **关系弧**：用共享画框、分隔、障碍、机位高度、焦距对比和移动权限，表现两人靠近、疏远或交换权力。
- **前景 / 背景线**：决定每个运动段落由哪条线主导画面。背景关系在转为前景线之前，可以先存在于空间纵深或反应中。
- **最终意象**：知道结尾后再设计开场意象。重复构图必须呈现关系变化，而不能只重复画面。

视觉总谱必须包含：

1. 一句话视觉命题；
2. 默认摄影机距离、高度、焦距范围、稳定度、移动权限、空间深度和光线 / 背景倾向；
3. 观众位置规则与主观性归属；
4. 各运动段落的递进；
5. 人物 / 关系规则；
6. 两至三个具有开端、变形和兑现的母题；
7. 禁用项及明确命名的破例。

这是架构层，不能替代构图、声音、蒙太奇或日后进入知识库的类型专门知识。

## 视觉成分结构

不能用摄影机规则清单冒充视觉结构。选择两至三个足以承载全片的视觉成分：

- **空间**：深、平、有限或含混；另行说明画框表现为开放还是封闭。
- **线条与形状**：主导方向、秩序 / 混乱、稳定 / 不稳定轮廓。秩序与混乱不必只写形容词，可落成线条密度、对称与倾斜、负空间是否被「管理」（概念：秩序与混乱可写成视觉性格）。
- **明暗与色彩**：对比范围、主体与背景分离、饱和度或色相递进。
- **运动**：主体运动、摄影机运动，或有意取消运动。
- **节奏**：镜头内部及剪口之间的交替、重复和速度。

每个成分选择一种结构：**恒定（constant）**、**递进（progression）**，或**指定事件上的对比 / 相似（contrast/affinity）**。恒定不等于中性：若开场建立了这种意义，持续的平面或深景空间都可能令人感到受困。递进必须有可观察的阶段。对比提高视觉强度，相似降低视觉强度；最强对比应留给配得上的节点。

故事强度曲线与视觉成分曲线应分别绘制。两者可以同向，也可以有意对位。若镜头方案中找不到所声称的曲线，本层即不通过。

## 正式画格前的导演侦查

- **这是谁的场？**明确观众主要进入谁的心智，即使另一个人物说得更多。
- **摄影机叙述者。**区分创作立场、叙述声音和物理视点。客观摄影机仍可好奇、严厉、诙谐或克制。主观摄影机分享即时感知；单纯视线主观镜头仍属第三人称，除非感知本身发生变化。
- **戏剧段落。**只在主导戏剧想法改变时分段，不要按每句台词或每个动作切段。
- **表演拍与叙事拍。**表演拍是演员可执行的行动；叙事拍是必须由调度或摄影机明确表达的重要故事推进。
- **场景支点。**找出场景仍可能倒向两边、随后开始确定方向的时刻。视觉峰值可以提前预示、正落支点，也可以等到反应再出现。
- **知情差（场级）。**分列观众、各主要人物、叙述者此刻各知道什么；标揭示点与隐藏点，且必须与剧本的揭示顺序一致。镜内威胁可见性用峰值菜单中的「威胁何时入画」，不与场级对表混层。
- **戏剧运动。**用一句话写明分开的人走近，或在一起的人走开；无关系变化的移动只算活动。
- **散文分镜或缩略图。**正式画格前，每句话或每格测试一个暂定镜头。句子顺序就是信息顺序；用这一遍发现缺拍和看不见的段落连接。

只有这些决策稳定后，才能开始正式分镜。

## 轴线与覆盖镜头规则

- **轴线作用。**180° 轴线保持银幕方向一致，使镜头可剪，也组织拍摄顺序：换角度通常意味着重新布光，因此同侧、同高度的镜头应集中拍摄。
- **合法越轴。**新视线可建立新轴线，例如人物入场或转向另一个人。演员跨过旧轴线，会在另一侧重新建立关系；重新交代空间的镜头可回到旧轴线。运动中，轴线跟随行进方向；同时存在两条轴线时，选择承载戏剧关系的那条。
- **三角机位基位。**工作半圆内包括斜侧单人（中景至近景）、主镜双人、过肩、视点单人（摄影机位于视线上）和侧面。常见组合为 A/C 单人加 B 主镜、A/C 过肩、A/C 位于视线上，或 A/C 侧面。只要轴线成立，景别与构图可以自由变化。
- **覆盖镜头是有代价的保险。**长轨道主镜头若可能失败，仍需反应镜头。每增加一个角度，都会占用复杂运镜也需要的布光与机位时间。按风险决定：儿童、连续性复杂的动作和表演不稳定的演员需要更多覆盖；能撑住长镜头的演员可以减少覆盖。
- **主镜头也用于排练。**覆盖搭建型场景可用宽幅主镜头以较轻表演建立空间，把最佳表演留给承载节拍的镜头。主镜调度与道具动作应简洁，便于过肩镜头匹配。
- **计划收紧。**在分镜上标明何时靠近、何时拉开。不要为整场计划每个角度；重复角度最终会被剪掉。

## 调度形态

双人场景（选择并写明站位形态）：

- 面对面：清楚、正式，也容易把关系拍平；
- 肩并肩，偶尔对视：陌生人、共同目标或回避正面冲突；
- 一方背转（抱臂、手插口袋）：拒绝、距离、控制；谁掌权仍须由行为决定；
- 两人各看不同方向：随意、注意力分散；看向对方的人会带领视线；
- 高低差（一坐一站）：表现权力，机位高度与焦距可进一步强化；
- 隔着障碍（桌、门口、窗）：可被打破的距离；跨越障碍就是转折。

三人及以上：

- **I 形**：人物排成一线；只有一条轴线，摄影机在一侧工作。
- **L 形**：两人在一条线上，第三人在斜角；拐角人物常成为关系铰链。
- **A 形**：两人面对第三人；选定轴线后，A 形仍可归纳为 I 型线。
- 大型群戏应归纳为一至两个中心人物及其轴线。五个人约可产生二十七种单人或组合镜头，只拍承载戏剧关系的组合，其余人物留在群体镜头中。
- 后发言者开口前，观众必须已经看见他的位置；否则先切到他附近的角度，让其他人转头看向他。

## 峰值镜头方法表

以下方法只用于转折拍。应把两三种方法合并进一个镜头，不要层层堆叠。每项后括号内为应读取的知识库概念。

**任何场景**

- 焦距、机位和人机相对运动必须一起选择；只改焦距而不改机位，会改变空间关系的真实感。（贵片感来自机位焦距和人机相对运动；换焦距时必须改机位）
- 机位高度决定观众站在谁的情绪上。每场都锁在眼平高度，会让影片彼此相似。表现权力时，强势一方可用较低、微仰、较短焦距；另一方用头高和较长焦距。（机位高度决定观众站在谁的情绪上）
- 演员动，摄影机才动；演员停，摄影机也停。人物离开而摄影机留下，银幕上便出现一个决定。（演员的动和停决定摄影机的动和停）

**对白、争执、爱情**

- 让距离形成形状：靠近、拉远或受阻。肩并肩时偶尔对视、绕行、边走边争论，以及仍能看见眼睛的侧面，都能让身体与视线留在同一画面中。（正反打清楚，也把关系拍平）
- 门、窗、桌等障碍与门槛把情感距离变成物理空间；跨越障碍就是转折。（障碍和门槛把情感距离做成可冲破的空间）
- 让身体承载未说出口的意思：转身背对、被拉回来、重新走入。随后用一个更紧的景别承接。（身体占位承担场面没说出口的意思）

**群戏**

- 先建立位置与视线，空间清楚后才使用特写。三个人可以共享一个镜头：桌子开放的一侧朝向摄影机，所有人向内倾，摄影机最后转向倾听者。（群戏先让位置和视线站得住）

**复杂运动**

- 写出镜头结束时观众必须知道的三件事：还有谁在场、他们的身体位于哪一侧、主人公此刻的脸。先固定末帧，再倒推；每次运镜都需要行走或视线作为理由。（复杂运动用来一次交代关系）

**登场、退场、揭示**

- 登场或退场的分量来自焦点停留时间和门框：从人群中出现、由背景走出、关窗、在摇镜中走远。（登场退场的分量靠焦点停留和门框）
- 优先使用连续揭示，如镜门、帘子、影子或视线转移，而不是直接切镜展示来者。

**情节转折**

- 认识发生转折时，让人物后退一步；观众不必被告知看见了什么，也能感到退缩。推近通常反而太弱。（情节转弯让人退开，不靠推镜头解释）

**悬念、追逐、惊吓**

- 威胁何时入画，决定效果是悬念还是惊吓。追逐者留在画外越久，通常比双方同框更紧张。（威胁何时入画决定这是悬念还是惊吓）

**打斗**

- 击中感来自长焦压缩距离并藏住接触点；受击者在正确时刻甩头。用慢动作检查。（打斗的击中靠长焦压缩和藏住的落点）

**地点**

- 地点可以在故事点内部自然出现，不必另拍独立定场镜头。（地点可以在故事点里被带出来）

**拍摄当天**

- 创意覆盖镜头应在早晨预排时确定；时间不足时，把方法合并成较短镜头，不要退回对称覆盖。（创意镜头要在预排里定，并服从当天剩下的时间）
- 给演员足够多的身体任务，让他们无暇自我检查，行为才会回到本能。（任务多到顾不上检查，表演才回到本能）

<a id="cut-check"></a>
## 剪接检查

检查连续性之前，先写清剪口设计：

1. **离开动机（Motivation）**：为什么现在离开——动作、视线、画面事件、声音还是时间？
2. **连接类型（Connection type）**：动作匹配、银幕位置交接、图形 / 形状匹配、概念并置，还是计划好的复合连接？
3. **新增信息（New information）**：入镜让观众看见或听见了出镜没有的信息是什么？
4. **声音时序（Sound timing）**：同步、声音先入、声音延续，还是有意静默？

若入镜没有新增信息，就继续保持当前镜头；只有重复本身改变情感、节奏或视点时才例外。

每个剪点都检查：

1. 银幕方向保持一致，或越轴已有依据（新视线、演员跨线、重新交代空间的镜头）。
2. 正反打之间视线匹配；近景与宽景保持相同视线方向。
3. 同一主体的相邻镜头约改变 30°，或有清楚的景别跳变。
4. 剪点处动作重叠：镜 N 结尾和镜 N+1 开头都包含用于剪接的动作。
5. 动作在镜头结束前完成；计划中不得在手势中途切断。
6. 对白覆盖两侧使用匹配角度与景别，除非有意采用不对称并已说明。
7. 一组正反打的视线空间与头顶空间一致。
8. 出入画方向连续：同一运动中，主体从画右离开后，应从下一画面的左侧进入。
9. 评分前把整份分镜当作预剪辑完整读一遍，先写下无约束的裸读记录，再打开量表；顺序见[盲评两段式](#blind-review)。

标准冲突时，按**情感 → 故事 → 节奏 → 视线轨迹 → 二维画面 → 三维空间**排序判断。这不等于允许忽略连续性；必须记录高阶收益，并保留足够的方位线索，让观众能够重新定位。

## 画格注意力检查

每个画格都必须回答：

1. 不论景别，这一格唯一的视觉主意是什么？
2. 视线首先落在哪里，哪种对比把视线引到那里？
3. 删除什么不会改变这个主意？
4. 负空间是在构框、隔离、等待或威胁主体，还是仅仅空着？
5. 局部最强对比是否留给最重要的信息？

全景可以成为地点或关系的“特写”；近景若承载多个互相竞争的主意，同样会失败。

<a id="lighting-intent"></a>
## 光意图

- **六级亮度**：白、亮明、浅灰、深灰、阴暗、黑。相邻级别的光量约相差一倍。“这里提高一级”就是可执行指令。级别写在光上：打在谁的脸上、手臂上，背景或雨幕比这个人亮还是暗。不要写成「Claire 浅灰、雨幕亮明」。浅灰不是灰雾，也不是衣服的颜色。
- **背景交代时间**：主体相同，背景较暗读作夜，较亮读作日。季节与时段首先从背景读出。
- **主光方向**：侧光提供体积和气氛；正面光压平；逆光分离主体，也可独立承担情绪。
- **过肩机位**需要单独说明：前景肩部如何处理（压暗、轮廓光），远端脸处于哪一级，并计划眼神光。
- **定义镜 / 心理主光**：场景支点或身份被照见的一格单独标注主光方向与背景级别，不得用「三点布光」泛写整场。
- **高感光摄影机**容易把夜晚拍得过亮，必须明确写出夜戏亮度级别。
- 此栏表达给摄影指导的意图。除非用户要求，不写灯具清单。

## 常见失败模式

- **漂亮画格，没有镜流**：单格好看却无法剪接；没有概要图，也没有轴线。
- **默认覆盖**：每场对白都是主镜头加对称单人，关系被拍平。
- **覆盖膨胀**：整场每个角度都拍，峰值镜头还没拍就用完拍摄日。
- **炫技运镜**：观众先注意运镜，后接收信息；路径没有人物理由。
- **无依据越轴**：摄影机只为更好看的角度跨线，没有新视线或演员跨线。
- **缺少场界素材**：宏观接口没有定场、交通或反应镜头，剪辑师只能被迫叠化。
- **夜戏拍成日戏**：光意图栏缺失或没有层次。
- **故事漂移**：镜头发明剧本没有的节拍，或忽略场景转折。
- **时长失配**：镜头时长总和远超场景分配。
- **单场合格、全片同质**：每场都能成立，但距离、高度、运动和覆盖密度在全片没有演化。
- **技术菜单式导演**：每个转折都套用可识别技巧——推近、后退、障碍——却没有本片规则。
- **母题不发展**：同一物体、画框或运动反复出现，意义从未改变。
- **策略只停在纸上**：视觉总谱写了规则，镜头表却不执行，也未记录破例。
- **自评分虚高**：只凭技术合规给视觉表现力加分，缺少整份分镜的证据。
- **有摄影机规则，没有成分结构**：总谱列出焦距和运动，却没有视觉成分的恒定、递进或事件节点对比曲线。
- **侦查前先画格**：精致画格掩盖了未定义的戏剧段落、支点或摄影机叙述者。
- **一格多个主意**：画面中有多个同等强势的信息，视线没有第一落点。
- **只换角度的剪接**：镜头变了，却没有新增视觉或听觉信息。
- **无动机的剪辑术语**：写了图形或概念匹配，却没有理由在那个时刻离开出镜。
- **动作行漂移**：改动了动作的发起方、先后顺序或结果（如剧本写「A 抓住 B 的手」，分镜画成「B 伸手扣 A」）。凡剧本写死的，一律以剧本为准；剧本未细写的，分镜自选并记为假设。
- **字级漂移**：专名、屏幕字、时间戳与剧本不一致（如把 `06/11` 写成 `6/11`、把 `3:36:02` 写成 `3:36`、把 `Gabriel Mora` 拼错）。屏幕字与时间戳以剧本原文为准，错一个都算失败。
- **揭示顺序漂移**：观众或人物的知情状态被提前或延后（如剧本要观众领先、分镜却让观众与人物同步得知）。知情差与揭示顺序以剧本为准。
- **连续性漂移**：人物外形、年龄、穿搭，地点，或道具状态与剧本及三份附件（Characters / Scenes / Assets）不一致。以最新剧本正文和三份附件为最高依据。

<a id="full-film-rhythm-and-anti-repetition"></a>
## 全片节奏与反重复

用视觉节奏矩阵检查整个段落或全片：

- **密度**：逐场记录镜头数与平均剪辑时长。峰值不必总是更快，但变化必须有意。
- **景别**：记录主导与最紧景别。若每场都抵达特写，特写就会贬值。
- **运动**：记录固定 / 运动比例和运动类型。若每拍都能发动运镜，就没有任何运动显得特殊。
- **高度与角度**：统计眼平机位比例。只有规则本身承载意义时，重复才成立。
- **覆盖形态**：标记重复的“主镜头 + 两边单人”、过肩镜头对和反应插入。
- **转折处理**：标记连续数个转折都使用推近、后退、换焦或揭示。
- **障碍隐喻**：门、窗、桌和前景遮挡不得成为所有紧张关系的万能缩写。
- **主观性**：记录谁控制信息与感知；意外转移必须有故事触发。
- **母题**：每次回归都必须改变尺度、语境、归属、方向、光线或后果。

只有当重复本身就是表达重点，且意义持续发展时，重复方案才通过；否则重做其中最弱的一次。

<a id="hard-indicator-gate"></a>
## 硬指标门槛

评分前，所有适用硬指标必须通过：

1. **场景变化可视化率：100%**——每个保留场景至少有一个镜头可见地承载从开场到结尾的变化。
2. **转折拍处理率：100%**——每个转折拍都有设计过的峰值镜头，或有书面决定说明为何克制强调。
3. **剪点检查通过率：100%**——每个计划剪口都通过清单，或记录了有意破例。
4. **宏观场界成对率：100%**——范围内每个宏观接口都有 A 场末帧 / B 场首帧。
5. **越轴可追溯率：100%**——每次轴线变化都写明触发。
6. **时长容差**——除非正式修订剧本时长账，每场预计剪辑时长须在分配值的 ±15% 内。
7. **复杂场压缩方案率：100%**——每个复杂场景都有保住场景变化的较短版本。
8. **镜头职务填写率：100%**——所有镜头的“这一镜交出什么”字段均不为空。
9. **视觉策略追溯率：段落 / 全片任务 100%**——每场都写明使用或打破的规则。
10. **导演侦查完成率：100%**——每个保留场景都在正式画格前写明戏剧段落、叙事拍、支点、场景归属、摄影机声音与知情差分配（含戏剧运动一句）。
11. **画格注意力完成率：100%**——每格都写明一个视觉主意和第一眼落点。
12. **剪口设计完成率：100%**——每个计划剪口都写明动机、连接类型和入镜新增信息。
13. **成分曲线追溯率：段落 / 全片任务 100%**——每个主导视觉成分都能从总谱追溯到场景与镜头。
14. **分镜单元时长**——每个镜头标明预计剪辑时长，默认不超过 15 秒。超过 15 秒的连续镜头必须按 15 秒分段描述，每段一个主导视觉主意，各段之和等于该镜时长。只写总秒数、不写各段看见什么，本项失败。

标记“不适用”必须说明理由。任何失败指标都会阻断交付，不得折算为部分得分。新增的镜流证据检查见 [quality-checklist.md](quality-checklist.md)；只有字段而没有实际画面证据，不算相应指标通过。

## 评分审查

进入评分前执行 [quality-checklist.md](quality-checklist.md)。原硬指标中的填写率只证明记录完成，必须继续核对画面、声音和时间是否兑现。关键事实仅存在于备注、必要动作不可见或关键空间与时间矛盾，按相应硬指标失败处理。创作效果不按勾选比例计分；可疑重复须比较实际镜流，不能凭同景别次数处罚。

评分对象是授权范围内的整份分镜，而不只是改动镜头。两项评分分开。单场任务不能因没有全片素材被迫补造全片：将“视觉命题与全片身份”按局部策略适配，将“全片节奏”按本场节奏适配；母题演化只有存在重复事件时才适用。完全不适用的维度写明理由，不给零分，按适用维度得分除以适用满分换算，并报告分子、分母与未验证范围；不是因质量差就可排除。全片专属封顶只作用于段落或全片任务；场内空间、原文保真、剪点和时长缺陷在单场仍阻断交付。

### 制作可靠性——100 分

| 维度 | 分值 | 得分条件 |
| --- | --- | --- |
| 场景职务忠实度 | 15 | 每镜服务于具体节拍；场景变化在设计镜头中可见；镜头内的物理动作与剧本动作行一致（发起方、顺序、结果），对白、专名、屏幕字与时间戳逐字照抄，知情差与揭示顺序同剧本一致 |
| 空间清晰度与轴线 | 15 | 概要图完整；轴线及其变化有依据；地理清楚 |
| 覆盖充分且节制 | 15 | 最小可剪集合齐全；保险有理由；没有膨胀 |
| 可剪性 | 15 | 每个剪点均通过剪接检查 |
| 场界 | 10 | 宏观接口成对；反应容器与低潮镜头已安排 |
| 可拍性与排期 | 15 | 机位归组装得进时间；复杂场景有压缩方案 |
| 光意图 | 5 | 每机位有主体与背景亮度；时间感可读 |
| 标注与可读性 | 10 | 镜号、分格、“切至”、箭头和时长一致 |

制作可靠性封顶（符合多项时取最低值）：

- 场景变化在任何镜头中都不可见：封顶 60。
- 多机位场景没有概要图，或轴线未定义：封顶 70。
- 越轴后没有建立有依据的新轴线：封顶 75。
- 范围内某个宏观接口没有场界成对设计：封顶 80。
- 方案超过已知时间且没有压缩方案：封顶 80。
- 镜头时长超过场景分配四分之一以上：封顶 85。

### 视觉表现力——100 分

| 维度 | 分值 | 得分条件 |
| --- | --- | --- |
| 视觉命题与全片身份 | 15 | 摄影机规则来自形式与主题；开场到结尾的视觉变化可见 |
| 视觉成分结构 | 15 | 两至三个成分遵循明确的恒定、递进或对比 / 相似结构 |
| 观众位置与摄影机叙述 | 10 | 创作立场、叙述声音、信息和物理视点保持区分，且只在触发时改变 |
| 关系与人物递进 | 10 | 共享画框、距离、权力和运动随人物弧演化 |
| 戏剧段落与支点表达 | 10 | 镜头形态变化与峰值强调来自段落和支点，而不是音量最大的台词 |
| 全片节奏与视觉递进 | 10 | 强度、密度、时长、景别、稳定度、空间状态和摄影机自由度均有意变化 |
| 构图与注意力 | 10 | 每格一个主意；第一眼落点受控；负空间有用；对比有依据 |
| 母题演化 | 5 | 重复画框、物体、运动或光型的意义发生变化 |
| 镜头与剪辑专属性 | 10 | 镜头带来新增信息；剪接有动机，不能无损移植到另一场 |
| 声音、静默与停顿意图 | 5 | 声音、静默、停顿或留白实质改变画面顺序、场界或观众读人物的时间；声音先入与画外空间同样计入 |

视觉表现力封顶：

- 段落或全片任务没有视觉总谱：封顶 50。
- 段落或全片任务没有主导视觉成分结构：封顶 60。
- 开场与结尾没有呈现所声称的视觉变化：封顶 65。
- 段落或全片任务没有相应范围的视觉节奏矩阵：封顶 70。
- 未定义戏剧段落与支点就正式分镜：封顶 75。
- 没有主题理由，却由同一覆盖形态和转折处理主导全片：封顶 75。
- 观众位置改变没有故事触发：封顶 80。
- 画格反复承载互相竞争的视觉主意，或剪口反复不增加信息：封顶 80。
- 母题重复但不发生变形：封顶 85。

阻断项：任何 80 分或更低的封顶。交付门槛：封顶后两项均不低于 85，所有硬指标通过，且没有阻断项。两项均以 90 为目标，不得取平均分；制作可靠性 95、视觉表现力 75，仍然只是技术安全、视觉未完成。

修订循环：

1. 先裸读并落盘，再检查硬指标，最后打开两套量表评分。
2. 先修复硬失败，再选择层级最高的失败维度：视觉策略 → 场景职务 → 空间 → 关系 / 主观性 → 覆盖 → 剪接 → 场界 → 全片节奏 → 排期 → 光意图 → 标注。
3. 对每个受影响场景做一遍集中修订，并保存新稿。
4. 重新通读并重评全部内容。
5. 是否接受改稿按 [creation-method.md](creation-method.md) 引用实际镜流的收益与损失。连续两轮无可定位收益或只在同等方案间摆动时停止；未达硬门槛仍标未就绪，评分仍受外部仪器开关约束。

<a id="blind-review"></a>
### 盲评两段式

先裸读、后对表，是为了不让两套量表和检查表替审稿者决定看什么。若一开始就按维度找分，模型只会确认量表已经问过的问题；而读整份分镜时的第一反应——在哪一格失去方向、哪一个剪口别扭、哪一段想快进、最后记住什么——更接近普通观众和模型训练所得的观影直觉。技能用来事后校准这份直觉，不是提前框住它。

1. **第一段：裸读。** 审稿者只收到授权范围内的分镜正文与镜头表，不收本技能文件、quality-checklist、两套量表、Audit、创意备忘或作者意图；视觉总谱、场景拆解等说明留到第二段再读。把整份分镜当预剪辑一次读完并想象声音，用完整句子写下：哪里被抓住、哪里走神、哪里空间或时间上不明白、哪个剪口别扭、哪一镜想删或想补、记住了哪个画面、这段像不像一场戏，以及一个粗略的直觉档位。此段不查表、不套术语、不逐项打分，记录先落盘。
2. **第二段：对表。** 裸读记录写完才打开两套量表和视觉总谱、场景拆解等说明。把第一段的具体反应逐条映射到制作可靠性与视觉表现力的维度，附镜号证据；再核查量表提示而裸读没有注意到的维度；反复迭代到每条反应都有归属、每个分项都有证据，再应用封顶，给出两项分数。
3. **处理两段的差。** 裸读指出的问题在量表里找不到归属时，单列为量表外缺陷，并说明为何不能折算成分数。量表分高于裸读整体印象时，用实际镜流说明观看体验为何被低估；说不出来就按裸读下调，不拿字段齐全、镜头更多或术语正确抬高分数。量表分低于裸读印象时，同样要指出具体维度与镜号，不能凭「量表觉得」压分。第二段可以纠正第一段的事实错误，但不得删掉或改写第一段的原始记录。
4. **记录与边界。** 两段都进 `Audit/`，格式见 [templates.md](templates.md)「审查表」。两段式不改变硬指标、阻断项和封顶；裸读印象不能代替画面证据，也不能让失败稿进入评分。审稿者若事先已看过量表、检查表或作者解释，须在记录里声明，该次只算约束阅读，不能冒充裸读；第二段所需的两套量表在第一段记录落盘后单独提供，不连同技能全文和 quality-checklist 一起交。

盲评优先由未参与起草的审稿者完成。没有独立审稿者时，可用同源新上下文（不读前文与结论）按同一顺序执行，并标明是同源；两段式改善的是判断顺序，不把同源升格为非同源，也不替代外部仪器。

<a id="sound-handoff"></a>
## 声音设计与交接

剧本写「声音意图」，分镜把它变成声音地图；混音在声音设计师手里，但地图必须在这里交清。

1. **声音底**：每场先定环境声与底噪；没有底，静默不成立。
2. **抽层**：这一场抽掉哪一层（人声、环境、音乐、拟音），什么时候回来；静默之前要有声音，之后要有声音回来。
3. **画外**：哪些声音在画外，何时入画；画外声因为看不见而获得权力，入画就是移交。
4. **同步点**：哪一下声音和画面焊成一个事件（关门、风车停、瓶口响、刹车）。
5. **音乐立场**：贴画面（共情）还是冷眼（反共情）；不要在每场都站同一边。
6. **交接表**：场次 / 声音事件 / 声音底 / 抽层 / 回来 / 画外 / 同步点 / 音乐立场；模板见 [templates.md](templates.md) 的「声音交接表」。

通过标准：每个重要场界有声音策略；静默有声音底和回来；人声不被音乐压掉；同步点与画面事件对得上。

边界：技能不设计混音，也不替作曲决定配器；它只交声音地图与意图。

<a id="animation-and-previz"></a>
## 动画与预演

仅动画或预演任务；实拍任务跳过，但 timing 与间距的判断仍可用于动作设计。

1. **先 key 后 extreme 再 breakdown**：key 回答镜头里发生了什么；extreme 管接触与承重；breakdown 决定动作性格（偏前、偏后、抬高、压低）。
2. **时间与间距分开写**：timing 决定何时发生，spacing 决定同一段时间里位移怎么分配；不要用挤压拉伸代替间距。
3. **活动保持**：停里留一个部件继续走（呼吸、眨眼、衣摆、重心）；全体同时停会像机器。
4. **对白**：先分句标重音，再画口型；重音可以比嘴早几格；硬重音弹回，软重音继续。
5. **预演**：把故事板按时间拍成 Leica reel，改动改在样片上，不改在动画上。
6. **重量**：身体被地面接住的那一格承重；走路是不断被重力接住的跌倒。

通过标准：关键动作有 key / extreme / breakdown 三层；停有活动保持；预演能读出时间；重量落在承重的那一格。

边界：这不是十二原则清单，是工序；二维曝光表术语要转译成 CG 曲线或定格毫米数。

## 外部仪器

**开关。** 默认关；阶段 0 问一次，评分 85 以上再提醒一次。开时按下列规则；关时两项分数是自评分，不宣称 90。

同源盲评只消除信息差，不消除偏差；先裸读后对表只改善判断顺序，两者都不能把同源变成非同源。开关为开时，85 分以上至少一次非同源审稿，90 分以上必须有外部仪器（真人、另一模型家族或实拍/预演反馈），审稿者先裸读再对表，并在 `Audit/` 里记录审稿人/渠道、独立性、两段记录、两项分数与分歧处理。没有开启时，只能说「自评分 X」，不能说「已经优秀」。

## 知识边界

- 剧本页面仍然不承载镜头指令；分镜应存在于独立文档中。
- 本技能不发明节拍，也不改写剧本的动作行、对白、专名、屏幕字、时间戳、揭示顺序，或与人物、地点、道具三份附件冲突。这些都是剧本或交付包写死的，分镜只决定用什么机位、景别和剪点让它们可见。故事问题退回 `screenplay-development`。
- 并非每场都需要绘制画格；简单场景可以只有镜头表。
- 风格可以打破这里的任何规则，例如有意跳切或制造迷失感的越轴，但破例必须一致，并写入风格约定。
- AI 关键镜帧与视频提示词：**默认开**（只要分镜时再关）。分镜就绪后交付。**阶段 12** 按镜关键镜帧（默认 **Nano Banana**，备选 **GPT Image**；每镜一张开镜首帧构图静帧，独立文件 `Storyboard-Keyframes.md`，每镜含「大致故事」（在本镜资产上方，**一句**梗概）与本镜资产表；**prompt＝纯静帧图像描述且自洽可读（可不依赖资产）**：景别／机位／空间／静止姿态／对焦，约 3–6 句；**每条只许一个景别**（写在开头一次；景深用近处／稍远／深处，禁「前景与中景：」作第二景别）；**禁**动作过程词与「尚未／刚／正在」等；资产表仍上传锁身份但 prompt 不得削到读不懂；禁风格／材质／负面长配方；禁止默认首中尾三张；禁止峰值／中间／尾帧顶替首帧；MidJourney 关键镜帧已退役）。**阶段 13** 视频提示词，独立文件交付（未指定模型时默认 MiniMax H3 / 全能参考）；分类 **MiniMax H3**（`minimax-h3-prompt`）或 **Seedance 2.5**（`seedance-prompt`）。产出开关、路由与禁止项见 [prompt-generation.md](prompt-generation.md)。身份参考图提示词在 `screenplay-development` 三附件中（仍可 MidJourney）；关键镜帧不替代三附件。
