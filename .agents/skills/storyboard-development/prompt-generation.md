# 提示词产出（分镜配套）

分镜技能在分镜定稿后，可选交付两类独立文件（均不塞进 `Storyboard - Draft N.md` 正文）：

1. **按镜关键镜帧提示词**（默认 **Nano Banana**；备选 **GPT Image**）：每镜 **一张** 开镜首帧构图静帧，见下文「关键镜帧提示词」。**MidJourney 关键镜帧已退役**，勿再作为新项目默认。
2. **按镜视频提示词**（MiniMax H3 / Seedance 2.5）：每条对应分镜一镜（或 H3 允许的连续段），见下文「视频提示词」。

两类开关独立；可只开其一。不要默认要求每镜首中尾三张静帧。

## 契合度元规则（总纲）

提示词（关键镜帧与视频）与分镜、剧本的匹配，不是靠「把词写得好」保住的，而是靠一条**单向派生链**、锁定层、一道**边界纪律**、**持有与入画分开**，以及**这一帧的身体写全**撑起来的。以下元规则统辖本页产出；持有与身体写全主要约束视频词。与单一模型细则冲突时，模型细则先于元规则，但不得借此放宽锁定或边界。

**1. 单向派生：下游只「呈现」，不「重写」上游。** 链条是 剧本 → 分镜 →（可选关键镜帧静帧）→ 视频提示词，每环权限写死：剧本锁定不可改的输入（对白、专名、屏幕字、时间戳、动作行、揭示顺序、人物 / 地点 / 道具）；分镜只决定机位、景别、剪点让变化可见，不改故事；关键镜帧只锁本镜开镜首帧的构图瞬间；视频提示词只把一镜看得到、听得到的内容译成模型演得出的过程，机位照抄分镜（镜号、焦距、景别），不重新设计。提示词一旦开始交代前因后果或另起剧情，就是在越界重写剧本，应删除。

**2. 锁定层是匹配度的物质基础。**
- **身份锁定（谁 / 在哪 / 用什么）**：人物、地点、英雄道具来自剧本三附件（`Characters.md` / `Scenes.md` / `Assets.md`），靠图N绑定 + 固定外形描述 + 固定名字锁死；反打、顶视从主视图垫图生成，不另起一套空间。防「换脸 / 换装 / 换房间 / 换道具」。
- **构图锁定（可选）**：若上传本技能产出的关键镜帧静帧，只锁本镜构图 / 取景 / 调度，不锁身份；与三附件图并存时，职责写清。
- **镜号锁定**：一条提示词对应分镜表唯一一个镜号，时长、对白、景别、焦距一一对上。保可追溯性。
- **素材锁定**：图N 与上传顺序一致，每张图职责单一，写清「参考什么、不参考什么」。

**3. 边界纪律：防两类漂移。** 可贴入段只写本镜；全片调色总谱、逐镜焦距、场号对照、跨场呼应、剧情背景放文件头「对照区」，不粘贴进单条。一类是「向剧本漂移」（复述总谱 / 场号 / 前情），一类是「向视觉漂移」（换造型 / 换空间 / 换道具），两类都禁。

**4. 翻译是契合度的试金石。** 分镜缩写（D#、画左 / 画右、半步、将扣、六级亮度）是给摄影组的，必须译成看得见的过程，不原样贴入。写不出可贴入词，通常说明分镜那一格只给了机位、没给「第一眼落点 + 一件主事件 + 停在什么状态」——产出提示词因此是对分镜的一次质检。

**5. 门禁：分镜就绪才出词。** 「产出关键镜帧提示词 = 开」或「产出视频提示词 = 开」时，须分镜通过硬指标、双评分不低于 85 且无阻断项（见 `storyboard-development` 阶段 11；关键镜帧为阶段 12，视频为阶段 13）；不从半成品出词。用户指定先做某场 / 某段时，那一场 / 段自身须达同标准。

**6. 持有与入画分开。** 一件道具在世界上由谁撑着、拿着或推着，以剧本和前后镜为准。转写某一镜之前先确认持有人，再决定这一镜看得见哪一段。本镜禁止某个入画的人碰到它，只说明这个人不接触，不说明这件东西失去了支撑，也不说明持有人消失。「只写本镜」管的是可贴入里不出现持有人的名字、揭示顺序和前因；决定裁切时仍然要用这个事实。入画的人都被禁止碰到一件需要支撑的道具时，正文写留下的可见部分，例如伞面停在画面左侧、伞柄不进入画面。不要写成柄上没有手、没有人握着、悬在空中。也不要为了补上支撑，在画外添一只这一镜不该出现的手。正文和不要做若一起删掉全部支撑，即使两段彼此不打架，这一条也不合格。同一件道具的持有人在前后镜里保持连续，持有人的名字留在分镜对照。

**7. 这一帧的身体写全。** 模型只有这一句，不共享分镜里已经排好的挡位。人从哪里出发，写成这一帧身体所在的那一块体积，并写明头顶、脸和胸口朝哪边。下缘、暗区、画面边缘是机位和剪点的标记，留在分镜对照，不拿来代替人站的位置。分镜写「从伞下冲出」时，不要收成「从伞的下沿出来」。下一步要碰到的人若在身后或在朝向的反侧，先写原地转身、脚停住，再写抬手。被碰到的袖口、皮肤、手写上这一镜的图N；Seedance 写一致性总谱里的同一指代。去掉剧本人名时，不要改成「那只袖口」或「袖口和皮肤」。H3 在不要做里再禁一次还背对着就伸手；Seedance 把正确的朝向和所有者写进时间轴。细则见 `minimax-h3-prompt`「这一帧的身体写全」。

**单条是否合格、是否与它的镜匹配，由视频 skill 的「交付检查表」检验。** 本页只定义契约（派生方向、锁定、边界、门禁、持有与入画、这一帧的身体），不复制检查表。转写分镜时，逐条校验见 `minimax-h3-prompt` 与 `seedance-prompt` 的 `reference.md`「交付检查表」：镜号 / 秒数 / 景别 / 焦距与分镜表一致，谁 / 在哪 / 用什么 = 三附件锁定的图N，可贴入不出现剧本人名 / 场景专名 / 内部代号，且无场号对照 / 跨场呼应 / 全片总谱 / 剧情背景句。需要支撑的道具还要核对持有人连续，以及这一镜留下的可见部分没有被写成失去支撑。人的起点还要核对这一帧的体积和朝向，被碰到的身体部位还要带上图N或总谱里的同一指代。

## 关键镜帧提示词（阶段 12）

**用途：**为就绪分镜的每个镜号生成 **一张** Nano Banana（默认）或 GPT Image（备选）提示词，用来出本镜的构图静帧。该静帧供 H3 全能参考等流程作构图锚，**不**代替三附件身份图，也 **不** 代替视频提示词。**MidJourney 关键镜帧已退役**（`kf-mj`），勿再写入新 `Storyboard-Keyframes.md`。

**张数规则：**每镜恰好一张，且固定为该镜 **开镜首帧**（「画面（按时间）」起点瞬间）。禁止把「首帧 + 中间帧 + 尾帧」三张设为默认交付；禁止改选节拍峰值、中间态或尾帧顶替首帧。

**选帧：**一律取开镜首帧。从该镜纯文字画格「画面（按时间）」的起点瞬间，并结合「视觉主意 / 第一眼」写清开镜构图。**描述方式＝普通静帧图像描述**：只写此刻画面里看得见的静止态（景别／机位、空间布局、谁／物在哪、姿态与相对位置、对焦），**不写**过程路径、时间过程与后续变化（那是视频词的事）。不把节拍峰值提前画进关键镜帧。资产态也按开镜可见静止态写（例如眼灯暗、趴在充电座、拇指停在耳缺旁有间距、连续白光眼灯、坏耳自然下垂）——用姿态／间距／立姿，**禁止**用「尚未擦到／尚未甩出／尚未僵／刚退后」等否定过程或动作路径来交代。

**每镜结构（强制）：**

1. **职务 / 第一眼**（中文一行）。
2. **大致故事**（中文，**一句**故事梗概；**必须写在「本镜资产」上方**）：给人看的本镜叙事梗概——谁做了什么／关系怎么变；从分镜压缩成**一句**，少细节，不写景别／构图／机位。可保留剧本人名。**不写进** `prompt` 围栏；不替代职务／第一眼，也不替代自洽可读的画面构造 prompt。
3. **本镜资产（按上传顺序）**：从 1 起编号；列出本镜要上传的 Characters／Scenes／Assets 条目（及开镜所需态），并写「只锁什么／不锁什么」。资产表仍强制写，供有图时按序上传锁定身份／风格／材质；职责「只锁／不锁」不变。可与同镜 H3「素材：」对齐精简。无图时标「（无图）」。
4. 中文 `prompt` 代码围栏正文：**自洽可读的画面构造**（见下）。

**语法（Nano Banana · 默认）：**

- 自然语言 **中文**；大约 **3–6 句**或等价信息量（以「盲读能画出分镜格」为准，不是越短越好）。
- **目标：** `prompt`＝**一张静帧照片的画面描述**。读者**不打开／不上传任何资产参考图**，只读正文，就能在脑中重建本镜开镜首帧的画面构造（谁／什么在哪、景别机位、框内布局、静止姿态与相对位置、对焦落点）。
- **一镜一个景别（强制）：** 每条 `prompt` **只许一个景别词**（全景／中全景／中景／中近景／近景／特写／大特写／远景／双人中景等），**写在开头一次**。景深分层用「近处／稍远／深处／后景浅处」或框内前后位置，**禁止**「前景与中景：」「中景与后景」这类把景深写成第二景别；也禁止正文再出现第二个景别词或「不切成××特写」等景别对照句。
- **结构习惯：** 景别 + 机位朝向 → 空间骨架（摊内／门口／柜台哪一侧；近处／稍远／深处谁在哪；谁同框；裁切到哪）→ 用**通用可见称谓**写清主体类型与可辨构造（如「中年男人」「柜后」「机器狗」「左耳缺一角」「充电座」「红单」）与**此刻可见的静止姿态／间距／立姿** → 对焦／第一眼。
- **有资产时**：资产图仍负责身份／材质／风格一致，但 **prompt 不得因有图而削到读不懂**；禁止依赖读者已看过资产图才懂「一人」「狗」指什么构造。
- **可保留**：可见静止态（眼灯暗、连续白光、坏耳自然下垂、身体略退后有间距、立姿未蹲）与画面内必须可读的印刷字原文。
- **禁止动作与过程词：** 过程动词与时间过程（刚…、正在…、随后…、准备…）；否定过程（尚未／还没／未／将要／刚要）；动作路径当画面描述（退后两步、迈进瞬间、刚抬起尚未放下等）。只写「此刻画面里是什么样子」，不对比过程峰、不说还没发生什么。
- **禁止堆砌**：风格化 3D 长配方、材质说明书、市井光色长段、负面套话（不要超写实／真人／anime 等）、「按本镜资产图N只锁…」套话、无字幕无水印套话。
- **不写** MidJourney 参数（无 `--no`、无 `--ar`、无 `--raw`、无 `--stylize` 等）。
- 画幅 16:9 在界面设置；可不塞进正文。
- **不写**：剧本人名、情节解释、场号、镜号、情绪解读。
- **合格自检（每镜）：** 遮住本镜资产表，只读 prompt，外人应能回答：景别机位？框里有哪些主体／道具？各自相对位置与静止姿态？对焦落哪？全文无「尚未／刚／正在」等过程词（印刷字原文与合理静物状态如「眼灯暗」除外）。**景别词整镜只出现一次**（通常在首句）；无「前景与中景」类第二景别。

**语法（GPT Image · 备选）：**

- 与 Nano Banana **同结构**（职务／第一眼 → **大致故事** → 本镜资产表 → 自洽可读中文 `prompt`）。
- 同样要求盲读可知画面构造；界面设置 16:9。
- **勿臆造**不存在的 API 字段；不要写 MJ 参数。

**文件结构 `Storyboard-Keyframes.md`：**

见 [templates.md](templates.md#关键镜帧提示词条目) 的条目模板。文件头含项目、模型（Nano Banana 默认／GPT Image 备选）、画幅、**「提示词自洽可读画面构造（可不依赖资产）」**、上传与绑定规则；其下按镜号分节。曾用 `Storyboard-Keyframes-MJ.md` 后缀已弃。

**与视频词的关系：**关键镜帧是可选的构图上游输入；视频提示词（阶段 13）仍以分镜纯文字画格为过程真源。没有关键镜帧也可以出视频词；有关键镜帧时，在 H3 素材列表里单独绑一张并写清职责。身份三附件参考图规则仍见 `screenplay-development/prompt-generation.md`（可继续 MidJourney），与关键镜帧模型分开。

## MiniMax H3 — 结构（每条）


1. 镜号、秒数、焦距 mm、模式（默认全能参考）、素材列表（图1=…）。
2. **可贴入**：一整段 **中文**。
3. **不要做**：3–6 条可观察禁令，只写进可贴入的最后一段，代码块外不再列一遍。

**可贴入段内容顺序（习惯）**

- `N秒、16:9视频。焦距××毫米，固定不许变焦。`
- **本镜亮度**写成落在谁身上的光（浅灰、深灰、亮明、阴暗是曝光）。不要写「这一镜的光是…浅灰」。人身上用了灰色亮度时，写明不要罩成灰雾、不要改衣服颜色
- 画左、画右、半步、将扣、接触尚未发生，译成画面左/右、迈完就停、碰到之前停住。细则见 `minimax-h3-prompt`「分镜缩写要译成看得见的过程」
- 眨眼、光影、真人实拍、本镜环境一句
- **图 N 绑定**（只锁什么 / 不参考什么）；若含关键镜帧静帧，写明只参考构图与调度，身份仍绑三附件图
- 主体、场景、运动、镜头、声音（句中只用 **图N**，不写剧本人名/场景名/素材代号，也不写他/她/他们/她们）
- 分镜「第一眼 / 眼睛落在」译成对焦，并写明景别是保持还是本镜特写。细则见 `minimax-h3-prompt`「元规则」
- 人的起点写成这一帧的体积和朝向。下缘、暗区不代替站位。朝向背对要碰的人时，先转身再抬手。被碰到的袖口、皮肤、手写图N。细则见 `minimax-h3-prompt`「这一帧的身体写全」
- 英文台词/屏幕字 **原文**；语速正常；每句最多 **重读一词**；画外 **口型闭合**
- 默认 **不要配乐**（禁旋律与垫乐，不只写「无 BGM」）
- **不要做** 作为可贴入的最后一段，以「不要做：」起头。代码块外不再重复这组句子。

**禁止写进可贴入段（剧本背景）**

- 全片调色总谱复述、场号对照（如「绿色只出现在第×场」）、跨场首尾呼应、近未来设定梗概、分镜外的结构说明。
- 总谱留在分镜「视觉策略」或 H3 文件 **对照表**，不粘贴进每条。
- 持有人的名字、揭示顺序和前因留在分镜对照。裁切后看得见的那一段仍然写进可贴入，例如伞面在、伞柄不进入画面。

**项目硬规则（有则写入每条或文件头）**

- 手机：正脸只见背壳；读屏 = 过肩或插入；脸与可读字 **不同框**。
- 播放器/头带 UI：索引与抽象光，不播可辨认记忆画面。
- 记忆场：Gabriel 主观；不反拍 G 客观反应；不出现当下 Naomi；手从 **右下** 入画。

细则以 `minimax-h3-prompt` 为准；与 Seedance 语法 **不可混用**。
