# 提示词产出（分镜配套）

分镜技能在分镜定稿后，可选交付两类独立文件（均不塞进 `Storyboard - Draft N.md` 正文）：

1. **按镜关键镜帧提示词**（默认 **Nano Banana**；备选 **GPT Image**）：每镜 **一张** 开镜首帧构图静帧，见下文「关键镜帧提示词」。**MidJourney 关键镜帧已退役**，勿再作为新项目默认。
2. **按镜视频提示词**（MiniMax H3 / Seedance 2.5）：每条对应分镜一镜，或按目标模型支持的范围覆盖连续镜段，见下文「视频提示词」。

两类开关独立；可只开其一。不要默认要求每镜首中尾三张静帧。

## 契合度元规则（总纲）

引用图片的关键镜帧或视频提示词，须在画面正文前集中交代图片与固定名词代称的对应关系。关键镜帧沿用独立的「本镜资产」区，视频提示词用单独的素材绑定段。按实际上传顺序登记每张图片，正文指代这些素材时统一使用同一个名词代称。图片编号、文件名与产品绑定标记只留在绑定段，具体标记遵循目标产品的文档。原台词照录。

提示词（关键镜帧与视频）与分镜、剧本的匹配，不是靠「把词写得好」保住的，而是靠一条**单向派生链**、锁定层、一道**边界纪律**、**持有与入画分开**，以及**这一帧的身体写全**撑起来的。以下元规则统辖本页产出；持有与身体写全主要约束视频词。与单一模型细则冲突时，模型细则先于元规则，但不得借此放宽锁定或边界。

**1. 单向派生：下游只「呈现」，不「重写」上游。** 链条是 剧本 → 分镜 →（可选关键镜帧静帧）→ 视频提示词，每环权限写死：剧本锁定不可改的输入（对白、专名、屏幕字、时间戳、动作行、揭示顺序、人物 / 地点 / 道具）；分镜只决定机位、景别、剪点让变化可见，不改故事；关键镜帧只锁本镜开镜首帧的构图瞬间；视频提示词只把一镜看得到、听得到的内容译成模型演得出的过程，机位照抄分镜（镜号、焦距、景别），不重新设计。提示词一旦开始交代前因后果或另起剧情，就是在越界重写剧本，应删除。

**2. 锁定层是匹配度的物质基础。**
- **身份锁定（谁 / 在哪 / 用什么）**：人物、地点、英雄道具来自剧本三附件（`Characters.md` / `Scenes.md` / `Assets.md`），靠图N绑定 + 固定外形描述 + 固定名字锁死；反打、顶视从主视图垫图生成，不另起一套空间。防「换脸 / 换装 / 换房间 / 换道具」。
- **构图锁定（可选）**：若上传本技能产出的关键镜帧静帧，只锁本镜构图 / 取景 / 调度，不锁身份；与三附件图并存时，职责写清。
- **镜号锁定**：按条标明对应的分镜镜号。使用白模视频参考时，若目标模型和模式允许连续镜段，可在一条提示词内覆盖多个连续镜号，逐镜保留切点、时长、对白、景别和焦距。时长按[提示词书写指南的白模规则](../prompt-writing-guide/SKILL.md#1-先锁镜头与时长)。
- **素材锁定**：图N 与上传顺序一致，每张图职责单一，写清「参考什么、不参考什么」。

**3. 边界纪律：防两类漂移。** 可贴入段只写本镜；全片调色总谱、逐镜焦距、场号对照、跨场呼应、剧情背景放文件头「对照区」，不粘贴进单条。一类是「向剧本漂移」（复述总谱 / 场号 / 前情），一类是「向视觉漂移」（换造型 / 换空间 / 换道具），两类都禁。

**4. 翻译是契合度的试金石。** 分镜缩写（D#、画左 / 画右、半步、将扣、六级亮度）是给摄影组的，必须译成看得见的过程，不原样贴入。写不出可贴入词，通常说明分镜那一格只给了机位、没给「第一眼落点 + 一件主事件 + 停在什么状态」——产出提示词因此是对分镜的一次质检。

**5. 门禁：分镜就绪才出词。** 「产出关键镜帧提示词 = 开」或「产出视频提示词 = 开」时，须分镜通过硬指标、双评分不低于 85 且无阻断项（见 `storyboard-development` 阶段 11；关键镜帧为阶段 12，视频为阶段 13）；不从半成品出词。用户指定先做某场 / 某段时，那一场 / 段自身须达同标准。

**6. 持有与入画分开。** 一件道具在世界上由谁撑着、拿着或推着，以剧本和前后镜为准。转写某一镜之前先确认持有人，再决定这一镜看得见哪一段。本镜禁止某个入画的人碰到它，只说明这个人不接触，不说明这件东西失去了支撑，也不说明持有人消失。「只写本镜」管的是可贴入里不出现持有人的名字、揭示顺序和前因；决定裁切时仍然要用这个事实。入画的人都被禁止碰到一件需要支撑的道具时，正文写留下的可见部分，例如伞面停在画面左侧、伞柄不进入画面。不要写成柄上没有手、没有人握着、悬在空中。也不要为了补上支撑，在画外添一只这一镜不该出现的手。正文和不要做若一起删掉全部支撑，即使两段彼此不打架，这一条也不合格。同一件道具的持有人在前后镜里保持连续，持有人的名字留在分镜对照。

**7. 这一帧的身体写全。** 模型只有这一句，不共享分镜里已经排好的挡位。人从哪里出发，写成这一帧身体所在的那一块体积，并写明头顶、脸和胸口朝哪边。下缘、暗区、画面边缘是机位和剪点的标记，留在分镜对照，不拿来代替人站的位置。分镜写「从伞下冲出」时，不要收成「从伞的下沿出来」。下一步要碰到的人若在身后或在朝向的反侧，先写原地转身、脚停住，再写抬手。被碰到的袖口、皮肤、手写上这一镜的图N；Seedance 写一致性总谱里的同一指代。去掉剧本人名时，不要改成「那只袖口」或「袖口和皮肤」。H3 在不要做里再禁一次还背对着就伸手；Seedance 把正确的朝向和所有者写进时间轴。细则见 `minimax-h3-prompt`「这一帧的身体写全」。

**单条是否合格、是否与它的镜匹配，由视频 skill 的「交付检查表」检验。** 本页只定义契约（派生方向、锁定、边界、门禁、持有与入画、这一帧的身体），不复制检查表。转写分镜时，逐条校验见 `minimax-h3-prompt` 与 `seedance-prompt` 的 `reference.md`「交付检查表」：镜号 / 秒数 / 景别 / 焦距与分镜表一致，谁 / 在哪 / 用什么 = 三附件锁定的图N，可贴入不出现剧本人名 / 场景专名 / 内部代号，且无场号对照 / 跨场呼应 / 全片总谱 / 剧情背景句。需要支撑的道具还要核对持有人连续，以及这一镜留下的可见部分没有被写成失去支撑。人的起点还要核对这一帧的体积和朝向，被碰到的身体部位还要带上图N或总谱里的同一指代。

## 产出开关（与阶段 0 联动）

在阶段 0 记录：

```text
产出关键镜帧提示词：开 | 关
关键镜帧分类：Nano Banana | GPT Image
产出视频提示词：开 | 关
视频分类（可多选）：MiniMax H3 | Seedance 2.5
```

- **默认**：关键镜帧与视频提示词均为 **开**（AI 成片默认路径）；用户明确只要分镜时再关。
- **关键镜帧 · 关**：不产 `Storyboard-Keyframes.md`。
- **关键镜帧 · 开**：分镜 **就绪**（或用户指定的分段）后，按镜写入 `Screenplays/<Title>/Storyboard-Keyframes.md`（或用户路径）；分类默认 **Nano Banana**；用户可改 **GPT Image**。曾用后缀 `-MJ` 的文件名已弃，新产勿再加。
- **视频 · 关**：分镜交付不含可贴入的生成词。
- **视频 · 开**：分镜 **就绪**（或用户指定的分段）后，按镜写入约定文件；每条标明 **分类 ID**（如 `vid-h3`）；未指定模型时默认 **MiniMax H3**（全能参考）。

建议路径：关键镜帧 → `Storyboard-Keyframes.md`；视频 → `MiniMax H3.md`、`Seedance.md`（或用户指定）。两开关彼此独立；**默认均为开**，用户只要分镜时再关。

## 关键镜帧提示词（阶段 12）

**用途：**为就绪分镜的每个镜号生成 **一张** Nano Banana（默认）或 GPT Image（备选）提示词，用来出本镜的构图静帧。该静帧供 H3 全能参考等流程作构图锚，**不**代替三附件身份图，也 **不** 代替视频提示词。**MidJourney 关键镜帧已退役**（`kf-mj`），勿再写入新 `Storyboard-Keyframes.md`。

**张数规则：**每镜恰好一张，且固定为该镜 **开镜首帧**（「画面（按时间）」起点瞬间）。禁止把「首帧 + 中间帧 + 尾帧」三张设为默认交付；禁止改选节拍峰值、中间态或尾帧顶替首帧。

**选帧：**一律取开镜首帧。从该镜纯文字画格「画面（按时间）」的起点瞬间，并结合「视觉主意 / 第一眼」写清开镜构图。**描述方式＝先调度后摄像机**：先写在什么场景中、人物和道具怎么摆放、人物当下在做什么；再写景别／视角／机位／对焦。**不写**过程路径、否定过程与后续变化（那是视频词的事）；调度句允许当下态（数纸钞／整理／低头／停步等开镜起点瞬间）。不把节拍峰值提前画进关键镜帧。资产态也按开镜可见静止态写（例如眼灯暗、拇指停在耳缺旁有间距、连续白光眼灯、坏耳自然下垂；《九成新》全片禁止充电座入画（含原 1.1／1.3／1.7）；来福趴／伏写地面或柜旁地面，交割后空位写「低处空位」）——用姿态／间距／立姿，**禁止**用「尚未擦到／尚未甩出／尚未僵／刚退后」等否定过程或动作路径来交代。

**每镜结构（强制）：**

1. **职务 / 第一眼**（中文一行）。
2. **大致故事**（中文，**一句**故事梗概；**必须写在「本镜资产」上方**）：给人看的本镜叙事梗概——谁做了什么／关系怎么变；从分镜压缩成**一句**，少细节，不写景别／构图／机位。可保留剧本人名。**不写进** `prompt` 围栏；不替代职务／第一眼，也不替代自洽可读的画面构造 prompt。
3. **本镜资产（按上传顺序）**：从 1 起编号；格式 `N. **代称**＝Characters／Scenes／Assets · 真名条目 — 只锁…；不锁…`。每个角色／物品／场景资产分配**全片唯一**的 **`[中文代称]`**；真名显示在本行「＝」右侧；括注态与只锁／不锁语义保留。无图时标「（无图）」；无锁图路人可不加代称。可与同镜 H3「素材：」对齐精简。
4. 中文 `prompt` 代码围栏正文：强制两段 **【构图】**＋**【资产细节】**（见下）。

**语法（Nano Banana · 默认）：**

- 自然语言 **中文**；大约 **3–6 句**或等价信息量（以「盲读能画出分镜格」为准，不是越短越好）。
- **目标：** `prompt`＝**【构图】**＋**【资产细节】** 两段静帧描述。【构图】＝**调度句**（场景＋摆位＋当下动作）＋**摄像机句**（景别＋视角＋机位＋对焦可选）（t103u；结构仍含 t101u 五要素）；用 `[中文代称]` 入画，不写外形细节。**禁止**把「框内同时可见／几乎占满画框／正对镜头／完整入画／背景浅处是…」等纯画面裁切词当调度主句——必要裁切挪到摄像机句或删掉，改成摆位／动作。**每镜须点名场景代称（t102u）：** `prompt`【构图】须出现本镜场景代称（`[摊位傍晚|夜间|日间|清晨]` 或 `[走廊傍晚|夜间|日间|清晨]`，须嵌在能回答「谁在哪、朝哪、内外」的方位短语，如「[摊位傍晚]柜前斜看门口，门外右侧是空的[走廊傍晚]」；**禁止**「[场景代称]方向」单独起句或当唯一空间交代；t107u）；**跨多场景时须点名全部相关场景代称（t108u／t109u）**；本镜资产表与【资产细节】同步含这些场景行；闭包仍适用。【资产细节】按资产表顺序每个代称一行写外形／状态。自洽可读＝构图段可读「场景摆位动作＋景别／视角／机位／对焦」；资产细节段可读外形。禁止剧本人名与冗长通用替称堆叠作身份句。
- **一镜一个景别（强制）：** 每条 `prompt` **只许一个景别词**（全景／中全景／中景／中近景／近景／特写／物件特写／屏幕插入／双人中景／低机位中全景等，取自 Storyboard「本镜为…」），**在【构图】内只出现一次**。景深分层用「近处／稍远／深处／后景浅处」或框内前后位置，**禁止**「前景与中景：」「中景与后景」这类把景深写成第二景别；也禁止正文再出现第二个景别词或「不切成××特写」等景别对照句。
- **硬规则（t107u · 构图空间描述准确）：** 【构图】空间描述须准确可读，禁止过度简略。**禁止**用「[场景代称]方向」单独起句或当唯一空间交代；场景代称必须嵌在能回答「谁在哪、朝哪、内外」的方位短语里（如「[摊位傍晚]柜前斜看门口，门外右侧是空的[走廊傍晚]」／「门槛内侧朝门外」）。对焦句写具体对象／区域，不写空「…方向」。与 t102u（点名场景代称）并用：点名≠硬贴「[X]方向」。
- **硬规则（t108u／t109u · 多场景全引用）：** 若本镜画面同时涉及多个场景空间（例：摊内柜前＋门外走廊），【构图】须点名**全部**相关场景代称，且各自嵌在能回答「谁在哪、朝哪、内外」的准确方位短语里（如「[摊位傍晚]柜前斜看门口，门外右侧是空的[走廊傍晚]」）。本镜资产表与【资产细节】须同步含这些场景行；闭包仍成立。**禁止**只写走廊／只写摊位，却用「柜前／摊内／门外」等普通名词暗示另一场景却不点名代称。时段须对齐场次（傍晚／夜间／日间／清晨）。判定：空廊入画、门口内外同框、机位朝门槛与走廊、门外持物者在廊等 → 要补齐双方；仅「朝向门外」作朝向且门外／走廊不入画 → 可不补走廊；纯走廊镜无摊内空间 → 可不补摊位。与 t102u（点名场景）／t107u（禁「[场景]方向」硬贴）并用：点名本镜场景 ≠ 跨场景时只点其一。
- **结构习惯（先调度后摄像机 · t103u）：** 【构图】写成两三句中文：`{调度：场景代称＋谁／物在哪＋当下动作}。{景别}。{视角}。{机位}。对焦在{…}。`。调度句只写场景／摆位／当下动作，不写外形；视角＝平视／俯拍／仰拍／略俯／略仰／贴地仰看等；机位用人话写方位（摊内左前方／柜前斜角等），**不写** D1/D2 等登记号；景别+视角可并写（如「全景俯拍视角」），机位仍宜单独写出（用户示范镜可例外）。【资产细节】＝按资产表顺序分行写外形／状态。**每镜强制点名本镜场景代称**（t102u；`[摊位*]`／`[走廊*]` 按时态；**须嵌在能答「谁在哪、朝哪、内外」的方位短语，禁止「[场景代称]方向」硬贴**；t107u）；本镜资产与【资产细节】同步含场景行；纯方位（门口、柜台）可另保留普通名词。
- **代称（硬）：** 全片为每个角色／物品／场景资产分配唯一 **`[中文代称]`**（方括号）；写入文件头代称表；本镜资产行首 `**[代称]**＝真名`；`prompt` 两段内用 `[代称]`，不把代称译回真名。同一物理资产多态共用一个代称，态写在该行「只锁」或【资产细节】。模板可用字母示意，项目交付以中文方括号为准。
- **有资产时**：资产图仍负责身份／材质／风格一致，但 **prompt 不得因有图而削到读不懂**；构图段布局须可读，资产细节段外形须可读。
- **可保留**：可见静止态（眼灯暗、连续白光、坏耳自然下垂、身体略退后有间距、立姿未蹲）与画面内必须可读的印刷字原文。
- **禁止过程路径与否定过程：** 否定过程（尚未／还没／未／将要／刚要）；动作路径（退后两步、迈进瞬间、刚抬起尚未放下等）；时间过程峰（随后…、准备…）。调度句**允许**当下态（数纸钞／整理／低头／停步／「正在整理」等开镜起点瞬间）。不对比过程峰、不说还没发生什么。
- **禁止堆砌**：风格化 3D 长配方、材质说明书、市井光色长段、负面套话（不要超写实／真人／anime 等）、「按本镜资产图N只锁…」套话、无字幕无水印套话。
- **不写** MidJourney 参数（无 `--no`、无 `--ar`、无 `--raw`、无 `--stylize` 等）。
- 画幅 16:9 在界面设置；可不塞进正文。
- **不写**：剧本人名（改用代称）、情节解释、场号、镜号、情绪解读；禁止冗长通用替称堆叠作身份句。
- **合格自检（每镜）：** ① 只读【构图】能答「场景摆位动作＋景别／视角／机位／对焦」且含本镜场景代称；空间关系可读（谁在哪、朝哪、内外），无「[场景代称]方向」硬贴（t107u）；跨场景时全部相关场景代称均已点名（t108u／t109u）；调度主句无「框内同时可见／几乎占满画框／正对镜头／完整入画」类纯裁切词；② 只读【资产细节】能答各代称本镜外形／状态；③ 对照资产表能把每个代称解析到真名；两段合计代称集 == 本镜资产表。无否定过程与动作路径（印刷字原文与合理静物状态除外）。**景别词整镜只出现一次**（在【构图】内）；无「前景与中景」类第二景别。

**语法（GPT Image · 备选）：**

- 与 Nano Banana **同结构**（职务／第一眼 → **大致故事** → 本镜资产表 → 中文 `prompt`【构图】＋【资产细节】）。
- 同样要求构图段可读布局、资产细节段可读外形；界面设置 16:9。
- **勿臆造**不存在的 API 字段；不要写 MJ 参数。

**文件结构 `Storyboard-Keyframes.md`：**

见 [templates.md](templates.md#关键镜帧提示词条目) 的条目模板。文件头含项目、模型（Nano Banana 默认／GPT Image 备选）、画幅、**「prompt＝【构图】＋【资产细节】」**、上传与绑定规则；其下按镜号分节。曾用 `Storyboard-Keyframes-MJ.md` 后缀已弃。

**与视频词的关系：**关键镜帧是可选的构图上游输入；视频提示词（阶段 13）仍以分镜纯文字画格为过程真源。没有关键镜帧也可以出视频词；有关键镜帧时，在 H3 素材列表里单独绑一张并写清职责。身份三附件参考图规则仍见 `screenplay-development/prompt-generation.md`（可继续 MidJourney），与关键镜帧模型分开。

## MiniMax H3 — 结构（每条）


1. 镜号、秒数、焦距 mm、模式（默认全能参考）、素材列表（图1=…）。
2. **可贴入**：一整段 **中文**。
3. **不要做**：3–6 条可观察禁令，只写进可贴入的最后一段，代码块外不再列一遍。

**可贴入段内容顺序（习惯）**

- `N秒、16:9视频。焦距××毫米，固定不许变焦。`
- **本镜亮度**写成落在谁身上的光（浅灰、深灰、亮明、阴暗是曝光）。不要写「这一镜的光是…浅灰」。人身上用了灰色亮度时，写明不要罩成灰雾、不要改衣服颜色
- 画左、画右、半步、将扣、接触尚未发生，译成画面左/右、迈完就停、碰到之前停住。细则见 `minimax-h3-prompt`「分镜缩写要译成看得见的过程」
- 眨眼、光影、真人实拍、本镜环境一句
- **图 N 绑定**（只锁什么 / 不参考什么）；若含关键镜帧静帧，写明只参考构图与调度，身份仍绑三附件图
- 主体、场景、运动、镜头、声音（句中只用 **图N**，不写剧本人名/场景名/素材代号，也不写他/她/他们/她们）
- 分镜「第一眼 / 眼睛落在」译成对焦，并写明景别是保持还是本镜特写。细则见 `minimax-h3-prompt`「元规则」
- 人的起点写成这一帧的体积和朝向。下缘、暗区不代替站位。朝向背对要碰的人时，先转身再抬手。被碰到的袖口、皮肤、手写图N。细则见 `minimax-h3-prompt`「这一帧的身体写全」
- 英文台词/屏幕字 **原文**；语速正常；每句最多 **重读一词**；画外 **口型闭合**
- 默认 **不要配乐**（禁旋律与垫乐，不只写「无 BGM」）
- **不要做** 作为可贴入的最后一段，以「不要做：」起头。代码块外不再重复这组句子。

**禁止写进可贴入段（剧本背景）**

- 全片调色总谱复述、场号对照（如「绿色只出现在第×场」）、跨场首尾呼应、近未来设定梗概、分镜外的结构说明。
- 总谱留在分镜「视觉策略」或 H3 文件 **对照表**，不粘贴进每条。
- 持有人的名字、揭示顺序和前因留在分镜对照。裁切后看得见的那一段仍然写进可贴入，例如伞面在、伞柄不进入画面。

**项目硬规则（有则写入每条或文件头）**

- 手机：正脸只见背壳；读屏 = 过肩或插入；脸与可读字 **不同框**。
- 播放器/头带 UI：索引与抽象光，不播可辨认记忆画面。
- 记忆场：Gabriel 主观；不反拍 G 客观反应；不出现当下 Naomi；手从 **右下** 入画。

显式 H3 交付：`prompt-writing-guide` → `h3-prompt-writing`（字段/节序/标签/时长）；补充产品手册中的绑图与平台限制。与 Seedance 语法 **不可混用**。

### 本镜资产 ↔ prompt 代称闭包（硬 · t82u／t88u／t92u）
- **本镜资产与 prompt 代称闭包：`prompt`（【构图】＋【资产细节】两段合计）出现的每个 `[中文代称]` 必须在本镜资产有且仅有对应一行；本镜资产不得含 prompt 未使用的代称。**
- 算法：从 `prompt` 用正则 `\[([^\]]+)\]` 提取方括号代称，与全片合法代称表求交；顺序＝prompt 中首次出现顺序；本镜资产按该顺序编号 1..n（亦可按上传需要固定顺序，但集合必须相等）。
- 不入画清理：代称若只出现在「不入画／均不入画／画外不入框」类否定里，从 prompt 删掉该代称（改普通中文），不上传锁图。
- 缺代称补全：屏显／手部借外形等主体若资产原有代称而 prompt 未写，在【构图】主体处或【资产细节】补上。
- 「大致故事」仍可留剧本人名；合格自检：prompt 代称集 == 本镜资产代称集；且每镜含【构图】与【资产细节】两段；**且【构图】含本镜场景代称，资产表与资产细节同步含场景（t102u）**；**且【构图】先调度（场景／摆位／当下动作）后摄像机（景别／视角／机位／对焦）；机位只用大概方位（柜后一侧、门内侧、两人侧面、肩高等），**禁止东西南北**。（t103u）**；**且【构图】空间描述准确可读，禁止「[场景代称]方向」硬贴（t107u）**；**且跨场景时【构图】／资产表／资产细节须全引用本镜涉及的全部场景代称（t108u／t109u）**。
