# 分镜开发模板

以下模板用于组织交付物。每份交付物只使用一种主语言；角色名、台词、镜号及剧本专名必须与剧本一一对应。

```markdown
- 目标市场：
- 交付主语言：
- 分镜工作语言：
- 格式规范：
- 角色 / 地点 / 专名方案：
- 画幅：
- 范围：第 X 场至第 Y 场（模式：单场 / 段落 / 全片 / 诊断 / 修订）
- 各场时长分配（来自剧本时长账）：第 X 场 __ 秒；第 Y 场 __ 秒
- 机器：单机 / 多机；可用支撑：手持 / 稳定器 / 滑轨 / 轨道 / 摇臂
- 拍摄时间：每场约 __ 小时（未知则写「假设」）
- 风格约定：主镜头长拍为主 / 覆盖镜头（coverage）剪辑为主 / 混合（说明）
- 交付物：完整分镜（画格 + 概要图 + 镜头表）/ 只要镜头表 / 诊断

```

## 纯文字画格规格

按镜号正文顺序读完，应能理解整段画面与声音，不依赖另一个附录解释。每格一个主导视觉主意不等于每格只有一个动作；连续发展时写清注意力如何转移。景别、焦距和机位不能互相替代，相机看不见的正脸或道具不得凭情绪意图写进画面。

同一镜号超过十五秒时，在二列表的“画面”字段用 0:00–0:15、0:15–0:30 等时段分开说明。可在同一字段写成多个完整句子；每段的时长相加等于该镜，所有入片镜头相加等于场景总长。不要留未分配的秒数再宣称时长已通过，也不要把全部静止当成活动保持。

第一镜的衔接·入对接片头或上场末帧，最后一镜的衔接·出对接下场首帧或片尾。剧本对白、屏幕文字与说者依原文逐字保留，不能默认改成英文。过肩、俯视和反向机位应核验同一空间，不能在切镜后重建另一间房。

纯文字分镜是导演与剪辑依据。关键镜帧和 H3 / Seedance 提示词另按 prompt-generation.md 生成，不反向替代画格。只有转换成提示词时才应用模型语法，分镜正文不提前套用图N或视频提示词格式。

## 剪口设计

```markdown
## 第 X 场 剪口设计

| 剪口 | 离开动机 | 连接类型 | 入镜新增信息 | 声音时序 | 连续性检查 | 若破例，情感 / 故事收益 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 → 2 | 甲看向门外 | 视线 + 银幕位置 | 门外是乙，不是预期的人 | 乙脚步声先入 | 轴线、视线通过 | 不适用 |
```

连接类型：动作 / 银幕位置 / 图形或形状 / 概念并置 / 复合。声音时序：同步 / 声音先入 / 声音延续 / 有意静默。

每个剪口均按 reference.md 的“计划外越轴的判断与修复”判断；普通通过项可在连续性检查栏简记依据。发现疑似或确定的计划外越轴时，按剪口补写以下记录，不把整段修复说明塞进宽表：

```markdown
### 剪口 X → Y 的越轴修复记录

| 项目 | 记录 |
| --- | --- |
| 原空间与判断 | 写明前镜落幅、后镜起幅的有效轴线、机位所在侧、人物银幕位置、视线与行进方向，说明是否存在可见的新轴线依据；资料不足时写明待补内容。 |
| 实际修复 | 写明选择的方案、修改的镜号和具体画面变化，并指出概要图、机位登记及剪口字段的同步位置；不能只列建议。 |
| 代价与时长 | 说明必要信息、戏剧职务及制作负担的变化；增删镜头或改变动作耗时后填写重算结果。 |
| 连续序列复查 | 写明从哪次空间建立读到哪镜、修复镜入出剪口的检查证据，以及有无新增方向、动作或信息问题。 |
| 结论 | 明确写出已修复并复查通过、未修复或未验证，并区分纸面、几何与成片验证范围；未修复或未验证时阻断交付。 |
```

## 呼吸点检查

必要时填写；无需要写「不增镜 / 镜内留白即可」及理由，不设每场必填配额。空镜不等于舒缓。

```markdown
## 呼吸点 · 位置：高峰后 / 高密度中 / 升温前 · 镜号或镜内段 ____

- 消化什么：前文哪次冲击、信息或情绪需要时间落定
- 画面可见过程：无人环境 / 物件 / 有人反应 / 远景 / 镜内停留；观众实际看见什么在继续
- 意图：舒缓消化 / 加压等待 / 其他
- 前后接法与声音：从哪一剪入、切出到哪；声音底、抽层或静默如何配合
- 时长与预算来源：__ 秒，来自本场分配 / 相邻镜压缩 / 其他
- 删并对照：删掉或并入前后镜后损失什么；若无损失则不单立此点
- 结论：保留单镜 / 镜内留白 / 不增镜，理由：
```

例：高峰后可单立空走廊两秒承接摔门；高密度中也可不增镜，只把远景跟跑多停一拍。

### 本镜资产 ↔ prompt 代称闭包（硬 · t82u／t88u／t92u）
- **本镜资产与 prompt 代称闭包：`prompt`（【构图】＋【资产细节】两段合计）出现的每个 `[中文代称]` 必须在本镜资产有且仅有对应一行；本镜资产不得含 prompt 未使用的代称。**
- 算法：从 `prompt` 用正则 `\[([^\]]+)\]` 提取方括号代称，与全片合法代称表求交；顺序＝prompt 中首次出现顺序；本镜资产按该顺序编号 1..n（亦可按上传需要固定顺序，但集合必须相等）。
- 不入画清理：代称若只出现在「不入画／均不入画／画外不入框」类否定里，从 prompt 删掉该代称（改普通中文），不上传锁图。
