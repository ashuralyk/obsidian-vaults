# 分镜开发模板

以下模板用于组织交付物。每份交付物只使用一种主语言；角色名、台词、镜号及剧本专名必须与剧本一一对应。

```markdown
- 目标市场：
- 交付主语言：
- 分镜工作语言：
- 格式规范：
- 角色 / 地点 / 专名方案：
- 画幅：
- 范围：第 X 场至第 Y 场（模式：单场 / 段落 / 全片 / 诊断 / 修订）
- 各场时长分配（来自剧本时长账）：第 X 场 __ 秒；第 Y 场 __ 秒
- 机器：单机 / 多机；可用支撑：手持 / 稳定器 / 滑轨 / 轨道 / 摇臂
- 拍摄时间：每场约 __ 小时（未知则写「假设」）
- 风格约定：主镜头长拍为主 / 覆盖镜头（coverage）剪辑为主 / 混合（说明）
- 交付物：完整分镜（画格 + 概要图 + 镜头表）/ 只要镜头表 / 诊断
```


## 镜头表

每个镜头一行。连续运动沿用同一镜号，关键时刻在同一行的纯文字描写中用 **3a / 3b** 或 **0:00–0:15** 分段。

<a id="inline-pure-text-column"></a>
### 纯文字描写（按镜号，Obsidian / 预览友好）

标准 Markdown **pipe 表格不支持单元格内换行**；把整镜纯文字塞进单列会导致单行数千字符，Obsidian 阅读模式常截断、不换行或整表解析失败。**默认交付结构：**

1. **索引表**（四列，行短）：镜号 | D机位 | 时长 | 职务·新增信息  
2. **紧接镜号正文**：每个镜号一个 `##### 镜 1.2 · D2 · 6秒`，其下用加粗小标题分段（不用 `<br>` 堆在同一表格 cell）。

字段顺序固定：

**衔接·入** → **画面（按时间）** → **摄影机** → **人物动作** → **声音** → **主意·第一眼·光** → **需要注意** → **禁止出现** → **衔接·出**

```markdown
## 第 X 场 镜头表

| 镜号 | D机位 | 时长 | 职务·新增信息 |
| --- | --- | ---: | --- |
| 1.2 | D2 | 6秒 | 主镜；Claire 主动离开安全区 |

#### 本场分镜正文（按镜号）

##### 镜 1.2 · D2 · 6秒

**衔接·入**

硬切自 1.1，伞沿与雨声连续……

**画面（0:00–0:06）**

0:00–0:02 中全景……

**摄影机**

轻摇约 15° 随 Claire 向画右，她停即停……

（其余字段同上）

---

合计剪辑时长：__ 秒（分配 __ 秒）
```

导出给只接受「单表一行」的 spreadsheet 时，可另生成 CSV；**仓库内主分镜稿以索引表 + 镜号正文为准**。HTML `<table><td>…</td>` 多段落单元格仅作备选，不与 Obsidian 主稿混用。

每个镜头填写剪辑时长。默认不超过 15 秒。同一镜号必须更长时，在该行的时长格写成「40 秒 = 15 + 15 + 10」，并在**纯文字描写**单元格的 **画面** 段按 0:00–0:15 分段。各段相加等于该镜时长；各镜相加落在本场分配内。不要把可以切开的镜头写成超长一镜，也不要把短镜头填到 15 秒。

字段用语：

- 作用：主镜 / 基位 / 峰值 / 保险 / 插入 / 场界
- 景别：远景 / 全景 / 中景 / 近景 / 特写 / 大特写
- 高度 / 角度：低于眼 / 头高 / 高于头；平视 / 仰 / 俯 / 倾斜
- 焦距倾向：短焦 / 中焦 / 长焦（需要时写毫米数）
- 机器运动：固定 / 推 / 拉 / 横移 / 摇 / 环绕 / 升 / 降 / 手持跟
- 剪接点：切至 / 连续（同号分格）/ 叠化 / 匹配切；并注明重叠的动作

## 画格说明

以文字代替图像时，每个画格采用以下格式。交付物若需支撑 AI 视频、预演或「闭眼能剪」的预剪，**必须**在镜头表同一行的 [纯文字描写列](#纯文字描写列) 写满 [纯文字画格规格](#纯文字画格规格) 各段；不得另开附录重复同一镜号。

### 摘要画格（镜头表同行或短说明）

```markdown
### 镜 3（3a—3c 为同一连续镜头）

**3a**　近景，D2，头高平视，中焦。画左三分之一是乙的右肩和后脑（虚），甲在画右，脸朝画左，视线越过乙。背景是窗，深灰。
视觉主意：甲第一次无法躲开乙。眼睛先落：甲的眼睛。负空间：画右空位等待甲退开。
框外箭头：推（缓）。框内箭头：甲向画左前倾。
对白：甲：「……」

**3b**……乙转身离开，画左空出。机器停住。

**3c**……甲独在画中，近景。

切至：镜 4
```

<a id="pure-text-frame"></a>
## 纯文字画格规格

目标：**按剪辑顺序读镜头表「纯文字描写」列，等于读完整段视频**——不依赖景别缩写，也不假设读者已看过概要图。每个镜号占表格一行；连续运镜在同一单元格内用时间段或 3a/3b 分格。

**写法原则**

- 按**时间顺序**写观众看见什么（默认每 15 秒一段；更短镜头可写 0:00–0:06 一整段）。
- **摄影机运动**写清：起止状态、方向、速度（慢/中/快）、何时因人物停而停、有无手持微晃。
- **人物动作**写到可表演：肢体起止、视线落点、手与道具的先后、微表情；对白标英文原文与说者。
- **衔接·入 / 衔接·出**各写一句：与上一镜共享的图形、动作、声音或位置；本镜末帧留给下一镜的钩子。
- **需要注意**与**禁止出现**分开：前者是执行要点与连续性；后者是不可出现的画面错误（含本片总谱禁用项）。
- 仍遵守「每段一个主导视觉主意」与「第一眼落点」；纯文字规格是展开，不是第二个主意。

```markdown
### 镜 1.2（6 秒）

**职务 / 新增信息：**主镜；Claire 主动离开伞下安全区。

**衔接·入：**硬切自 1.1 末帧——黄伞沿仍占上缘，暴雨声连续；本镜第一帧可保留伞沿一条，随即 Claire 从下缘闯入亮雨区（银幕位置：从安全区进入雨区，与 1.1 的「伞内/伞外」分区一致）。

**画面（0:00–0:06）**
- 0:00–0:02：中全景，D2，肩高约 1.5m，40mm 倾向。画左保留黄伞下缘一条；Claire 从伞下缘**向上**冲入画面中央偏右，身体已半湿，头发贴额；Gabriel 仍在伞下画左后，只露肩与袖口，不入 Claire 的视线目标。
- 0:02–0:04：Claire 完全站在伞外亮雨区，面向画右（河的方向），大笑，嘴型可见；**第一眼落点：**左腕内侧颜料渍（红/黄杂色，非血）。
- 0:04–0:06：Claire 向画右迈出一步，雨帘在身后形成亮幕；Gabriel 的手从画左伸入帧边缘，尚未扣住——为 1.3 留手。

**摄影机：**开机固定；Claire 冲出时**轻摇**约 15° 随其向画右，0:03 她停步即**停摇**，不推近、不跟脸。

**人物动作：**Claire 速度中快、带笑；湿发甩动一次即可；Gabriel 在伞下**不动**，只伸手。

**声音：**暴雨连续，无配乐；Claire 笑与雨声同级，无对白本镜。

**视觉主意 / 第一眼：**安全区留在身后，Claire 走进比她更亮的雨。第一眼：左腕上的颜料。

**光意图：**打在 Claire 脸上和手臂上的侧逆光保持浅灰，雨幕比她更亮，落到亮明。浅灰和亮明是亮度级，不要拍成灰雾，也不要改衣服的颜色。伞下的 Gabriel 保持深灰。

**需要注意：**Claire 与 Gabriel 衣着反差（湿/干、随意/整洁）在本镜已可见；Gabriel 不得先于 Claire 进雨。

**禁止出现：**情侣式拥抱、Claire 正脸大特写占满画框、Gabriel 与 Claire 同框对称构图、推近「解释」情绪、当下 Naomi 或任何现代道具、河面绿色（留给 1.4）。

**衔接·出：**切至 1.3 时，Gabriel 的手应已触及 Claire 手腕或即将扣住——剪点在「手将合未合」或「刚扣住」重叠 4 帧；雨声与亮雨区曝光连续。
```

连续镜号超过 15 秒时，在 **画面** 下用 **0:00–0:15 / 0:15–0:30** 分段；每段仍写摄影机是否继续同一运动。

**场首 / 场末：**第一场第一镜的 **衔接·入** 写「片头 / 黑场后」或场界表；每场最后一镜的 **衔接·出** 对接下一场 **衔接·入**（可引用场界成对设计）。

**与视频提示词的关系：**纯文字画格是导演与剪辑依据；转 H3 / Seedance 时再按 `prompt-generation.md` 压缩，不得反向用提示词代替画格规格。

同一镜号超过 15 秒时，用时间段代替含糊的总时长。下面这条是 37 秒的连续镜头，镜号仍是 4：

```markdown
### 镜 4（连续 37 秒 = 15 + 15 + 7）

**0:00–0:15**　近景，D1，头高平视，固定。甲的手停在乙的肩上，两人都不动。
视觉主意：这一停本身就是事件。眼睛先落：甲的手。

**0:15–0:30**　同一镜，机器仍固定。甲的手指开始一根根松开。
视觉主意：停结束了，松手开始。眼睛先落：松开的第一根手指。

**0:30–0:37**　同一镜。手离开，画中只剩乙的肩。机器不跟甲。
视觉主意：甲已经走了，机器留下这个决定。眼睛先落：空出的肩。

切至：镜 5
```

## 剪口设计

```markdown

| 剪口 | 离开动机 | 连接类型 | 入镜新增信息 | 声音时序 | 连续性检查 | 若破例，情感 / 故事收益 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 → 2 | 甲看向门外 | 视线 + 银幕位置 | 门外是乙，不是预期的人 | 乙脚步声先入 | 轴线、视线通过 | 不适用 |
```

连接类型：动作 / 银幕位置 / 图形或形状 / 概念并置 / 复合。声音时序：同步 / 声音先入 / 声音延续 / 有意静默。
