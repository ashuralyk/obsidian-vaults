# 分镜开发模板

以下模板用于组织交付物。每份交付物只使用一种主语言；角色名、台词、镜号及剧本专名必须与剧本一一对应。

## 制作框架

```markdown

- 目标市场：
- 交付主语言：
- 分镜工作语言：
- 格式规范：
- 角色 / 地点 / 专名方案：
- 画幅：
- 范围：第 X 场至第 Y 场（模式：单场 / 段落 / 全片 / 诊断 / 修订）
- 各场时长分配（来自剧本时长账）：第 X 场 __ 秒；第 Y 场 __ 秒
- 机器：单机 / 多机；可用支撑：手持 / 稳定器 / 滑轨 / 轨道 / 摇臂
- 拍摄时间：每场约 __ 小时（未知则写「假设」）
- 风格约定：主镜头长拍为主 / 覆盖镜头（coverage）剪辑为主 / 混合（说明）
- 交付物：完整分镜（画格 + 概要图 + 镜头表）/ 只要镜头表 / 诊断
- 假设：
```

## 纯文字画格规格

按镜号正文顺序读完，应能理解整段画面与声音，不依赖另一个附录解释。每格一个主导视觉主意不等于每格只有一个动作；连续发展时写清注意力如何转移。景别、焦距和机位不能互相替代，相机看不见的正脸或道具不得凭情绪意图写进画面。

同一镜号超过十五秒时，在二列表的“画面”字段用 0:00–0:15、0:15–0:30 等时段分开说明。可在同一字段写成多个完整句子；每段的时长相加等于该镜，所有入片镜头相加等于场景总长。不要留未分配的秒数再宣称时长已通过，也不要把全部静止当成活动保持。

第一镜的衔接·入对接片头或上场末帧，最后一镜的衔接·出对接下场首帧或片尾。剧本对白、屏幕文字与说者依原文逐字保留，不能默认改成英文。过肩、俯视和反向机位应核验同一空间，不能在切镜后重建另一间房。

纯文字分镜是导演与剪辑依据。关键镜帧和 H3 / Seedance 提示词另按 prompt-generation.md 生成，不反向替代画格。只有转换成提示词时才应用模型语法，分镜正文不提前套用图N或视频提示词格式。

## 关键镜帧提示词条目

文件：`Screenplays/<Title>/Storyboard-Keyframes.md`。阶段 0「产出关键镜帧提示词」**默认开**；分类默认 **Nano Banana**（备选 GPT Image）。开且分镜就绪后产出。每镜一张＝该镜开镜首帧；每镜结构含「大致故事」（在本镜资产上方）；禁止默认首中尾三张；禁止用峰值／中间／尾帧顶替首帧。曾用 `-MJ` 后缀已弃。

~~~markdown
# Storyboard Keyframes — Nano Banana

- 项目：〈片名〉
~~~
