# 分镜质量检查：从字段核对到实际镜流

## 使用与判定

在正式镜头序列完成后、双评分之前执行本表；修订后重查受影响项，并完整顺读授权范围。先固定同一剧本版本、附件与测试范围。每项记录通过、失败或不适用，附具体镜号、画面或声音证据及修复动作。未知不能写成通过；纸面可行、几何核验和成片验证必须分开。

条目用于发现问题，不按勾选比例折算质量分。关键事实缺失、因果改写、必要动作不可见、无法成立的空间或时间方案，属于执行失败，修复前阻断交付。景别重复、镜头冗余、特写分配与风格选择先是待举证问题，不能凭次数自动阻断；只有它们造成可指出的理解或执行失败，或触发原量表的质量上限时，才按相应规则处理。

## 1. 检查输入与判断范围

- [ ] 已记录明确版本和覆盖范围，剧本与人物、地点、道具附件一致；冲突已列出且按正文优先处理。
- [ ] 已说明本段开场与结尾的状态，以及导致变化的关键行动。
- [ ] 已区分执行缺陷、可争论选择和偏好，没有把未经验证的效果写成事实。
- [ ] 不适用项有理由，未知条件与未验证范围另列，不用不适用逃避质量问题。

## 2. 检查剧本是否进入画面

- [ ] 每个关键事件都在画面、动作或声音字段中实际呈现，而不只出现在引文、职务或备注里。
- [ ] 动作的发起方、顺序与结果没有改变，主观感受由可观察行为承载。
- [ ] 对白、专名、屏幕文字及时间信息没有遗漏、增写或改义；画外对白也有准确落点。
- [ ] 人物和观众获知信息的顺序与剧本一致，新增反应没有提前揭示结局。
- [ ] 所定景别、遮挡与持续时间让关键身体动作、道具和文字可读；需要精读的表面已经获得足够画幅。

## 3. 检查每镜的实际作用

- [ ] 每镜说明观众因此看见、理解、期待或感受到什么，实际事件支持该作用。
- [ ] 已试读删除或合并可疑镜头后的序列，能指出损失；没有损失时优先删并，而不是补一句解释。
- [ ] 没有新事实的停留仍有倾听、等待或情绪消化，前文压力足以支撑该时间。
- [ ] 每镜有一个主导视觉主意；注意力转移有次序，没有要求观众同时读两个竞争重点。第一眼必须指向可辨认的对象或部位，不能以“本镜的主要变化”代替落点。

## 4. 检查连续景别与重复

- [ ] 已按实际剪辑顺序展开每段的景别、主体、角度、时长与作用，而非仅统计全片平均值。
- [ ] 连续同景别各有理由；同一主体、近似角度和构图的硬切已检查尺度变化、三十度默认语法或有意跳切。
- [ ] 没有为制造变化而机械轮换远中近；匹配正反打、克制与相似结构可以成立。
- [ ] 连续近景没有丢失关系地理，连续远景没有使关键动作与表演不可辨。
- [ ] 近景与特写没有无意消耗后续转折的表达余地；不同转折可用不同手段，也允许有依据地保持距离。
- [ ] 相同反应、揭示、构图或推近再次出现时，信息、关系、节奏或后果发生了可说明的变化。

不使用“连续三个同景别即失败”等固定次数规则。发现可疑重复时，比较保留、合并或改变观看位置的实际短镜流，记录各自收益与损失。

## 5. 检查剪口与空间

- [ ] 每个剪口都有此刻离开的动机、入镜的必要内容、连接类型与声音时序。
- [ ] 概要图与实际画面一致，相机能看到所写事件；必要时核验边界点，而非只检查主体中心。
- [ ] 视线、银幕方向、身体朝向、道具状态和动作阶段能衔接，剪掉的时间不造成瞬移。点数、整理等日常过程允许省略，但须标明时间省略及定位依据，不能写成实际完成不了的连续动作。
- [ ] 越轴、空间重建与视点改变有触发和定位线索，观众能重建关系。
- [ ] 最小可剪集合齐全，额外保险素材有风险依据，且未重复计入成片账。

## 6. 检查镜内时间

- [ ] 自然语速下，对白、动作、必要反应和表面阅读能装入该镜；高负载镜已列时间预算。
- [ ] 能并行的过程才重叠计算，需要先看再理解、再回应的事件保留先后。
- [ ] 门、车、倒计时等持续运动跨切口继续核算，没有切走即暂停的隐含假设。
- [ ] 停顿内有活动保持；具体秒数是制作预算，不要求表演机械卡点。
- [ ] 各场时长、全片时长和备用素材账相互一致；必要长镜已分段，不靠技术时限随意拆镜。

## 7. 检查戏剧变化与声画

- [ ] 场景支点明确，镜头组织响应真正改变局势的事件；克制不变也有可见作用。
- [ ] 关系通过距离、共享画框、遮挡、运动或视点发生变化，不依赖心理形容词。
- [ ] 观众距离和知情程度的改变有故事依据，高峰后的反应时间没有被无关镜头冲淡。
- [ ] 声音、静默、画外空间和留白改变理解或等待，不重复解释已清楚的画面。

## 8. 检查段落与全片

- [ ] 视觉强度、镜头密度、景别和镜长形成可追溯结构，不要求与情绪机械同向。
- [ ] 覆盖形态和转折处理没有无理由地复制；母题在重复时改变意义或后果。
- [ ] 场界的末帧、首帧、声音和情绪承接已成对复查。
- [ ] 总谱声称的变化在实际镜流中成立，不能由总谱替未兑现的镜头得分。

## 9. 检查制作方案

- [ ] 机位、画幅、焦距、主体距离与景别相容，演员和相机路线不会遮住关键事件。
- [ ] 主体与背景光意图明确，时段和状态连续；浅灰等词指受光，不改衣物颜色。
- [ ] 机位、布光、表演、动画与特效负担符合已知条件；未知排期没有被宣布通过。
- [ ] 复杂场的压缩版是一条独立完整序列，重新核算时长和机位并说明损失。
- [ ] 已区分纸面方案、几何检查、预演与真实制作的验证范围。

## 10. 检查破例与交接结论

- [ ] 每项破例列出镜号、被打破的规则、具体触发、预期收益、理解代价和补偿线索。
- [ ] 高分依据实际镜流和观众理解的变化，没有把字段齐全、镜头更多或术语正确当成表现力。
- [ ] 双评分分别报告，已核实的阻断项和封顶不会被平均或其他长处抵消。
- [ ] 评分前先写裸读记录再看量表：裸读发现的具体问题在第二段有归属或被单列为量表外缺陷，量表分与裸读印象的差异有镜号证据。
- [ ] 新稿完整顺读，列出收益、损失和新增问题，并将旧稿与审查记录保留。
- [ ] 最终结论明确区分阻断项、优先修改项和未验证风险，不把平台期当作就绪。
