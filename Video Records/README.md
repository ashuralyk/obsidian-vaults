# Video Records — 仓库约定

用法：粘贴视频链接 → 提取文字稿 → 蒸馏入库。

## 目录

- `00 Inbox/`：待处理链接
- `01 Videos/YYYY/`：蒸馏主笔记
- `02 Transcripts/YYYY/`：全文稿归档
- `03 Topics/`：主题索引（MOC）
- `04 Creators/`：创作者 / 频道索引
- `Templates/`：笔记模板
- `Attachments/`：封面与截图

## 命名

- 主笔记 / 文稿：`YYYY-MM-DD · 视频标题.md`
- 文稿可放在 `02 Transcripts/`，或使用 `.transcript.md` 后缀

## 主笔记属性

`type` / `status`（inbox → processing → distilled）/ `url` / `platform` / `creator` / `published` / `watched` / `topics` / `transcript`

## 蒸馏正文

一句话 → 核心观点（尽量带时间戳）→ 值得记住的细节 → 我的反应 → 关联
