# 分镜表左页画格右页鸟瞰一一对应

## 是什么

*Cinematic Motion* 规定的制片向 **分镜表终稿形态**：**左页** 按序编号的分镜画格 + 镜下 **镜头说明**（对白写在说明下）；**右页** 配套 **拍摄示意图/鸟瞰图**，编号与左页一致，机位常冠 **「D」** 前缀。一编号 = 一镜头；连续运镜用 1a–1c 等同号分格。部分场次另附 **概要图**（全场俯视图），符号与单镜图统一。

## 为何重要

肯沃斯俯视图教 **单技巧**；卡茨 Motion 教 **整场的纸面交付物**，副导演可据此排 **同角同批** 拍摄日。这是 PPK「高质量分镜表」的 **推荐物理版式**，与 AI 视频提示词无关。

## 怎么用

流程：**剧本场职务** → 右页概要图标轴线与 D 位 → 左页填格与 [[故事板要标清运镜切至与连续镜分格]] → 峰值镜备注可引肯沃斯条目 → 第二遍 [[分镜须成对设计场景首尾帧]] → **Lighting 列** 见 [[画格六级亮度用来沟通布光意图]]。Ch.5 类长场面（《阿波麦托克斯》）：鸟瞰负责 **机位号与安置**，运动细节仍要文字补。

## 边界

小项目可用单页 shot list + 简图；字段语义（编号、切至、箭头）仍应保留。
