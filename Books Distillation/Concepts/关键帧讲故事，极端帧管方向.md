# 关键帧讲故事，极端帧管方向

## 是什么

key（关键帧）是“讲故事的那一张”，回答这个镜头里发生了什么；extreme（极端帧）是“必须存在的那一张”，回答动作在哪里改变方向、在哪里接触、在哪里承重。两者必须分开：一旦混用，人就会淹死在几十个姿势里，丢掉镜头的重点。威廉姆斯说，先把故事讲清楚的那两三张画到最好，再补其他；Frank Thomas 为一张猫的表情画了一整天，因为那是 key。

## 为何重要

一个镜头的信息量有限。观众只能同时接住一件事，key 就是那件事；极端帧和中间帧都是“怎么过去”。先画 key，可以用最便宜的方式检验故事通不通；先画极端，容易把注意力花在接触点和承重上，戏反而散了。

## 怎么用

先用火柴人画三张，圈起来，算出它们落在第几格——走过去四秒就是九十六格，第二个 key 落在九十六；只拍这三张，看故事通不通。通过后再补 extreme：脚接触地、手碰到粉笔、预备的最低点。extreme 不画圈，只有 key 画圈。

## 边界

“key animator”不是“只画 key 的人”，而是像“key executive”一样，指重要的动画师。也不是所有极端都叫 key；把所有极端都当 key，是旧习惯，会把整理工作搞乱。反过来，只画两张 key 就把中间丢给助手，然后去打网球，是对助手和片子的双重不负责。
