# Audio-Vision（米歇尔·希翁）

米歇尔·希翁著，克劳迪娅·戈尔曼编译，哥伦比亚大学出版社 2019 年第二版英译本（CIP 记 2018），译自法文第四版（2017）；默奇 1994 年的序原样保留，描述的是第一版十章结构，不能当这一版的导读。这不是一本讲录音技术的书，而是一套关于“声音如何改写画面”的概念工具。

## 摘录

> “By added value I mean the expressive and informative value with which a sound enriches a given image so as to create the definite impression … that this information or expression ‘naturally’ comes from what is seen and is already contained in the image itself.”（第一章，Added Value）

> “Synchresis … is the spontaneous and irresistible weld produced between a particular sound event and a particular visual event when they occur at the same time. This join results independently of any rational logic.”（第三章，Synchresis）

> “When sounds are placed in relation to shots in a film, there is no soundtrack.”（第三章，The Predominance of the Vertical）

## 中心论证

声音和画面之间没有天然和谐，二者靠一份“视听契约”结合。声音给画面追加意义，观众却把意义误认成画面自带的；因此电影研究长期低估声音。希翁用一组新词把这种关系拆开：追加价值、同步融合、人声中心、画外存在、渲染、听点、还原听。他的目标不是证明声音比画面重要，而是说明两者如何共同生产一个观众以为单一的经验。

## 关键内容

- 追加价值：声音给画面带来表情和信息，却让观众觉得这些本来就在画面里；声音越好，画面越显得好。
- 人声中心与语言中心：混合声中的人声自动吸住注意力；录音、混音和字幕都围绕它组织。
- 同步融合：声音与画面在精确同一点发生，会被观众焊成一个事件，哪怕真实因果不匹配。
- 三种听法：因果听（这是什么）、编码听（它在说什么）、还原听（声音本身的质地）；因果听又分具象与侦查。
- 画外存在：只听见、看不见的角色悬在画内与画外之间，常被赋予看见一切、全知、全能、无处不在的权力；一旦被看见，权力就移交给了身体。
- 声音没有画框：它总在寻找自己的位置；单声道时代靠画面“磁化”定位，深度靠混响与频响暗示，多声道让真实方位成为可能。
- 渲染而非复制：拟音要传达重量、材质和感觉，不是复刻真实声音；玉米淀粉比真雪更像雪。
- 静默、悬置与“负形”：静默不是没有声音，而是被组织出来的对比；该响而不响，会产生看不见的空洞。
- 音乐可以贴着画面（共情），也可以冷眼旁观（反共情）；反共情不是冷漠，而是把情绪放到一个更大的背景上。音乐还是唯一能穿墙的声音元素，可以从一场戏流进另一场，是转场的“时空转盘”。
- 声音把画面的时间变成可感的：静照因声音获得时间，节奏的规则性比速度更能改变观众对画面的时间感。
- 声音替剪接做黏合与标点：把切开的画面连成一条流，用一声狗叫或台球撞击替台词收尾，也可以先一步把下一场的空间放出来。
- 对白分三种：戏剧性（被完整听见、支配调度）、文本性（说出一个词就能召来画面）、散发式（听不清、不推动剧情，是人物的分泌物）。三种用错一种，整场戏就塌。

## 边界

这是理论书，不是操作手册。例子以欧洲艺术片和好莱坞经典为主，技术判断（单声道、Dolby、影院声场）带有年代。希翁明确反对把“音画对位”当万能概念：很多被称作对位的段落，其实只是不协和的和声。书中的术语中译尚未统一，落库时以机制为准，不照搬译名。
