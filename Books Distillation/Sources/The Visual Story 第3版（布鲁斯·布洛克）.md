# The Visual Story 第3版（布鲁斯·布洛克）

Bruce Block 著，Routledge 第三版，2020。全书不把视觉风格理解为镜头花样，而是把画面拆成空间、线条、形状、明暗、色彩、运动与节奏七种可控制的成分，再用对比与相似组织它们。

## 中心论证

故事有自己的强度曲线，视觉也有。导演可以让某种视觉成分保持恒定，让某种成分随冲突递进，也可以在关键节点突然制造对比。视觉成分若不受控制，仍会自行形成结构，只是这套结构往往与故事争夺注意力。

## 关键内容

- 对比提高视觉强度，相似降低视觉强度；这个规律同时作用于单格、镜与镜、场与场。
- 空间不只分深浅，还可设计成深、平、有限与含混四种状态。开放空间与封闭空间说的是画面和边框的关系，不等于地点大小。
- 剪辑节奏由交替、重复与速度共同构成。相邻镜头视觉差异越大，切口越响；越相似，切口越轻。
- 全片视觉结构有三种基本组织法：恒定、递进、对比与相似。视觉曲线可以与故事曲线并行，也可以有意对位。
- 视点首先是创作者希望观众怎样感受人物与题材，不等于摄影机的物理角度。

## 边界

本书提供视觉结构，不替代场面调度、coverage 与剪辑连续性。它最适合进入全片视觉总谱与节奏矩阵，不宜被缩成一张“不同颜色代表什么”的符号表。
