# 从零开始写故事（叶伟民）

叶伟民著，知乎「一小时」系列 epub（南方周末特稿记者经验）。原书文件未放入 `Sources/attachments/`。

## 中心论证

特稿是非虚构在新闻领域的短故事形式：**真实 + 文学 + 意义**，并强调公共性与问题意识。写作可标准化拆解：用**三同心圆**定主题（故事—问题—意义），采访前用**世界线**做案头拼图，采访中追求**创造性采访**，结构上在模块、时间线、多人物/空间、剥洋葱四类间组合，成稿时按**人—事 / 人—人**两种模式推情节，并用叙述、描写、引语、背景四元素配搭节奏。

## 关键摘录

- 狭义非虚构：真实、文学手法、意义指向；特稿另需公共利益。
- 三同心圆：本体（故事）→ 所指（问题，刚需）→ 外延（意义）；中心是问题意识，且须有人性闪光。
- 世界线：时间法 / 空间法整理资料，像警匪片拼图。
- 创造性采访：双方对话达到任一方无法独自达到的知晓程度。
- 四种结构：模块式、时间线（单/双）、多人物多空间、剥洋葱式。
- 两种模式：人—事（执念—行动—困难—结果）；人—人（形象—相识—对立/破裂—和好/相杀）。
- 行文四元素：叙述、描写、引语、背景（「一二三四」舞步）。
- 4.3 写好开头：给读者的**合同与邀请**。
