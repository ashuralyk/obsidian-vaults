# 走出幻觉走向成熟（金融帝国，2012）

本书全名《股经·走出幻觉 走向成熟：从学生股民到系统交易专家》，2012 年由中国经济出版社出版。作者用自己从 1997 年牛市顶部走到系统交易的路，解剖行业如何卖幻觉，以及为什么趋势跟踪是他认为散户能走通的路。它不是另一本「怎样赚钱」的教程，而是一本把交易当成概率游戏、把成熟当成接受成本的自传。

本地阅读文件为 EPUB，见 `Sources/attachments/走出幻觉走向成熟（金融帝国）.epub`。理解已拆入概念笔记；本篇只保留来源定位、短摘录与阅读边界。与 Douglas 重叠的机制写入对应概念的「多源互证」。

## 中心论证

作者十几岁在 1997 年的顶部走进股市，十九岁前把家里积蓄亏掉一半；真正用真钱赢回来，是 2008 年以后的事。他把这段路写成：行业卖的是确定性、神奇大师和不用付代价的技巧。大师的结局本身就是反证：格雷厄姆走向有效市场，韦尔德走向顺其自然，利弗莫尔自杀，江恩留下的财产也撑不起后来的神话。

市场的真相是冰山：你能说出的原因 A，加上你看不见的 X，才等于结果 B。事后看起来合理的路径，不等于事先可以预测。学习效应会收割追赶新法的人；正确率与赔率互损；趋势跟踪用赔率换正确率，先付出「跟丢」的代价。资金管理不能把负期望翻正；分散只是把微观破产风险抹平。

价值投资不是占便宜。价格是绝对的，价值随观察者的价值观而变。散户在基本面上没有信息优势；止损和价值信仰也容易冲突。他把趋势跟踪写成「最不坏」的路：量化贪婪与恐惧，把预测变成环与链，个性化之前先接受成本。最后他也招认：心灵与效率互损，这条路可能衰弱，但在中国以散户为主的市场里，它还能走很久。

## 关键摘录

- 「A + X = B」你能解释的部分加上看不见的部分，才等于市场结果。
- 事后合理的树形路径，不等于事先可知。
- 盈亏同源：让你赚钱的机制，也是让你亏钱的机制。
- 超市原理：过高的正确率会把赔率吃掉。
- 点球原理：趋势是用赔率赌出来的，不是看见的。
- 交易必须成环成链；预测做的是点。
- 资金管理翻不了负期望；分散只抹平微观风险。
- 价格是绝对的，价值是相对的。

## 阅读导航

- 第一部：个人路与行业幻觉。
- 第二部：概念工具（冰山、树形、恐龙、钟摆、盈亏同源、学习效应、超市、点球等）。
- 第三部：基本面的边界与价值观。
- 第四部：系统交易的路径与资金管理。
- 第五部：交易与生活，心灵与效率。

## 来源边界

作者的结论锁定在中国 A 股与期货的散户市场。「卖完理论」、部分市场奇闻和对个别大师的定性评价，不应写成通用定律。趋势跟踪是他的解法，不是价值投资的替代品。把本书读成「散户不能做价值投资」，会把他对信息优势的警告，误成对 Graham—Buffett 路线的否定。

他对「看见趋势」的不信任，比 Douglas 更彻底。同样谈概率、规则和承担，他把最高阶段留给接受成本的机械系统，而不是直觉。
