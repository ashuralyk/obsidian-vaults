# 大师场景（杰弗里·迈克尔·贝斯）

杰弗里·迈克尔·贝斯（Jeffrey Michael Bays）著，英文原题 *Between the Scenes: What Every Film Director, Writer, and Editor Should Know About Scene Transitions*（Michael Wiese Productions，2014）。中译本副题强调导演、编剧、剪辑师必知的**场景转换**。书名同属「大师」书系，作者不是克里斯托弗·肯沃斯。肯沃斯管一场之内的机位；本书只转**场景 A 结尾与场景 B 开头之间**的衔接技艺。全书由硕士论文改写，案例以 1980–2010 年代好莱坞叙事片为主。

本地 pdf 为嵌图扫描（无可检索文字层）。2026-10-05 逐章对表以英版十章目录互证；见 [[Outputs/briefings/扫描类剧本分镜书逐章对表-2026-10-05]]。

## 中心论证

行业习惯把精力砸在单场戏，按时间轴一拼才发现**衔接处**决定节奏与情感是否连贯。贝斯认为：戏剧的动态变化主要发生在**转换带**里——观众在此内化事件（思考、感受、舒缓或加张力、与人物共情）。场景是**单一场所里的事件**；转换是**事件的内化**。多数转换应像冰山在水下（快、硬切即可），少数才戏剧化；但**六种宏观接口**（开场、第一幕末、第二幕中、第二幕末、高潮后、离场）不可忽略。

## 关键摘录

- 场景内张力升到顶点，结尾常留**回响线**；多事件成段落，段落有更高顶点。
- **场所二元对立**（昼/夜、内/外、贫/富等）像板块碰撞，产生「场景地震」并帮观众建心理地图。
- **火车模型**：事件如车厢，靠相似性、物体钩子、问答钩、运动匹配等**绑**在一起；断钩则叙事脱轨。
- **情感顶点**后常需**交通/运动场景**承载主人公与观众的共同反应；无情感理由的在途应删。
- **情感低潮**用定场、机位距离、景物、次要情节或「可忽略的对白」让观众加工上一波。
- **音乐**在转换线两侧：默→音、音→默等四种组合转化情绪。
- **拼图**：整片靠场长、张力、情绪错落；过渡场类型含事件、交通、拼贴、主题场、副线、末节场。
- **时间机器**：讲故事即省略；删掉的与留下的同样重要，接缝处用视觉技艺「贴创可贴」。

## 与剧本—分镜工作流

本书不替代一场之内的机位，那一层见 [[贵片感来自机位焦距和人机相对运动]]。对分镜的指导在**第二遍场界**：成对设计 A 尾/B 首、为六种接口与顶点/低潮预备定场、交通、反应、匹配体；与 [[动作行只写镜头里的主体]] 互补——剧本不写机位，但须让转换有素材可剪。
