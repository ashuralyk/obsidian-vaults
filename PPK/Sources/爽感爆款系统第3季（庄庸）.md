# 爽感爆款系统：中国网络文学阅读潮流研究 第3季（庄庸）

庄庸主编，研究网文「爽感」建构与爆款机制，以《斗破苍穹》退婚流、废柴流等为主要分析对象。PDF 扫描版，本地文件未放入附件。

## 中心论证

爽感不是单一刺激，而是在创作链、传播链与读者共建中**被建构**出来的。核心技法是**先阻后助**：多层阻力链蓄能，最大助力阀引爆情绪流（欲扬先抑、弹簧、决堤等比喻同构）。人物系统靠**绿配/衬托链**制造落差；情节靠**V 型人生**、**退婚/打脸**等临界点集中释放；设定靠**缺陷—馅饼**把最大劣势翻成奇遇空间；高潮靠**预期打破**与**不对称局**完成虐到爽的神转折。分析偏方法论与类型史，不是文学价值评判。

## 关键摘录

- 爽感建构：从「多层阻力链」到「最大助力阀」；小—中—大爽点嵌套。
- 绿配鄙视链：内部/外部衬托，虐渣与主角光环同构。
- 纳兰嫣然退婚：长期压抑后的高峰体验引爆点。
- 缺陷即馅饼：缺陷越大，可兑现的超出预期落差越大。
- 王炸：预期打破、不对称之局（势力/信息）。
