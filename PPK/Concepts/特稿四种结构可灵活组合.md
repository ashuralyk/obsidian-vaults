# 特稿四种结构可灵活组合

## 是什么

叶伟民归纳四类常用特稿结构，可混搭：

1. **模块式**：并列版块同一中心，元素可拆重组（灾后北川、停电细节）。  
2. **时间线式**：单线顺叙（情节够猛）；或**双时间线**（一天穿插一生，《举重冠军之死》）。  
3. **多人物/多空间**：双人对照道路、多城交叉（《通天塔》式潜在关联逐步给）。  
4. **剥洋葱式**：层层揭开至核心，适合解释性报道；忌承诺与真相不对等（《走近科学》反例）。

结构服务「带读者走完征程抵达大海」，不是填空模板。

## 为何重要

选错结构会让时间线变死路（灾后静态现场用单线）或悬疑落空。与 [[段落用一个想法拴住一串场面]] 同族：这里是**长文**尺度的段落逻辑。

## 怎么用

按素材性质初选：灾难进行中→时间线；灾后切片→模块；人物命运对照→双轨人物；调查真相→洋葱。写大纲时标「这一章完成哪种读者情绪劳动」。

## 边界

特稿/非虚构；故事片分幕见 [[故事片先搭一条走得完的线]]。四种可组合，「无招」阶段再打破名目。
