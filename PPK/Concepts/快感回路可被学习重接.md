# 快感回路可被学习重接

## 是什么

林登：几乎任何线索（声音、场景、记忆）都可与愉悦绑定，成为新的「快感源」。成瘾、赌博、药物共用**使用依赖**轨迹：压力触发、耐受、复发。记忆、学习与愉悦回路交叉——不只药物改变大脑，**学习规则**也改变多巴胺编码方式。

## 为何重要

观众「养成」不只来自内容质量，也来自**条件反射式场景**（固定 BGM、固定反转类型）。类型惯例见 [[类型惯例由制作作品与观众改写]]：惯例 = 集体学习后的预测模板。

## 怎么用

建立 IP 时意识到：你在训练什么线索 → 奖赏联想。换类型若保留同一「开奖声」，可能沿用旧回路。戒断式设计需改线索，不只改剧情摘要。

## 边界

不否认自由意志与文化调节；与 [[交易心理与系统]] 分轨。
