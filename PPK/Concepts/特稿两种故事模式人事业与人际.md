# 特稿两种故事模式人事业与人际

## 是什么

叶伟民推情节的两条母线：

**人—事**：执念 → 行动 → 困难 → 再行动 → 结果（战胜或失败）。典型特稿主引擎。

**人—人**：人物形象 → 相识 → 对立/破裂 → 和好或相杀。关系变化推动。

可嵌套：《伊力亚的归途》以人—事为主，遇警察陈峰段插入人—人，补人性闪光与节奏平衡。每个「困难—行动」大回合可对应小标题。

## 为何重要

与 [[戏从需求撞上障碍开始]] 同形不同域：特稿的「事」常是真实执念与公共问题，不是银幕 120 页单一需求。混模式不清会导致中段散、关系线抢主线。

## 怎么用

开写前标主模式；若副模式存在，写清它承担的职能（平衡、闪光、过渡）。设计回合时按模式检查：人—事是否每个困难都有行动反馈；人—人是否关系变化有可见节点。

## 多源互证

- Field / 沃尔特：主人公需求与障碍驱动情节。
- 叶伟民：非虚构显式区分「事」引擎与「人」引擎及嵌套。

## 边界

非虚构叙事；虚构剧本仍优先 [[人物选择产生情节]] 与单一戏剧需求，但可借鉴双模式嵌套。
