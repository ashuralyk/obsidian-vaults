# B2D

## 是什么

B2D（Business to Developer）指面向开发者的商业模式：公司卖出的是输入件，也就是积木，而不是成品。价值交换往往发生在开发者用这些积木做成自己的产品、并且成功之后。营销的任务是赋能和启发，而不是推销一件已经包装好的商品。关系也不会随一次购买结束。

变现有四条路径。一是直接收费，而且收入来得早；二是直接收费，但收入延后；三是间接增强市场，只适用于 Developer Plus；四是间接增强生态，也只适用于 Developer Plus。业务成熟之后，公司可以把高频用例做成现成方案，从而把产品往技术栈上游移。

## 为何重要

B2B 与 B2C 的成交节奏、漏斗设计和社区玩法，都不能原样套用到 B2D。这是一场数字游戏：多数用户不会贡献有意义的收入，旅程上的摩擦会把转换率一点点磨掉。

## 实践含义

要把 Learn 与 Build 阶段的摩擦去掉。可持续性不要押在一串很快过时的用例上，也不要押在少数大客户上。上移技术栈是为了节省装配时间，而不是再暴露一层更先进的核心 API。
