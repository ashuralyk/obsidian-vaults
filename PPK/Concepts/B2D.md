# B2D

## 是什么

B2D（Business to Developer）指面向开发者的商业模式：公司卖的是投入品，也就是积木，而不是成品。真正的价值交换，往往要等开发者用这些积木搭出自己的产品、并且做成了之后才发生。营销的任务是赋能和启发，而不是推销一件已经包装好的商品。关系也不会随一次购买结束。

变现有四条路径。一是直接收费，而且收入来得早；二是直接收费，但收入延后；三是间接增强市场，只适用于 Developer Plus；四是间接增强生态，也只适用于 Developer Plus。业务成熟之后，公司可以把高频用例做成现成方案，让产品沿技术栈往上走一层。

## 为何重要

B2B 与 B2C 的成交节奏、漏斗设计和社区玩法，都不能原样套用到 B2D。这归根结底是个基数的生意：多数用户不会带来像样的收入，而旅程上的每一处摩擦，都会把转换率一点点磨掉。

## 实践含义

要把 Learn 与 Build 阶段的摩擦去掉。想做得长久，就不能把赌注压在一批很快过时的用例上，也不能压在少数几个大客户身上。沿技术栈往上走，图的是替开发者省下装配时间，而不是再往外抛一层更先进的核心 API。
