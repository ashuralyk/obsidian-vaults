# 画格六级亮度用来沟通布光意图

## 是什么

下牧把画格亮度分为 **六级**（白、亮明、浅灰、深灰、阴暗、黑），工业沟通上 **相邻级约二倍光比**。说「此处加一级」即银幕该处升一个亮度级别，把 **物理光量** 接到 **心理感受**，方便导演、摄影、美术在分镜阶段对齐，而不是只写「三点布光」。

## 为何重要

[[分镜表左页画格右页鸟瞰一一对应]] 缺 **Lighting 列** 时，现场各猜各的。高感光时代 **夜景过亮** 会丢「夜晚味道」；六级尺度也用来 **约束背景** 见 [[背景光亮度承担时间与气氛叙事]]。

## 怎么用

每格或每场在分镜表注 **主体面光级别 + 背景级别**（如「脸 3 / 背景 5」）；特殊镜另注 [[过肩镜头要有单独布光设计]]。与 Bowen Ch.4 光比概念可并用，下牧偏 **中文现场口语** 与 **教学图示**。

## 边界

不替代测光与灯具选型；六级是 **意图沟通**，不是曝光表唯一真理。
